## 2. 🕵️ Passive vs Active Reconnaissance

### 1. Passive Reconnaissance (Tanpa Menyentuh Target)
Mengumpulkan informasi tanpa mengirimkan paket langsung ke server target, sehingga **tidak akan memicu alarm pada firewall atau IDS/IPS**:
- **Search Engine Dorking (Google Dorks)**:
  - `site:target.com filetype:pdf confidential`
  - `site:target.com inurl:admin | inurl:login`
  - `site:target.com ext:env | ext:log | ext:sql`
- **Shodan / Censys (Internet-Wide Port Scanners)**:
  - `org:"Target Corp" port:"22,3389,8080"`
  - `ssl.cert.subject.CN:"target.com"`
- **Certificate Transparency Logs (`crt.sh`)**: Mengungkap semua subdomain yang pernah dibuatkan sertifikat SSL/TLS.

### 2. Active Reconnaissance (Interaksi Langsung)
Mengirimkan probe jaringan, ping, dan HTTP request langsung ke target untuk memetakan port terbuka, layanan, dan vHost.

## 3. 🛠️ Essential CLI Recon Workflows

```bash
# ── PASSIVE SUBDOMAIN RECON (CRT.SH) ─────────────────────────
curl -s "https://crt.sh/?q=%25.target.com&output=json" | jq -r '.[].name_value' | sort -u

# ── WHOIS & ASN ENUMERATION ──────────────────────────────────
whois target.com
whois -h whois.radb.net -- "-i origin AS13335" # List IP prefixes for ASN

# ── ACTIVE SUBDOMAIN DISCOVERY (FFUF / SECPOSTS) ─────────────
ffuf -u "http://FUZZ.target.com" -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt -mc 200,301,302

# ── VIRTUAL HOST (VHOST) FUZZING ─────────────────────────────
ffuf -u "http://target.com" -H "Host: FUZZ.target.com" -w /usr/share/seclists/Discovery/DNS/namelist.txt -fs 1234
```
