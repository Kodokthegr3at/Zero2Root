## 1. 🚦 Nmap Port States

| State | Description / Respons Jaringan |
|:---|:---|
| **`open`** | Aplikasi target aktif menerima koneksi (Merenspons dengan `SYN-ACK` pada TCP atau balasan pada UDP). |
| **`closed`** | Port dapat diakses tetapi tidak ada aplikasi yang mendengarkan (Merespons dengan paket `RST` pada TCP atau `ICMP Port Unreachable` pada UDP). |
| **`filtered`** | Firewall / packet filter memblokir probe Nmap sehingga status tidak dapat ditentukan (Tidak ada respons sama sekali / *dropped* atau respons `ICMP Admin Prohibited`). |
| **`unfiltered`** | Port dapat diakses tetapi Nmap tidak dapat menentukan apakah port open atau closed (Khas pada *ACK Scan* `-sA`). |
| **`open|filtered`** | Nmap tidak dapat membedakan apakah port open atau difilter oleh firewall (Khas pada scan UDP tanpa respons). |

## 2. ⚡ Core Scanning Techniques

```bash
# ── 1. TCP SYN (STEALTH) SCAN (-sS) [DEFAULT ROOT] ───────────
# Mengirim SYN -> Jika target balas SYN-ACK -> Kirim RST (Koneksi tidak pernah selesai dibuka)
sudo nmap -sS target.com

# ── 2. TCP CONNECT SCAN (-sT) [NON-ROOT] ─────────────────────
# Melakukan 3-way handshake penuh (Mencatat log koneksi di server target)
nmap -sT target.com

# ── 3. UDP SCAN (-sU) ────────────────────────────────────────
# Menguji port UDP (DNS:53, SNMP:161, DHCP:67, TFTP:69)
sudo nmap -sU --top-ports 100 target.com

# ── 4. AGGRESSIVE FULL SCAN (-A) ─────────────────────────────
# Menggabungkan OS Detection, Version Detection, Script Scanning & Traceroute
sudo nmap -A -p- target.com
```

## 3. 📜 Nmap Scripting Engine (NSE)

NSE menggunakan skrip Lua untuk melakukan tugas otomatisasi rekon, pengujian kerentanan, dan eksploitasi:

```bash
# ── DEFAULT SCRIPTS (-sC) ────────────────────────────────────
nmap -sC -sV target.com

# ── VULNERABILITY SCANNING ───────────────────────────────────
nmap --script "vuln" -p 80,443,445 target.com

# ── SMB ENUMERATION (ETERNALBLUE DETECTION) ──────────────────
nmap -p 445 --script "smb-vuln-ms17-010" 192.168.1.100

# ── HTTP VULNERABILITY & ENUMERATION ─────────────────────────
nmap -p 80 --script "http-enum,http-title,http-headers" target.com
```

## 4. 🥷 Firewall & IDS/IPS Evasion Techniques

```bash
# ── FRAGMENT PACKETS (-f / --mtu) ────────────────────────────
# Memecah header TCP menjadi fragmen kecil 8-byte untuk melewati packet filter sederhana
sudo nmap -f -sS target.com

# ── DECOY SCAN (-D) ──────────────────────────────────────────
# Menyelundupkan IP penyerang di antara ribuan IP acak palsu
sudo nmap -D RND:10,ME target.com

# ── SOURCE PORT MANIPULATION (--source-port / -g) ────────────
# Memalsukan port sumber (misal port DNS 53 atau NTP 123) untuk melewati firewall permisif
sudo nmap -g 53 target.com

# ── TIMING TEMPLATES (-T0 to -T5) ────────────────────────────
# -T0 (Paranoid) / -T1 (Sneaky) -> Menghindari deteksi IDS berbasis rate-limit
# -T4 (Aggressive) / -T5 (Insane) -> Scan berkecepatan tinggi di lab lokal
sudo nmap -T4 -p 1-10000 192.168.1.50
```
