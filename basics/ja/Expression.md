## 重要な用語

この教材でよく出てくる言葉である。

| 用語 | 意味 |
|:---|:---|
| 式(expression) | 値を生み出すコードのかたまり。`2 + 2` や `x > 5` など |
| 演算子(operator) | 何かをする記号: `+`、`&&`、`==`、`<<` |
| オペランド | 演算子が作用する値(`2 + 3` ならオペランドは 2 と 3) |
| 優先順位 | 演算子が実行される順番(学校の算数と同じで `*` が `+` より先) |
| ブール | `true` か `false` のどちらかだけの値 |
| 短絡評価 | 答えが確定した時点で論理のチェックを早く打ち切ること |
| オーバーフロー | 数が型に収まらないほど大きくなり、一周して戻ること |
| キャスト | 値をある型から別の型に変換すること |
| RegEx | テキストを照合するためのパターン言語 |

## 1. 式とは何か

**式(expression)**とは、1つの値になるコードのかたまりだ。`2 + 2` は式だ(`4` を生む)。`年齢 > 18` も式だし(`true` か `false` を生む)、`"admin".toUpperCase()` もそうだ。

式は**オペランド**(値)と**演算子**(それらを組み合わせる記号)から組み立てられる。この教材では、演算子の主な仲間、実行される順番、そして式を、特に信頼できない入力に対して不用意に評価したときに忍び込むセキュリティのバグをたどる。

## 2. 算術式

**算術式**は、おなじみの数学の演算子で数を生む。足し算(`+`)、引き算(`-`)、掛け算(`*`)、割り算(`/`)、余り(`%`)だ。

順番は普通の学校の算数(BODMAS/PEMDAS)に従う。`*`、`/`、`%` が `+` と `-` より先に走り、かっこ `()` がすべてに勝つ。同じ優先度の演算子は左から右へ走る。

> **整数オーバーフローに注意。** どの整数型にも最大値がある。32ビット符号付き `int` は 2,147,483,647 で頭打ちになり、もう1足すと一周して大きな負の数になる。Cでは、これがプログラムが小さすぎるバッファを確保する典型的な原因で、メモリのバグにつながる。

```java
// ── Java ─────────────────────────────────────────────────────
int a = 10, b = 3;
int sum        = a + b;          // 13
int difference = a - b;          // 7
int product    = a * b;          // 30
int quotient   = a / b;          // 3    (整数の割り算は小数部を捨てる)
int remainder  = a % b;          // 1    (割った後の「余り」)
```

```c
/* ── C: / と % で秒を 時:分:秒 に分ける ──────────────────── */
#include <stdio.h>
int main(void) {
    int total_seconds = 3665;
    int hours   = total_seconds / 3600;        /* 1 */
    int minutes = (total_seconds % 3600) / 60; /* 1 */
    int seconds = total_seconds % 60;          /* 5 */
    printf("Time: %02d:%02d:%02d\n", hours, minutes, seconds);
    return 0;
}
```

| 演算子 | 意味 | 例 | 結果 |
|----------|------|------|-------|
| `+` | 足す | `10 + 3` | `13` |
| `-` | 引く | `10 - 3` | `7` |
| `*` | 掛ける | `10 * 3` | `30` |
| `/` | 割る | `10 / 3` | `3`(整数) |
| `%` | 余り | `10 % 3` | `1` |

## 3. 論理式(ブール)

**論理式**は、true/false の値を組み合わせて1つの true/false の答えにする。AND(`&&`)、OR(`||`)、NOT(`!`)を使う。

ほとんどの言語は**短絡評価**だ。答えが確定した時点で止まる。`A && B` で `A` がすでに `false` なら、`B` は決してチェックされない。これは単なる最適化ではなく、安全のための道具だ。定番の使い方は、何かが空でないことを使う*前に*確かめることだ。

```java
// username が null なら username.length() には到達しない(クラッシュしない)
if (username != null && username.length() > 3) {
    System.out.println("Valid user format");
}

boolean isAuthenticated = true;
boolean hasAdminRole    = false;
boolean canAccessAdmin  = isAuthenticated && hasAdminRole;  // false(両方必要)
boolean canViewPublic   = isAuthenticated || hasAdminRole;  // true (どちらか必要)
boolean isGuest         = !isAuthenticated;                 // false(その反対)
```

| 演算子 | 名前 | true になるのは… |
|----------|------|------------------|
| `&&` | AND | 両側が true のとき |
| `\|\|` | OR | 少なくとも片側が true のとき |
| `!` | NOT | true と false を入れ替える |

## 4. 関係式(比較)

**関係式**は2つの値を比べ、ブール値を返す。`==`(等しい)、`!=`(等しくない)、`>`、`<`、`>=`、`<=` だ。

> **セキュリティの観点 — 型のゆるい比較(type juggling)。** 一部の言語は、型の違う値をゆるく比較できる。PHPの `==` やJavaScriptの `==` は、比較の前にこっそり型を変換してしまい、それが実際の認証バイパスを引き起こしてきた(たとえば、違う2つの文字列がどちらも「ゼロと等しい」とみなされる、など)。対策は**厳密な**比較だ。PHP/JSの `===`、または型変換をしない型付きの比較を使う。パスワードのハッシュをゆるい `==` で比べては絶対にいけない。

```c
int user_uid = 1000;
int root_uid = 0;
int is_root     = (user_uid == root_uid);   /* 0 (false) */
int is_standard = (user_uid >= 1000);       /* 1 (true)  */
```

| 演算子 | 意味 | 例 → 結果 |
|----------|------|-----------|
| `==` | 等しい | `10 == 10` → true |
| `!=` | 等しくない | `10 != 20` → true |
| `>` `<` | より大きい / 小さい | `15 > 10` → true |
| `>=` `<=` | 以上 / 以下 | `10 >= 10` → true |

## 5. 代入式

**代入**は `=` で値を変数に入れる。複合形は演算と代入を組み合わせる。`x += 5` は `x = x + 5` の意味だ。

代入は**右結合**だ。`x = y = z = 10` は右から左へ走るので、まず `z` に 10、次に `y`、最後に `x` が入る。

```java
int counter = 0;
counter += 5;   // 5   (counter = counter + 5)
counter *= 2;   // 10
counter -= 3;   // 7

// ++ と -- は変数を1だけ変える。どちらに置くかで意味が変わる:
int a = 5;
int b = ++a;    // 「前置」: a が先に 6 になり、その後 b = 6
int c = a++;    // 「後置」: c = 6 が先で、その後 a が 7 になる
```

## 6. 条件式(三項演算子)

**三項演算子**は、値を生むコンパクトな `if-else` だ。「条件 ? trueのときの値 : falseのときの値」と読む。

```python
user_role = "admin"
access_level = 100 if user_role == "admin" else 10   # Pythonの書き方
```

```c
int port = 443;
const char *protocol = (port == 443) ? "HTTPS(暗号化)" : "HTTP(平文)";
```

短い二択に使う。枝が複数あるものには、普通の `if-else` のほうが読みやすいままだ。

## 7. ラムダ式

**ラムダ**は、値のように持ち回せる、名前のない小さな関数だ。Java 8+、Python(`lambda`)、C++(`[]{}`)、JavaScript(`() => {}`)のどれにもある。リストの絞り込みや変換で真価を発揮し、ログ解析で絶えず出てくる。

```python
# 失敗したリクエスト(HTTPステータス400以上)だけを残す
logs = [
    {"ip": "192.168.1.10", "status": 200},
    {"ip": "10.0.0.5",     "status": 404},
    {"ip": "172.16.0.4",   "status": 401},
]
failed = list(filter(lambda e: e["status"] >= 400, logs))
```

```java
// 機微に見えるエンドポイントだけを残し、大文字にする
List<String> sensitive = endpoints.stream()
    .filter(ep -> ep.contains("admin") || ep.contains("config"))
    .map(String::toUpperCase)
    .collect(Collectors.toList());
```

## 8. 正規表現(RegEx)

**正規表現**はテキストを照合するためのパターンだ。入力の検証、ログの検索、検知シグネチャ(Snort、Suricata、YARA)の記述に使う。

```bash
# ログからIPv4アドレスを探す
grep -E -o '([0-9]{1,3}\.){3}[0-9]{1,3}' /var/log/auth.log

# MD5ハッシュの形(16進32文字)を探す
grep -E -i '\b[a-f0-9]{32}\b' hashes.txt

# AWSアクセスキーの形を探す
grep -E 'AKIA[0-9A-Z]{16}' source_code.py
```

| 部品 | 意味 |
|------|------|
| `^` / `$` | テキストの先頭 / 末尾 |
| `.` | 任意の1文字 |
| `\d` / `\w` / `\s` | 数字 / 単語文字 / 空白のいずれか1つ |
| `*` / `+` / `?` | 0回以上 / 1回以上 / あってもなくても |
| `{n,m}` | n回からm回 |
| `[...]` | 集合の中のどれか1文字 |
| `(A\|B)` | A または B |

> **ReDoSのリスク:** 入れ子の繰り返し(`(a+)+$` など)を含む下手なパターンは、特定の入力に対して指数時間かかり、プログラムを固めてしまう。攻撃者はそれをわざと引き起こせる。パターンは単純に保ち、照合のタイムアウトを設けるか、線形時間のエンジンを使うこと。

## 9. ビット式

**ビット式**は、数の個々の1と0を操作する。暗号、サブネット計算、Unixのパーミッション、リバースエンジニアリングで登場する。

演算子: AND(`&`)、OR(`|`)、XOR(`^`)、NOT(`~`)、左シフト(`<<`)、右シフト(`>>`)。

```c
/* XORは元に戻せる: 同じ鍵を2回当てると元の値に戻る */
char original  = 'A';              /* 01000001 */
char key       = 0x5A;             /* 01011010 */
char encrypted = original ^ key;   /* 00011011 */
char decrypted = encrypted ^ key;  /* 01000001 → 再び 'A' */

/* Unixのパーミッションをビットで: read=4, write=2, execute=1 */
int rwx = (1 << 2) | (1 << 1) | (1 << 0);  /* 4 | 2 | 1 = 7 (rwx) */
int can_execute = (rwx & 1);               /* executeビットを調べる */
```

| 演算子 | 名前 | 例(`a=5` `0101`、`b=3` `0011`) | 結果 |
|----------|------|---------------------------------|-------|
| `&` | AND | `0101 & 0011` → `0001` | `1` |
| `\|` | OR | `0101 \| 0011` → `0111` | `7` |
| `^` | XOR | `0101 ^ 0011` → `0110` | `6` |
| `~` | NOT | すべてのビットを反転 | `-6` |
| `<<` | 左シフト | `0101 << 1` → `1010`(×2) | `10` |
| `>>` | 右シフト | `0101 >> 1` → `0010`(÷2) | `2` |

## 10. キャスト式

**キャスト**は値をある型から別の型に変換する。2種類ある。

- **拡大(安全):** 小さい型 → 大きい型。`int` → `double` など。何も失われず、言語が自動でやってくれる。
- **縮小(危険):** 大きい型 → 小さい型。`double` → `int`、または32ビット `int` → 8ビット `char` など。明示的に指定する必要があり、データが**切り捨てられる**ことがある。

```c
int large = 300;
/* 300は8ビットに収まらない。下位8ビットだけが残る: 300 → 44 */
unsigned char truncated = (unsigned char)large;   /* 300 ではなく 44 */
```

その静かな切り捨ては、実際のセキュリティバグの源だ。長さチェックは大きい値で通るのに、実際に使われるのは切り捨てられた小さい値、という具合になる。

## 11. オブジェクト生成式

**オブジェクト生成式**は、メモリ上に新しいオブジェクトを作る。たいてい `new` を使い、そのオブジェクトのコンストラクタを呼び出す。

```java
TargetHost target = new TargetHost("192.168.1.1", 443);
target.scan();
```

マネージド言語(Java、Python、C#)ではメモリは自動で片付けられる。C/C++では、確保したメモリ(`new` / `malloc`)はちょうど一度だけ解放(`delete` / `free`)しなければならない。さもないと、リーク(解放し忘れ)や use-after-free(解放後に使う)のバグになる。

## 12. セキュリティノート

式は、信頼できない入力がコードとして評価されたり、チェックなしに使われたりすると、脆弱性に変わる。テーマは、入力を命令ではなくデータとして扱うことだ。

| リスク | 何がまずいか | 防御 |
|:---|:---|:---|
| 式言語インジェクション(SpEL/OGNL) | ユーザーのテキストがサーバー側の式として評価される | 入力を式として評価しない。テンプレートを許可リスト化する |
| ReDoS | 細工した文字列で正規表現が延々と走る | 単純なパターン、照合のタイムアウト、線形時間のエンジン |
| 型のゆるい比較 | ゆるい `==` が別物の値を等しいとみなす | 厳密な等価(`===` / 型付き比較)、特に秘密情報では |
| 整数オーバーフロー(C) | サイズが一周し、バッファが小さく確保される | 確保の前に確認する。`-fsanitize=undefined,integer` |
| 入力への shell `eval` / `$((...))` | 入力がコマンドになる | 生の入力を `eval` しない。クォートする。本物のパーサーを使う |

## 13. チートシート

| 分類 | 演算子 | 生むもの |
|----------|--------|----------|
| 算術 | `+ - * / %` | 数 |
| 論理 | `&& \|\| !` | true/false(短絡評価) |
| 関係 | `== != < > <= >=` | true/false |
| 代入 | `= += -= *= /=` | 値を格納する |
| 三項 | `cond ? a : b` | 2つの値のどちらか |
| ラムダ | `(x) -> ...` | 関数 |
| RegEx | `^ $ \d \w .*` | テキストの一致 |
| ビット | `& \| ^ ~ << >>` | ビット単位の結果 |
| キャスト | `(type) value` | 変換された値 |
| オブジェクト | `new Class()` | 新しいオブジェクト |
