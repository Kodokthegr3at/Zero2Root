## 1. 🏢 Overview — Public-Key Cryptography

### 🇮🇩 Bahasa Indonesia
Kriptografi Asimetris menggunakan **sepasang kunci yang saling terhubung secara matematis**:
- **Public Key (Kunci Publik)**: Dapat disebarkan secara bebas kepada siapa saja di internet. Digunakan untuk **mengenkripsi pesan** atau **memverifikasi tanda tangan digital**.
- **Private Key (Kunci Privat)**: Harus dijaga kerahasiaannya oleh pemilik dan tidak boleh dibagikan. Digunakan untuk **mendekripsi pesan** atau **membuat tanda tangan digital**.

## 2. 🧮 The RSA Algorithm (Rivest-Shamir-Adleman)

### 🇮🇩 Bahasa Indonesia
Keamanan RSA bergantung pada kesulitan komputasi dalam melakukan **faktorisasi bilangan bulat besar (*Prime Factorization Problem*)** menjadi dua faktor prima $p$ dan $q$:

1. Pilih dua bilangan prima rahasia yang sangat besar $p$ dan $q$.
2. Hitung modulus publik $n = p \times q$.
3. Hitung fungsi Euler $\phi(n) = (p - 1)(q - 1)$.
4. Pilih eksponen publik $e$ sedemikian rupa sehingga $\gcd(e, \phi(n)) = 1$ (standar industri: $e = 65537$).
5. Hitung eksponen privat $d$ sedemikian rupa sehingga $d \times e \equiv 1 \pmod{\phi(n)}$.

$$\text{Enkripsi: } C \equiv M^e \pmod n \quad\quad \text{Dekripsi: } M \equiv C^d \pmod n$$

## 3. 🤝 Diffie-Hellman Key Exchange (DH & ECDH)

Diffie-Hellman memungkinkan dua pihak (Alice dan Bob) yang berkomunikasi melalui saluran publik yang tidak aman untuk menyepakati satu **kunci rahasia bersama (*shared secret*)** tanpa pernah mengirimkan kunci itu sendiri melintasi jaringan!

```
Alice                                                                 Bob
  │                                                                     │
  │─── 1. Public Parameters: Prime (p), Generator (g) ─────────────────>│
  │                                                                     │
  │ [Alice generates private 'a']                 [Bob generates private 'b']
  │ [Computes Public: A = g^a mod p]              [Computes Public: B = g^b mod p]
  │                                                                     │
  │─── 2. Sends Public Key (A) ────────────────────────────────────────>│
  │<── 3. Sends Public Key (B) ─────────────────────────────────────────│
  │                                                                     │
  │ [Computes Secret: K = B^a mod p]              [Computes Secret: K = A^b mod p]
  │                                                                     │
  │══════════ SHARED SECRET K IS IDENTICAL ON BOTH SIDES! ══════════════│
```

## 4. 📈 Elliptic Curve Cryptography (ECC)

ECC menawarkan tingkat keamanan yang setara dengan RSA tetapi dengan **ukuran kunci yang jauh lebih kecil**, konsumsi CPU yang jauh lebih rendah, dan pemrosesan yang jauh lebih cepat:

| Security Level | Symmetric Equivalent | RSA Key Size | ECC Key Size (ECDSA / Ed25519) |
|:---|:---|:---|:---|
| **Standard** | 128-bit | RSA-3072 bit | ECC-256 bit (secp256r1 / Ed25519) |
| **High Security** | 192-bit | RSA-7680 bit | ECC-384 bit |
| **Ultra Military**| 256-bit | RSA-15360 bit| ECC-521 bit (Ed448) |

## 5. 🛠️ Practical OpenSSL Command Workflows

```bash
# ── RSA 4096-BIT KEYPAIR GENERATION ──────────────────────────
openssl genrsa -out private_rsa.pem 4096
openssl rsa -in private_rsa.pem -pubout -out public_rsa.pem

# ── ECC (SECP256R1) KEYPAIR GENERATION ───────────────────────
openssl ecparam -name prime256v1 -genkey -noout -out private_ec.pem
openssl ec -in private_ec.pem -pubout -out public_ec.pem

# ── ED25519 (MODERN EDDSA) KEYPAIR GENERATION ────────────────
openssl genpkey -algorithm ED25519 -out private_ed25519.pem
openssl pkey -in private_ed25519.pem -pubout -out public_ed25519.pem

# ── DIGITAL SIGNATURE & VERIFICATION ─────────────────────────
# Sign file with private key
openssl dgst -sha256 -sign private_rsa.pem -out doc.sig document.pdf
# Verify signature with public key
openssl dgst -sha256 -verify public_rsa.pem -signature doc.sig document.pdf
```
