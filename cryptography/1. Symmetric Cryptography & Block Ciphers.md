## 1. 🏢 Core Cryptographic Principles

### 🇮🇩 Bahasa Indonesia
Kriptografi modern adalah disiplin matematika dan komputasi yang menyediakan empat pilar keamanan informasi:
1. **Confidentiality (Kerahasiaan)**: Memastikan hanya pihak berwenang yang dapat membaca data (Enkripsi).
2. **Integrity (Integritas)**: Memastikan data tidak dimanipulasi atau diubah selama transit (Hash / MAC).
3. **Authentication (Autentikasi)**: Memverifikasi identitas pengirim atau sumber data (Digital Signatures).
4. **Non-Repudiation (Anti-Penyangkalan)**: Mencegah pengirim menyangkal bahwa ia telah mengirimkan pesan tersebut.

## 2. 🔑 Symmetric vs Asymmetric Cryptography

| Parameter | Symmetric Cryptography (Kunci Simetris) | Asymmetric Cryptography (Kunci Publik) |
|:---|:---|:---|
| **Jumlah Kunci** | 1 Kunci Rahasia Bersama (*Shared Secret Key*) | 2 Kunci (Public Key + Private Key) |
| **Kecepatan** | Sangat Cepat (Dioptimalkan hardware AES-NI) | Lambat (Operasi matematika kompleks) |
| **Ukuran Kunci Standar** | AES-128, AES-256 bit | RSA-2048/4096 bit, ECC-256/384 bit |
| **Masalah Utama** | Distribusi Kunci (*Key Exchange Problem*) | Komputasi intensif & ukuran ciphertext |
| **Penggunaan Utama** | Enkripsi data massal, disk encryption, TLS payload | Key exchange (ECDH), autentikasi & tanda tangan digital |

## 3. 🧩 Block Cipher Modes of Operation

```
┌────────────────────────────────────────────────────────────────────────┐
│                   BLOCK CIPHER MODES OF OPERATION                      │
├──────┬───────────────────────────────┬────────────┬────────────────────┤
│ Mode │ Description                   │ Security   │ Vulnerabilities    │
├──────┼───────────────────────────────┼────────────┼────────────────────┤
│ ECB  │ Electronic Codebook           │ 🔴 Broken  │ Patterns preserved │
│ CBC  │ Cipher Block Chaining         │ 🟡 Legacy  │ Padding Oracle     │
│ CTR  │ Counter Mode                  │ 🟢 High    │ Nonce reuse reuse  │
│ GCM  │ Galois/Counter Mode (AEAD)    │ 🟢 Standard│ Nonce reuse attack │
└──────┴───────────────────────────────┴────────────┴────────────────────┘
```

### 1. ECB (Electronic Codebook) — INSECURE
Setiap blok plaintext 128-bit dienkripsi secara independen dengan kunci yang sama. **Pola data plaintext tetap terlihat pada ciphertext** (contoh terkenal: *ECB Tux Penguin*). Jangan pernah gunakan ECB!

### 2. CBC (Cipher Block Chaining)
Setiap blok plaintext di-XOR dengan blok ciphertext sebelumnya sebelum dienkripsi. Blok pertama di-XOR dengan **IV (Initialization Vector)** acak.
- **Kelemahan**: Rentan terhadap **Padding Oracle Attack (POODLE / Vaudenay)** jika server membocorkan error validasi PKCS#7 padding.

### 3. GCM (Galois/Counter Mode) — MODERN STANDARD (AEAD)
Menggabungkan mode Counter (CTR) dengan otentikasi Galois (*Galois Message Authentication*). Menyediakan **Authenticated Encryption with Associated Data (AEAD)** — menghasilkan *ciphertext* sekaligus *authentication tag* (GMAC) 128-bit untuk menjamin kerahasiaan sekaligus integritas data secara bersamaan.

## 4. 🛠️ Practical OpenSSL Command Workflows

```bash
# ── AES-256-CBC ENCRYPTION (WITH SALT) ───────────────────────
openssl enc -aes-256-cbc -salt -in confidential.txt -out secret.enc -pbkdf2 -iter 100000

# ── AES-256-CBC DECRYPTION ───────────────────────────────────
openssl enc -d -aes-256-cbc -in secret.enc -out decrypted.txt -pbkdf2 -iter 100000

# ── AES-256-GCM AUTHENTICATED ENCRYPTION ─────────────────────
openssl enc -aes-256-gcm -in secret.txt -out secret.gcm -K <HEX_KEY> -iv <HEX_IV>

# ── BENCHMARK CRYPTOGRAPHIC SPEED ────────────────────────────
openssl speed -evp aes-256-gcm
```
