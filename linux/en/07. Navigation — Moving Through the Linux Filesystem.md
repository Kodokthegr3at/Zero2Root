## Key Terms

You'll see these words throughout the lesson.

| Term | Plain meaning |
|:---|:---|
| Working directory | The folder you're "standing in" right now |
| Absolute path | A full address from the root, like `/home/alex/notes` |
| Relative path | An address from where you are, like `../notes` |
| `.` and `..` | "This folder" and "the folder above" |
| `~` | A shortcut for your home directory |

## 1. `pwd` (Print Working Directory)

`pwd` is used to find out our current position in the filesystem. It's the first command worth running after accessing a system, so we know exactly where we are.

```bash
$ pwd
/home/cry0l1t3
```

---

## 2. `ls` (List Directory Contents)

`ls` displays a list of files and directories at a location. Without extra options, only the names of files and folders are shown. We can also specify a path without navigating there first.

```bash
# List current directory
$ ls
Desktop  Documents  Downloads  Music  Pictures  Public  Templates  Videos

# List specific path without navigating there
$ ls /var/
backups  cache  crash  lib  local  log  lock  mail  opt  run  spool  tmp
```

---

## 3. `ls -l` (Detailed Listing)

The `-l` flag shows detailed information about each file and directory, including permissions, owner, size, and modification time. The first line, `total 32`, indicates total disk blocks used (32 blocks x 1024 bytes = 32 KB).

```bash
$ ls -l

total 32
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:37 Desktop
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:34 Documents
drwxr-xr-x 3 cry0l1t3 htbacademy 4096 Nov 15 03:26 Downloads
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:34 Music
```

### Output Column Breakdown

```
drwxr-xr-x   2   cry0l1t3   htbacademy   4096   Nov 13 17:37   Desktop
     │        │       │           │         │          │           │
     │        │       │           │         │          │           └─ Name
     │        │       │           │         │          └─ Date & Time
     │        │       │           │         └─ Size (bytes) / blocks
     │        │       │           └─ Group owner
     │        │       └─ Owner (user)
     │        └─ Number of hard links
     └─ Type + Permissions
```

| Column | Description |
|--------|-------------|
| `drwxr-xr-x` | File type & permissions |
| `2` | Number of hard links |
| `cry0l1t3` | File owner (user) |
| `htbacademy` | Group owner |
| `4096` | File size in bytes |
| `Nov 13 17:37` | Last modification date & time |
| `Desktop` | File / directory name |

### Understanding Permissions: `drwxr-xr-x`

```
d  rwx  r-x  r-x
│   │    │    │
│   │    │    └─ Others  : read + execute only
│   │    └─ Group    : read + execute only
│   └─ Owner    : read + write + execute
└─ Type: d=directory, -=file, l=symlink
```

| Symbol | Meaning |
|--------|---------|
| `d` | Directory |
| `-` | Regular file |
| `l` | Symbolic link |
| `r` | Read permission |
| `w` | Write permission |
| `x` | Execute permission |
| `-` | No permission |

## 4. `ls -la` (Show Hidden Files)

The `-a` flag shows all files, including hidden ones. On Linux, hidden files start with a dot (`.`), like `.bashrc` or `.bash_history`. These files usually contain important configuration and are often missed by plain `ls`.

```bash
$ ls -la

total 403188
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:37 .bash_history
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:37 .bashrc
...
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:37 Desktop
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:34 Documents
```

Pentesting note: hidden files like `.bash_history` can contain previously executed commands, credentials, or sensitive paths left behind by other users. Always check with `ls -la` when enumerating a system.

### Common Hidden Files

| File | Function |
|------|----------|
| `.bashrc` | Bash shell configuration |
| `.bash_history` | History of executed commands |
| `.bash_profile` | Login shell configuration |
| `.ssh/` | SSH keys & configuration |
| `.env` | Environment variables |

## 5. `cd` (Change Directory)

`cd` is used to navigate between directories. We can use an absolute path (starting from `/`) or a relative path (relative to the current directory). There's no need to navigate step by step; we can jump directly to the full destination path.

```bash
# Navigate using absolute path (jump directly)
$ cd /dev/shm
cry0l1t3@htb[/dev/shm]$

# Navigate using relative path
$ cd Documents

# Jump to home directory
$ cd ~
$ cd          # also goes to home

# Navigate using dot notation
$ cd ./Storage/local/user
```

### Absolute vs Relative Path

```
Filesystem root: /
        │
        ├── home/
        │     └── cry0l1t3/        ← you are here (~)
        │           ├── Desktop/
        │           └── Documents/
        │
        └── dev/
              └── shm/             ← target

Absolute: cd /dev/shm              (always starts from /)
Relative: cd ../../dev/shm         (from current location)
```

---

## 6. `cd -` (Return to Previous Directory)

`cd -` is a quick shortcut to return to the previously visited directory. It's useful when switching back and forth between two different directories.

```bash
$ pwd
/home/cry0l1t3

$ cd /dev/shm
cry0l1t3@htb[/dev/shm]$

$ cd -
cry0l1t3@htb[~]$         # back to /home/cry0l1t3

$ cd -
cry0l1t3@htb[/dev/shm]$  # and back again
```

---

## 7. `cd ..` (Go Up to Parent Directory)

`..` (two dots) always refers to the parent directory, one level above the current directory. `.` (one dot) refers to the current directory. Both symbols always appear in `ls -la` output as the first two entries.

```bash
$ pwd
/dev/shm

$ ls -la /dev/shm
total 0
drwxrwxrwt  2 root root   40 Mai 15 18:31 .    ← current dir (/dev/shm)
drwxr-xr-x 17 root root 4000 Mai 14 20:45 ..   ← parent dir (/dev)

# Go up one level
$ cd ..
cry0l1t3@htb[/dev]$

# Go up two levels at once
$ cd ../..

# Combine with path
$ cd ../../home/cry0l1t3
```

---

## 8. `clear` (Clear the Terminal)

`clear` cleans the terminal screen of all previous output. It can be combined with other commands using `&&`. A faster alternative is the keyboard shortcut `[CTRL + L]`.

```bash
# Clear the terminal
$ clear

# Combine: navigate and clear in one line
$ cd /dev/shm && clear

# Keyboard shortcut alternative
[CTRL + L]
```

## 9. Shell Navigation Shortcuts

The shell provides various keyboard shortcuts that significantly speed up terminal navigation and usage.

| Shortcut | Function |
|----------|----------|
| `[TAB]` | Auto-complete file/path names |
| `[TAB TAB]` | Show all possible completions |
| `↑ / ↓` | Scroll through command history |
| `[CTRL + R]` | Search command history |
| `[CTRL + L]` | Clear terminal |
| `[CTRL + C]` | Cancel running command |
| `[CTRL + A]` | Move to start of line |
| `[CTRL + E]` | Move to end of line |

### TAB Auto-complete Demo

```bash
# Type partial path and press TAB twice to see options
$ cd /dev/s[TAB TAB]
shm/  snd/

# Add "h" to narrow it down — shell completes automatically
$ cd /dev/sh[TAB]
$ cd /dev/shm/    ← completed!
```

```bash
# ── WHERE AM I ──────────────────────────────────────
pwd                         # show current directory

# ── LIST CONTENTS ───────────────────────────────────
```
