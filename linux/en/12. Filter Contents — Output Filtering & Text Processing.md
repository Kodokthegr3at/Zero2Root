## Key Terms

You'll see these words throughout the lesson.

| Term | Plain meaning |
|:---|:---|
| Pager | Views long output one screen at a time (`less`, `more`) |
| `head` / `tail` | Show the first / last lines of a file |
| `grep` | Keep only lines that match a pattern |
| `cut` | Pull out specific columns or fields |
| `sort` / `uniq` | Order lines / collapse repeated lines |
| `wc` | Count lines, words, and characters |
| `awk` / `sed` | Mini text-processing languages for fields and substitutions |

## 1. `more`

`more` displays file contents page by page. It has a couple of limitations: you can't scroll upward, and once you exit with `q`, whatever was already displayed stays in the terminal. It's fine for a quick look at a file when you don't need to navigate around.

```bash
more /etc/passwd
```

> Use `SPACE` to go to the next page, `q` to quit.

---

## 2. `less`

`less` is a more capable version of `more`. It scrolls both up and down, displays the full file, and clears the terminal on exit with `q` instead of leaving output behind. It's the better choice for reading long files.

```bash
less /etc/passwd
```

> Use the arrow keys or `j`/`k` to scroll, `/keyword` to search inside the file, `q` to quit.

---

## 3. `head`

`head` shows a file's first 10 lines by default. Useful for previewing headers or the start of a log or data file.

```bash
head /etc/passwd

# Custom: show first 20 lines
head -n 20 /etc/passwd
```

---

## 4. `tail`

`tail` is the opposite of `head`: it shows a file's last 10 lines. Combined with the `-f` flag it's essential for watching log files in real time.

```bash
tail /etc/passwd

# Real-time log monitoring
tail -f /var/log/syslog

# Custom: show last 20 lines
tail -n 20 /etc/passwd
```

---

## 5. `sort`

`sort` arranges a file's contents or an incoming stream alphabetically (A-Z) by default. It can be piped after another command to sort that command's output.

```bash
sort /etc/passwd

# Reverse order (Z-A)
sort -r /etc/passwd

# Sort numerically
sort -n file.txt
```

---

## 6. `grep`

`grep` stands for Global Regular Expression Print. It searches for and filters lines from a file or a stream that match a given pattern, and it becomes much more capable once combined with regex.

```bash
# Show lines containing "root"
grep "root" /etc/passwd

# Exclude lines with "false" or "nologin"
grep -v "false\|nologin" /etc/passwd

# Case insensitive search
grep -i "ROOT" /etc/passwd
```

| Flag | Function |
|------|----------|
| `-v` | Invert match (exclude pattern) |
| `-i` | Case insensitive |
| `-n` | Show line numbers |
| `-r` | Recursive search in a directory |
| `-E` | Extended regex |

---

## 7. `cut`

`cut` removes or extracts a specific part of each line in a file. It's typically used to select a column based on a delimiter, such as the `:` character in `/etc/passwd`.

```bash
# Extract field 1 (username) using ":" as delimiter
cut -d":" -f1 /etc/passwd

# Extract multiple fields
cut -d":" -f1,7 /etc/passwd
```

---

## 8. `tr`

`tr` (translate) replaces or deletes characters in a stream. For example, swapping `:` for a space makes output easier to read.

```bash
# Replace ":" with space
cat /etc/passwd | tr ":" " "

# Convert lowercase to uppercase
cat file.txt | tr 'a-z' 'A-Z'

# Delete specific characters
cat file.txt | tr -d ':'
```

---

## 9. `column`

`column` formats a stream into a neat, readable table layout. It's commonly paired with `tr` to produce clean, structured tables.

```bash
# Format passwd file as a table
cat /etc/passwd | tr ":" " " | column -t
```

---

## 10. `awk`

`awk` is a powerful text-processing language. Its main use here is printing specific columns from each line of output: `$1` refers to the first column, `$NF` refers to the last column.

```bash
cat /etc/passwd | grep -v "false\|nologin" | tr ":" " " | awk '{print $1, $NF}'
```

**Output:**
```
root /bin/bash
sync /bin/sync
postgres /bin/bash
mrb3n /bin/bash
cry0l1t3 /bin/bash
htb-student /bin/bash
```

| Variable | Meaning |
|----------|---------|
| `$1` | First column |
| `$2` | Second column |
| `$NF` | Last column (N = total fields) |
| `$0` | Entire line |
| `NR` | Current line number |

---

## 11. `sed`

`sed` (Stream Editor) substitutes text in a stream using regex patterns. The general format is `s/old_pattern/new_pattern/g`, where `s` means substitute and `/g` means global, replacing every occurrence rather than just the first.

```bash
cat /etc/passwd | grep -v "false\|nologin" | tr ":" " " | awk '{print $1, $NF}' | sed 's/bin/HTB/g'
```

**Output:**
```
root /HTB/bash
sync /HTB/sync
postgres /HTB/bash
mrb3n /HTB/bash
cry0l1t3 /HTB/bash
htb-student /HTB/bash
```

---

## 12. `wc`

`wc` (Word Count) counts the number of lines, words, or characters in a file or stream. The flag most commonly used for filtering is `-l`, which counts the number of matched lines.

```bash
cat /etc/passwd | grep -v "false\|nologin" | tr ":" " " | awk '{print $1, $NF}' | wc -l
```

**Output:**
```
6
```

| Flag | Function |
|------|----------|
| `-l` | Count lines |
| `-w` | Count words |
| `-c` | Count bytes/characters |

## 13. Combining All the Tools

A one-liner pipeline that chains every tool above:

```bash
cat /etc/passwd \
  | grep -v "false\|nologin" \   # Remove service accounts
  | tr ":" " " \                 # Replace ":" with space
  | awk '{print $1, $NF}' \      # Print username and shell
  | sed 's/bin/HTB/g' \          # Replace "bin" with "HTB"
  | sort \                       # Sort alphabetically
  | wc -l                        # Count total results
```

### Pipeline Diagram

```
[cat /etc/passwd]
       │
       ▼
[grep -v "false\|nologin"]  ── filter out service accounts
       │
       ▼
[tr ":" " "]  ── make columns readable
       │
       ▼
[awk '{print $1, $NF}']  ── extract username & shell
       │
       ▼
[sed 's/bin/HTB/g']  ── substitute text
       │
       ▼
[sort]  ── alphabetical order
       │
       ▼
[wc -l]  ── count output
```

## 14. Security Note: Log Forensics & GTFOBins

Text filtering commands are a foundational part of Security Operations Center (SOC) work, threat hunting, and incident response.

1. Forensic log analysis: isolate SSH brute-force attempts with `grep "Failed password" /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | sort -nr`; detect automated web scanners with `grep -E "nikto|sqlmap|nmap|dirbuster" /var/log/apache2/access.log`; extract the top offending IP addresses with `awk '{print $1}' /var/log/nginx/access.log | sort | uniq -c | sort -nr | head -10`.
2. Credential and secret hunting: scan a web root or project tree for exposed passwords or keys with `grep -rnwiE "password|secret|apikey|access_token|db_pass" /var/www/ 2>/dev/null`.
3. Privilege escalation with text-processing binaries (see GTFOBins): `awk` can spawn a shell with `awk 'BEGIN {system("/bin/sh")}'`; `sed` can read a protected file with `sed -e '1w /dev/stdout' -e 1d /etc/shadow`; `cut` can read a protected file line by line with `cut -d "" -f1 /etc/shadow`; `less` and `more` can be escaped to a shell with `!/bin/sh`.

```bash
# ── ADVANCED LOG PARSING ONE-LINERS ──────────────────────────

# Extract all unique IPv4 addresses from auth.log
$ grep -oE '([0-9]{1,3}\.){3}[0-9]{1,3}' /var/log/auth.log | sort -u

# Find top 5 HTTP 404 targets (directory fuzzing detection)
$ awk '($9 ~ /404/)' /var/log/apache2/access.log | awk '{print $7}' | sort | uniq -c | sort -nr | head -5

# GTFOBins Sudo Awk Root Shell
$ sudo awk 'BEGIN {system("/bin/sh")}'
```

## Quick Reference Cheatsheet

```bash
# View files
more file.txt          # paged, stays in terminal
less file.txt          # paged, scrollable, clean exit
head -n 10 file.txt    # first 10 lines
tail -n 10 file.txt    # last 10 lines
tail -f file.txt       # real-time follow

# Filter & search
grep "pattern" file.txt          # search for pattern
grep -v "pattern" file.txt       # exclude pattern
grep -i "pattern" file.txt       # case-insensitive

# Transform
sort file.txt                    # sort A-Z
sort -r file.txt                 # sort Z-A
cut -d":" -f1 file.txt           # extract column 1
tr ":" " " < file.txt            # replace char
column -t file.txt               # table format

# Advanced
awk '{print $1, $NF}' file.txt   # print first & last column
sed 's/old/new/g' file.txt       # substitute text globally
wc -l file.txt                   # count lines
```
