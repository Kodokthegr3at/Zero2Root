## Key Terms

You'll see these words throughout the lesson.

| Term | Plain meaning |
|:---|:---|
| Prompt | The text shown before each command, like `user@host:~$` |
| PS1 | The variable that defines what the prompt looks like |
| Escape sequence | A code like `\u` or `\w` that PS1 expands into live info (user, path) |
| Environment variable | A named value the shell keeps, such as `PS1` or `PATH` |
| ANSI color code | Special codes that color the prompt text |
| PROMPT_COMMAND | A command Bash runs right before showing each prompt |
| `.bashrc` | The shell config file where you make prompt settings permanent |

## 1. Bash Prompt Basics

The Bash prompt is a line of text that appears in the terminal to let us know the system is ready to receive commands. By default, it displays the following information.

- Username: who is currently logged in.
- Hostname: the name of the computer/machine.
- Current directory: the active folder.

After the prompt appears, the cursor (a blinking line or box) waits for us to type a command.

---

## 2. Prompt Structure

The default bash prompt format follows a consistent, easy-to-understand pattern.

### Default Format

```
<username>@<hostname><current working directory>$
```

### Anatomy

```
cry0l1t3  @  htb  [~]  $
    │     │   │    │    │
    │     │   │    │    └── $ = regular user  |  # = root user
    │     │   │    └─────── current directory (~ = home)
    │     │   └──────────── hostname (machine name)
    │     └──────────────── separator
    └────────────────────── username
```

### Real Examples

```bash
# Standard user in home directory
cry0l1t3@htb[~]$

# Standard user in a different directory
cry0l1t3@htb[/etc/ssh]$

# Root user
root@htb[/htb]#

# Minimal prompt (when PS1 not set — common in reverse shells)
$       ← unprivileged user
#       ← root / privileged
```

Note: the tilde `~` always refers to the home directory of the logged-in user. For example, `~` equals `/home/cry0l1t3` for a regular user, or `/root` for root.

## 3. User vs Root Prompt

The easiest way to tell whether we're logged in as a regular user or root is to look at the last character of the prompt.

- `$` means a regular user (unprivileged).
- `#` means root / superuser (privileged).

This distinction matters during penetration testing. A `#` character means we've achieved root access.

```bash
# Regular user prompt
cry0l1t3@htb[~]$  ← $ = normal user, limited privileges

# Root prompt
root@htb[/htb]#   ← # = root, FULL system access

# Minimal shell (e.g. after exploit / reverse shell)
$   ← still a user shell
#   ← got root! privilege escalation successful
```

Pentesting note: when running a reverse shell on a target, we might only see `$` or `#` with no username/hostname. This happens because the PS1 variable hasn't been set properly in that shell session.

## 4. PS1 Variable

PS1 (Prompt String 1) is an environment variable in Linux that controls how the command prompt looks. PS1 works like a template that defines the text shown every time the system is ready for a command.

By customizing PS1, we can display additional useful information, such as:

- The machine's or target's IP address.
- Date and time.
- The success/failure status of the last command.
- The full path of the current directory.

This is especially useful during penetration testing, since it helps track activity and document work more effectively.

```bash
# Check current PS1 value
$ echo $PS1
\[\u@\h \W\]\$

# Temporarily change PS1 in current session
$ PS1="[\u@\h \w] $ "

# Permanently change in ~/.bashrc
$ nano ~/.bashrc
# Add/modify PS1 line, then:
$ source ~/.bashrc
```

---

## 5. PS1 Special Characters

PS1 uses special characters prefixed with a backslash `\` to automatically display dynamic information.

| Character | Description | Example Output |
|-----------|-------------|-----------------|
| `\u` | Current username | `cry0l1t3` |
| `\h` | Hostname (up to first dot) | `htb` |
| `\H` | Full hostname | `htb.local` |
| `\w` | Full path of current directory | `/home/user/docs` |
| `\W` | Current directory name only | `docs` |
| `\d` | Date (Mon Feb 6) | `Mon Feb  6` |
| `\D{%Y-%m-%d}` | Date in YYYY-MM-DD format | `2025-06-01` |
| `\t` | Time, 24-hour (HH:MM:SS) | `14:32:10` |
| `\T` | Time, 12-hour (HH:MM:SS) | `02:32:10` |
| `\@` | Time, 12-hour (AM/PM) | `02:32 PM` |
| `\s` | Name of the shell | `bash` |
| `\j` | Number of background jobs | `2` |
| `\n` | Newline | ↵ |
| `\$` | `$` for user, `#` for root | `$` or `#` |

## 6. Prompt Customization Examples

PS1 is configured in the `~/.bashrc` file. Permanent changes must be added to this file and sourced to take effect immediately.

### Preset Examples

```bash
# ── MINIMAL (clean and simple) ──────────────────────
PS1="[\u@\h \W]\$ "
# Output: [cry0l1t3@htb ~]$

# ── WITH FULL PATH ───────────────────────────────────
PS1="[\u@\h \w]\$ "
# Output: [cry0l1t3@htb /home/cry0l1t3/documents]$

# ── WITH DATE & TIME ─────────────────────────────────
PS1="[\D{%Y-%m-%d} \t] \u@\h:\w\$ "
# Output: [2025-06-01 14:32:10] cry0l1t3@htb:~$

# ── PENTESTING PROMPT (with IP tracking) ─────────────
PS1="[\u@\h - $(hostname -I | awk '{print $1}')] \w\$ "
# Output: [cry0l1t3@htb - 10.10.14.5] /home/cry0l1t3$

# ── WITH COLOR (green user, blue path) ───────────────
PS1="\[\033[01;32m\]\u@\h\[\033[00m\]:\[\033[01;34m\]\w\[\033[00m\]\$ "
# Output: cry0l1t3@htb:/home/cry0l1t3$  (colored)
```

### Color Codes Reference

```bash
# Format: \[\033[<code>m\]...\[\033[00m\]
#                    └── color code

# Text Colors
\[\033[30m\]   # Black
\[\033[31m\]   # Red
\[\033[32m\]   # Green
\[\033[33m\]   # Yellow
\[\033[34m\]   # Blue
\[\033[35m\]   # Purple
\[\033[36m\]   # Cyan
\[\033[37m\]   # White

# Bold versions
\[\033[01;32m\]  # Bold Green
\[\033[01;34m\]  # Bold Blue
\[\033[01;31m\]  # Bold Red

# Reset
\[\033[00m\]   # Reset to default
```

### How to Apply Permanently

```bash
# 1. Open .bashrc
$ nano ~/.bashrc

# 2. Find or add the PS1 line at the bottom:
PS1="[\D{%Y-%m-%d} \t] \u@\h:\w\$ "

# 3. Save and apply without restarting terminal
$ source ~/.bashrc
# or
$ . ~/.bashrc
```

### Pentesting Workflow: Recording Commands

```bash
# Record all commands with timestamps using script
$ script -a -t 2>~/pentest_timing.txt ~/pentest_log.txt

# View bash history with timestamps
$ export HISTTIMEFORMAT="%F %T "
$ history

# Bash history file location
$ cat ~/.bash_history
```

Note: setting a custom PS1 with date/time, combined with logging via `script`, is good practice during pentests. It automatically documents every command with a timestamp for reporting purposes.

## Quick Reference Cheatsheet

```bash
# ── CHECK CURRENT PROMPT ─────────────────────────────
echo $PS1                    # show current PS1 value
echo $0                      # show current shell

# ── IDENTIFY USER LEVEL ──────────────────────────────
whoami                       # current username
id                           # UID, GID, groups
# $ at end = regular user
# # at end = root

# ── TEMPORARY CHANGE ─────────────────────────────────
PS1="[\u@\h \w]\$ "         # change for current session only

# ── PERMANENT CHANGE ─────────────────────────────────
echo 'PS1="[\u@\h \w]\$ "' >> ~/.bashrc
source ~/.bashrc

# ── COMMON PS1 PRESETS ───────────────────────────────
# Minimal:     PS1="[\u@\h \W]\$ "
# Full path:   PS1="[\u@\h \w]\$ "
# With time:   PS1="[\t] \u@\h:\w\$ "
# Pentesting:  PS1="[\D{%Y-%m-%d} \t] \u@\h \w\$ "

# ── RECORD COMMANDS (pentest documentation) ──────────
script -a ~/session.log      # start recording
exit                         # stop recording
export HISTTIMEFORMAT="%F %T "  # add timestamps to history
```
