## 1. OS & Kernel Identification

Gathering operating system and kernel information is the first step in systems administration and penetration testing reconnaissance. These commands reveal the distribution release, kernel version, and CPU architecture.

- `uname -a`: displays complete kernel information (kernel version, build timestamp, architecture, hostname).
- `/etc/os-release` / `/etc/issue`: files defining the official distribution name and version (Ubuntu, Debian, Kali, CentOS).
- `hostnamectl`: outputs a unified summary of hostname, chassis, kernel release, and architecture on `systemd` distributions.

```bash
# ── KERNEL & OS VERSION CHECK ────────────────────────────────
$ uname -a
Linux htb-target 5.15.0-78-generic #85-Ubuntu SMP Fri Jul 7 15:25:09 UTC 2023 x86_64 x86_64 x86_64 GNU/Linux

$ uname -r      # Kernel release only (e.g., 5.15.0-78-generic)
$ uname -m      # Machine architecture (e.g., x86_64 / aarch64)

# ── DISTRO INFORMATION ───────────────────────────────────────
$ cat /etc/os-release
NAME="Ubuntu"
VERSION="22.04.3 LTS (Jammy Jellyfish)"
ID=ubuntu
ID_LIKE=debian
VERSION_ID="22.04"

$ hostnamectl
```

## 2. Hardware, CPU & Memory

The Linux kernel exposes hardware status and resource consumption through the `/proc` virtual filesystem.

- `lscpu`: detailed processor architecture, core counts, threads per core, virtualization flags, and CPU cache topology.
- `free -h`: physical RAM and swap utilization in human-readable units (`-h`).
- `/proc/cpuinfo` & `/proc/meminfo`: raw kernel data detailing hardware specifications.

```bash
# ── CPU SPECIFICATIONS ───────────────────────────────────────
$ lscpu
Architecture:            x86_64
  CPU op-mode(s):        32-bit, 64-bit
  Address sizes:         39 bits physical, 48 bits virtual
  Byte Order:            Little Endian
  CPU(s):                4
  Model name:            Intel(R) Core(TM) i7-10700K CPU @ 3.80GHz

# ── MEMORY CONSUMPTION ───────────────────────────────────────
$ free -h
               total        used        free      shared  buff/cache   available
Mem:           7.7Gi       2.1Gi       3.4Gi       120Mi       2.2Gi       5.2Gi
Swap:          2.0Gi          0B       2.0Gi
```

## 3. Disks & Filesystems

- `lsblk`: lists all block storage devices (SATA disks, NVMe, USB volumes, virtual loop devices) in a tree structure alongside their mountpoints.
- `df -h`: reports disk space allocation and capacity across all mounted filesystems.
- `du -sh <directory>`: total disk space consumed by a target directory or file.
- `fdisk -l` / `parted -l`: raw partition tables (requires root privileges).

```bash
# ── BLOCK DEVICES TREE ───────────────────────────────────────
$ lsblk
NAME   MAJ:MIN RM   SIZE RO TYPE MOUNTPOINTS
sda      8:0    0    50G  0 disk 
├─sda1   8:1    0     1M  0 part 
├─sda2   8:2    0     2G  0 part /boot
└─sda3   8:3    0    48G  0 part /

# ── DISK FREE SPACE ──────────────────────────────────────────
$ df -h /
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda3        48G   12G   34G  27% /

# ── DIRECTORY SIZE CALCULATION ───────────────────────────────
$ du -sh /var/log/
1.4G	/var/log/
```

## 4. Network Interfaces & Hostname

- `ip addr` / `ip a`: network interfaces with their IPv4/IPv6 addresses and MAC identifiers (the modern successor to `ifconfig`).
- `ip route` / `ip r`: the kernel routing table and default gateway address.
- `hostname -I`: a concise list of all assigned host IP addresses.
- `/etc/resolv.conf`: the DNS nameservers used by local resolvers.
- `/etc/hosts`: a static hostname-to-IP mapping file, checked before DNS queries.

```bash
# ── INSPECT NETWORK INTERFACES ───────────────────────────────
$ ip -br a
lo               UNKNOWN        127.0.0.1/8 ::1/128 
eth0             UP             10.10.14.25/24 fe80::250:56ff:fe9d:8b2a/64 
tun0             UP             10.10.10.50/32 

# ── ROUTING & DNS ────────────────────────────────────────────
$ ip route
default via 10.10.14.1 dev eth0 proto dhcp src 10.10.14.25 metric 100 

$ cat /etc/resolv.conf
nameserver 1.1.1.1
nameserver 8.8.8.8
```

## 5. Open Files & Sockets (`lsof`)

In Linux, everything is a file. The `lsof` utility (List Open Files) lists all files, pipes, devices, and network sockets currently held open by running processes.

- `lsof -i`: active network connections and open ports.
- `lsof -i :80`: finds which process is bound to port 80.
- `lsof -u <username>`: files currently opened by a specific user account.
- `ss -tulnp`: listening TCP/UDP sockets along with the PID of the owning process.

```bash
# ── LIST OPEN NETWORK CONNECTIONS ────────────────────────────
$ sudo lsof -i -P -n
COMMAND    PID     USER   FD   TYPE DEVICE SIZE/OFF NODE NAME
sshd       892     root    3u  IPv4  24110      0t0  TCP *:22 (LISTEN)
sshd       892     root    4u  IPv6  24112      0t0  TCP *:22 (LISTEN)
apache2   1245 www-data    4u  IPv4  28901      0t0  TCP *:80 (LISTEN)

# ── LISTENING PORTS USING SS ─────────────────────────────────
$ ss -tulnp
Netid State  Recv-Q Send-Q Local Address:Port  Peer Address:PortProcess
tcp   LISTEN 0      128          0.0.0.0:22         0.0.0.0:*    users:(("sshd",pid=892,fd=3))
tcp   LISTEN 0      511          0.0.0.0:80         0.0.0.0:*    users:(("apache2",pid=1245,fd=4))
```

## 6. Environment Variables

Environment variables are dynamic key-value pairs used by the system and applications to determine execution configuration.

- `$PATH`: the colon-separated list of directories searched when executing binaries without absolute paths.
- `$USER` & `$HOME`: the active username and home directory path.
- `env` / `printenv`: prints all environment variables active in the current session.
- `export VAR="value"`: sets a new variable and exports it to every child process spawned from that shell.

```bash
# ── INSPECT ENVIRONMENT ──────────────────────────────────────
$ echo $PATH
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin

$ echo $USER $HOME
htb-student /home/htb-student

# Set temporary environment variable
$ export TARGET_IP="10.10.10.100"
$ ping -c 1 $TARGET_IP
```

## 7. Security Note: Kernel Exploits, Local Recon & Environment Poisoning

In Linux penetration testing (HTB Academy Module 18 & The Hacker Playbook 3), system information is the foundation for local exploitation.

1. Kernel exploit mapping. Older kernel versions revealed by `uname -r` often carry documented Local Privilege Escalation (LPE) vulnerabilities, for example Dirty COW (CVE-2016-5195), Dirty Pipe (CVE-2022-0847), OverlayFS (CVE-2021-3493), or PwnKit (CVE-2021-4034). Query offline vulnerability archives with `searchsploit linux kernel <version>`.
2. `$PATH` hijacking / environment poisoning. When a SUID binary or cron job invokes a command without an absolute path (calling `curl` instead of `/usr/bin/curl`, for example), an attacker can prepend a malicious directory to `$PATH` (`export PATH=/tmp:$PATH`) to get code execution as root.
3. Internal port enumeration. `ss -tulnp` or `netstat -tlpn` can reveal local services listening only on `127.0.0.1` (an internal MySQL database, Redis, or a web admin backend, for example), which may be pivoted to or exploited directly.

```bash
# ── PENTESTING SYSTEM RECONNAISSANCE SCRIPT ──────────────────
# 1. OS & Architecture check
uname -a; cat /etc/*release 2>/dev/null

# 2. Search for kernel exploits with searchsploit
searchsploit "Linux Kernel $(uname -r | cut -d'-' -f1)"

# 3. Check internal listening services
ss -tulnp | grep -E "127.0.0.1|::1"

# 4. Check for writable directories in PATH
echo $PATH | tr ":" "\n" | while read dir; do [ -w "$dir" ] && echo "[!] Writable PATH: $dir"; done
```

## 8. Quick Reference Cheatsheet

```bash
# ── SYSTEM & KERNEL ──────────────────────────────────────────
uname -a                               # full kernel & architecture
uname -r                               # kernel release version
cat /etc/os-release                    # Linux distribution details
hostname -I                            # all host IP addresses

# ── HARDWARE & RESOURCES ─────────────────────────────────────
lscpu                                  # CPU architecture details
free -h                                # RAM & Swap memory usage
lsblk                                  # list block devices & mounts
df -h                                  # free disk space per partition
du -sh /path/dir                       # directory disk usage

# ── NETWORK & SOCKETS ────────────────────────────────────────
ip -br a                               # brief network interfaces list
ip route                               # routing table & default gateway
ss -tulnp                              # listening TCP/UDP ports with PID
sudo lsof -i -P -n                     # active network connections & files

# ── ENVIRONMENT ──────────────────────────────────────────────
env                                    # print all environment variables
echo $PATH                             # print execution search path
export VAR="value"                     # set environment variable
```
