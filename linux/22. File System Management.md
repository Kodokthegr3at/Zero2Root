## 1. 🧱 Linux Storage Stack — From Disk to Directory Tree

### 🇮🇩 Bahasa Indonesia
Data disimpan pada **block device** (disk, LV, loop), diformat dengan **file system**, lalu di-**mount** ke direktori dalam single tree (`/`).

$$
\text{Hardware} \rightarrow \text{Partition/LV} \xrightarrow{\texttt{mkfs}} \text{FS superblock} \xrightarrow{\texttt{mount}} \texttt{/mountpoint}
$$

### 🇬🇧 English
Administrators work with **`lsblk`** for topology, **`blkid`** for UUIDs/types, and **`/etc/fstab`** for boot persistence. Wrong fstab entries can prevent boot — always test with `mount -a`.

### 日本語
ブロックデバイスをフォーマットし、単一のディレクトリツリーへマウントします。構成確認は `lsblk` / `blkid`、永続化は `/etc/fstab` です。誤った fstab は起動不能の原因になるため `mount -a` で必ず検証します。

```
/dev/nvme0n1
 ├─ nvme0n1p1  →  /boot/efi   (vfat)
 ├─ nvme0n1p2  →  /boot       (ext4)
 └─ nvme0n1p3  →  LVM PV
                      ├─ vg0-root → /       (ext4)
                      ├─ vg0-home → /home  (ext4)
                      └─ vg0-swap → [swap]
```

| Layer | Tools | Key files |
|:---|:---|:---|
| Discovery | `lsblk`, `fdisk -l`, `parted -l` | `/dev/*` |
| Format | `mkfs.ext4`, `mkfs.xfs`, `mkswap` | FS superblock |
| Mount | `mount`, `umount`, `findmnt` | `/etc/fstab`, `/proc/mounts` |
| LVM | `pvcreate`, `vgcreate`, `lvcreate` | `/etc/lvm/` metadata |

## 2. 🧩 Partitioning — MBR, GPT, `fdisk` & `parted`

### 🇮🇩 Bahasa Indonesia
Disk modern memakai **GPT** (GUID Partition Table); legacy **MBR** masih ada di VM lama. **`fdisk`** (interactive) dan **`parted`** (scriptable) adalah alat standar.

### 🇬🇧 English
Always confirm the device name (`/dev/sdb` vs `/dev/sda`) before destructive ops. Use **`partprobe`** or reboot after partition table changes.

### 日本語
現行ディスクは GPT、古い VM は MBR が多いです。破壊的操作の前にデバイス名を必ず確認し、テーブル変更後は `partprobe` か再起動でカーネルに反映します。

```bash
# Topology
lsblk -f
sudo fdisk -l
sudo parted -l

# GPT partition with parted (example — DESTRUCTIVE on wrong disk)
sudo parted /dev/sdb --script mklabel gpt
sudo parted /dev/sdb --script mkpart primary ext4 1MiB 100%
sudo partprobe /dev/sdb

# Interactive fdisk
sudo fdisk /dev/sdb    # n=new, p=print, w=write, q=quit
```

| Scheme | Max partitions | Boot firmware | Notes |
|:---|:---:|:---|:---|
| MBR | 4 primary (+ extended) | BIOS | Legacy |
| GPT | Very large | UEFI | Preferred today |

## 3. 📂 File System Types — ext4, XFS & swap

### 🇮🇩 Bahasa Indonesia
Pilih FS sesuai beban: **ext4** umum, **XFS** file besar / default RHEL, **vfat** untuk ESP, **swap** untuk memori virtual.

| FS | Typical use | Create |
|:---|:---|:---|
| **ext4** | General purpose root/home | `mkfs.ext4` |
| **XFS** | Large files / RHEL default | `mkfs.xfs` |
| **vfat** | EFI System Partition | `mkfs.vfat -F 32` |
| **swap** | Virtual memory / hibernation | `mkswap` |

### 🇬🇧 English
Label or note **UUID** for fstab — device names (`/dev/sda1`) can reorder after hardware changes.

### 日本語
`/etc/fstab` ではデバイス名ではなく **UUID** を使います。ハードウェア追加で `/dev/sdX` の番号が変わるためです。

```bash
sudo mkfs.ext4 -L datavol /dev/sdb1
sudo mkfs.xfs /dev/vg0/lv_data
sudo mkswap /dev/vg0/lv_swap
sudo swapon /dev/vg0/lv_swap

blkid
lsblk -f
```

## 4. 📌 Mount, Umount & `/etc/fstab`

### 🇮🇩 Bahasa Indonesia
**`mount`** menempelkan FS ke direktori kosong. **`/etc/fstab`** mendefinisikan mount otomatis saat boot.

Format fstab:

$$
\text{device} \quad \text{mountpoint} \quad \text{type} \quad \text{options} \quad \text{dump} \quad \text{fsck}
$$

### 🇬🇧 English
Use **`nofail`** for non-critical removable media on servers. Use **`UUID=`** over `/dev/sdX`. Test: `sudo mount -a`.

### 日本語
fstab 変更後は必ず `mount -a` で検証します。取り外し可能な非クリティカル媒体には `nofail` を付け、起動停止を防ぎます。

```bash
# Manual mount
sudo mkdir -p /mnt/data
sudo mount /dev/sdb1 /mnt/data
findmnt /mnt/data
mount | grep /mnt/data

# Umount (busy → stop processes using path)
sudo umount /mnt/data
sudo fuser -vm /mnt/data

# /etc/fstab example
# UUID=abc-123-def   /mnt/data   ext4   defaults,nofail   0   2
sudo mount -a          # apply fstab without reboot
```

| Mount option | Effect |
|:---|:---|
| `defaults` | rw, suid, dev, exec, auto, nouser, async |
| `noexec` | Block execution from mount (upload dirs) |
| `nosuid` | Ignore setuid bits on FS |
| `nodev` | Ignore device files on FS |
| `ro` | Read-only |
| `nofail` | Boot continues if mount fails |

## 5. 📦 LVM — Logical Volume Manager

### 🇮🇩 Bahasa Indonesia
**LVM** adalah abstraksi di atas partition:

$$
\text{PV (Physical Volume)} \rightarrow \text{VG (Volume Group)} \rightarrow \text{LV (Logical Volume)}
$$

Keuntungan: resize online, snapshots, striping (advanced).

### 🇬🇧 English
Workflow: partition type `8e` (MBR) or GPT `8300` Linux LVM → `pvcreate` → `vgcreate` → `lvcreate` → `mkfs` → mount.

### 日本語
PV → VG → LV の順で積み上げ、必要ならオンラインで拡張します。ext4 は `resize2fs`、XFS は `xfs_growfs` でファイルシステムを伸ばします。

```bash
# Create stack (lab disk /dev/sdb1 prepared)
sudo pvcreate /dev/sdb1
sudo vgcreate vg_data /dev/sdb1
sudo lvcreate -L 50G -n lv_archive vg_data
sudo mkfs.ext4 /dev/vg_data/lv_archive
sudo mkdir -p /archive
echo '/dev/vg_data/lv_archive  /archive  ext4  defaults  0  2' | sudo tee -a /etc/fstab
sudo mount -a

# Extend LV + filesystem (ext4)
sudo lvextend -L +20G /dev/vg_data/lv_archive
sudo resize2fs /dev/vg_data/lv_archive

# Inspect
pvs; vgs; lvs
sudo lvdisplay
```

| Command | Purpose |
|:---|:---|
| `pvcreate` | Init partition as PV |
| `vgcreate` | Group PVs into VG |
| `lvcreate` | Allocate LV from VG |
| `lvextend` / `lvreduce` | Resize LV |
| `resize2fs` / `xfs_growfs` | Grow FS to fill LV |

## 6. 📊 Capacity, Usage & Integrity

### 🇮🇩 Bahasa Indonesia
- **`df -hT`** — ruang bebas per mount.
- **`du -sh`** — ukuran direktori.
- **`fsck`** — periksa/perbaiki FS (**unmount dulu**, kecuali root dengan care).

### 🇬🇧 English
Monitor inode exhaustion (`df -i`) on mail/cache servers. Schedule filesystem checks via the fstab pass field or systemd timers.

### 日本語
空き容量は `df`、ディレクトリサイズは `du`、整合性は **アンマウント後の `fsck`** です。inode 枯渇は `df -i` で監視します。

```bash
df -hT
df -i
du -sh /var/log/* 2>/dev/null | sort -h | tail

# Offline check (FS must be unmounted)
sudo umount /dev/sdb1
sudo fsck -f /dev/sdb1

# Find large files quickly
sudo find /var -xdev -type f -size +100M -ls 2>/dev/null | head
```

## 7. 🔐 Security Notes — DEFENSE / Privilege Paths

### 🇮🇩 Bahasa Indonesia
Opsi mount (`noexec`, `nosuid`, `nodev`) adalah kontrol keamanan, bukan kosmetik. Direktori unggahan dan share jaringan harus dikunci.

### 🇬🇧 English
World-writable mounts with `exec` are a classic webshell drop path. Keep `/etc/fstab` root-owned `644` and treat remote NFS/SMB content as untrusted.

### 日本語
アップロード領域は `noexec,nosuid,nodev` を付け、NFS/SMB の内容をローカル同等に信頼しません。`/etc/fstab` は root 所有の `644` に保ちます。

| Risk | Mechanism | Defense |
|:---|:---|:---|
| World-writable mount + `exec` | Drop webshells on `/mnt/uploads` | `noexec,nosuid,nodev` |
| NFS/SMB mount as root | Remote content trusted like local | `nosuid,nodev`; network ACLs |
| `/etc/fstab` writable by users | Boot-time root compromise | root-owned `644`; config management |
| Full disk | Log/cache fill → DoS | Quotas; logrotate; alerts on `df` |
| LVM snapshot abuse (admin) | Forensic copies of sensitive LV | RBAC on LVM commands |

```bash
# Defensive mount audit
findmnt -lo TARGET,OPTIONS,SOURCE
grep -v '^#' /etc/fstab
mount | grep -E 'nosuid|noexec'
```

## 8. 🧠 Quick Reference Cheatsheet

```bash
# Discovery
lsblk -f
blkid
sudo fdisk -l

# Format & swap
sudo mkfs.ext4 /dev/sdb1
sudo mkswap /dev/sdb2 && sudo swapon /dev/sdb2

# Mount
sudo mount /dev/sdb1 /mnt/data
sudo umount /mnt/data
sudo mount -a

# LVM
sudo pvcreate /dev/sdb1
sudo vgcreate vg0 /dev/sdb1
sudo lvcreate -L 10G -n lv0 vg0
pvs && vgs && lvs

# Space
df -hT
du -sh /path
```
