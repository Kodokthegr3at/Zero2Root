## 1. Overview: Mengapa User Management Penting

User management adalah aspek fundamental dari administrasi sistem Linux. Administrator sering perlu membuat akun user baru untuk anggota tim, menambahkan user ke grup tertentu untuk kontrol akses, dan menjalankan perintah sebagai user berbeda untuk tugas yang membutuhkan privilege berbeda.

Dari perspektif cybersecurity, memahami user management penting untuk mengidentifikasi peluang privilege escalation, menemukan permission yang salah konfigurasi, dan melakukan auditing serta troubleshooting sistem.

### File `/etc/shadow`

```bash
# Regular user — CANNOT read /etc/shadow
$ cat /etc/shadow
cat: /etc/shadow: Permission denied

# With sudo — CAN read /etc/shadow
$ sudo cat /etc/shadow
root:<SNIP>:18395:0:99999:7:::
daemon:*:17737:0:99999:7:::
bin:*:17737:0:99999:7:::
```

> `/etc/shadow` menyimpan hash password terenkripsi untuk semua akun user. File ini hanya bisa dibaca/ditulis oleh root untuk mencegah akses tidak sah ke data autentikasi.

## 2. `sudo`, Jalankan sebagai User Lain

`sudo` (superuser do) memungkinkan user yang diizinkan untuk menjalankan perintah dengan hak akses user lain, biasanya root. Ini adalah cara aman untuk melakukan tugas administratif tanpa perlu login sebagai root secara langsung, sebuah praktik terbaik keamanan sistem.

```bash
# Run a single command as root
$ sudo cat /etc/shadow

# Run command as specific user
$ sudo -u alex cat /home/alex/secret.txt

# Open a root shell
$ sudo -s
$ sudo su

# Check what sudo privileges current user has
$ sudo -l

# Run with environment preserved
$ sudo -E command
```

> Catatan pentesting: `sudo -l` adalah salah satu perintah pertama yang dijalankan setelah mendapat akses ke sebuah sistem. Perintah ini mengungkap perintah apa saja yang bisa dijalankan dengan hak akses tinggi tanpa perlu tahu password root.

## 3. `su`, Ganti User

`su` (switch user) dipakai untuk beralih ke sesi user lain secara penuh. Berbeda dengan `sudo` yang hanya menjalankan satu perintah, `su` membuka shell baru sebagai user target. Membutuhkan password user tujuan (kecuali dijalankan oleh root).

```bash
# Switch to root (requires root password)
$ su
Password:
root@hostname#

# Switch to specific user
$ su alex
Password:
alex@hostname$

# Switch with full login environment (recommended)
$ su - alex

# Switch to root with login environment
$ su -
```

### `su` vs `sudo`: Perbedaan Utama

```
sudo command          →  runs ONE command as root, then back to your user
su                    →  opens a NEW SHELL as another user (stays until exit)
su -                  →  full login shell (loads target user's env variables)
sudo su               →  switch to root shell using sudo privileges
```

## 4. `useradd`, Buat User Baru

`useradd` dipakai untuk membuat akun user baru. Saat user dibuat, sistem secara otomatis membuat direktori home, menetapkan UID, dan mengatur konfigurasi default dari `/etc/default/useradd`.

```bash
# Create a basic new user
$ sudo useradd alex

# Create user WITH home directory (-m) and default shell (-s)
$ sudo useradd -m -s /bin/bash alex

# Create user with specific UID (-u) and GID (-g)
$ sudo useradd -m -u 1500 -g developers alex

# Create user with comment/description (-c)
$ sudo useradd -m -c "Alex - Developer" alex

# Create user and add to supplementary groups (-G)
$ sudo useradd -m -G sudo,docker alex

# Create system user (no home dir, for services)
$ sudo useradd --system --no-create-home serviceaccount
```

| Flag | Fungsi |
|------|--------|
| `-m` | Buat direktori home |
| `-s` | Set default shell |
| `-u` | Set UID spesifik |
| `-g` | Set primary group |
| `-G` | Tambah ke supplementary groups |
| `-c` | Tambah komentar/deskripsi |
| `-e` | Set tanggal kadaluarsa akun |

## 5. `userdel`, Hapus User

`userdel` dipakai untuk menghapus akun user dari sistem. Gunakan flag `-r` untuk menghapus direktori home dan mail spool sekaligus. Tanpa `-r`, file user tetap tersisa di filesystem.

```bash
# Delete user only (home directory remains)
$ sudo userdel alex

# Delete user AND their home directory + mail spool
$ sudo userdel -r alex

# Force delete even if user is logged in
$ sudo userdel -f alex
```

> Selalu gunakan `userdel -r` dengan hati-hati. Perintah ini menghapus permanen direktori home user beserta semua file di dalamnya.

## 6. `usermod`, Modifikasi User

`usermod` dipakai untuk memodifikasi akun user yang sudah ada. Ini adalah tool paling fleksibel untuk mengelola user, bisa mengubah username, shell, grup, direktori home, dan lain-lain.

```bash
# Add user to a supplementary group
$ sudo usermod -aG docker alex
#                  ↑
#                  -a = append (IMPORTANT: without -a, existing groups are REPLACED)

# Add user to multiple groups
$ sudo usermod -aG sudo,docker,developers alex

# Change user's primary group
$ sudo usermod -g developers alex

# Change username
$ sudo usermod -l newname alex

# Change home directory
$ sudo usermod -d /new/home alex

# Change default shell
$ sudo usermod -s /bin/zsh alex

# Lock a user account
$ sudo usermod -L alex

# Unlock a user account
$ sudo usermod -U alex

# Set account expiry date
$ sudo usermod -e 2025-12-31 alex
```

> Penting: selalu gunakan `-aG` (append + group), jangan pernah `-G` saja. Memakai `-G` tanpa `-a` akan menghapus user dari semua grup lain terlebih dahulu.

---

## 7. `addgroup`, Tambah Grup

`addgroup` dipakai untuk membuat grup baru di sistem. Grup dipakai untuk mengelola akses ke file dan direktori secara kolektif, semua anggota grup berbagi permission yang sama.

```bash
# Create a new group
$ sudo addgroup developers

# Create group with specific GID
$ sudo addgroup --gid 1500 developers

# Add existing user to existing group
$ sudo addgroup alex developers
```

---

## 8. `delgroup`, Hapus Grup

`delgroup` dipakai untuk menghapus grup dari sistem. Grup tidak bisa dihapus jika masih ada user yang memakainya sebagai primary group.

```bash
# Remove a group
$ sudo delgroup developers

# Remove user from a group (without deleting the group)
$ sudo delgroup alex developers
```

---

## 9. `passwd`, Ubah Password

`passwd` dipakai untuk mengubah password user. User biasa hanya bisa mengubah password mereka sendiri, sedangkan root bisa mengubah password siapa pun tanpa perlu tahu password lama.

```bash
# Change YOUR OWN password
$ passwd

# Change another user's password (requires root)
$ sudo passwd alex

# Lock a user's password (disable login)
$ sudo passwd -l alex

# Unlock a user's password
$ sudo passwd -u alex

# Force user to change password on next login
$ sudo passwd -e alex

# Check password status
$ sudo passwd -S alex
```

## File Sistem Kunci

| File | Isi |
|------|-----|
| `/etc/passwd` | Daftar semua user (username, UID, GID, home, shell) |
| `/etc/shadow` | Hash password terenkripsi (hanya root) |
| `/etc/group` | Daftar semua grup dan anggotanya |
| `/etc/sudoers` | Konfigurasi hak sudo per user/grup |

## Contoh Alur Kerja Praktis

```bash
# Create new employee "alex" with full setup
$ sudo useradd -m -s /bin/bash -c "Alex - Developer" alex

# Set password
$ sudo passwd alex

# Add to necessary groups
$ sudo usermod -aG sudo,docker,developers alex

# Verify
$ id alex
uid=1001(alex) gid=1001(alex) groups=1001(alex),27(sudo),998(docker),1500(developers)

# Check home directory was created
$ ls -la /home/alex/

# Later: lock account if employee leaves
$ sudo passwd -l alex
$ sudo usermod -e 2025-01-01 alex
```

## Cheatsheet Referensi Cepat

```bash
# ── CREATE ──────────────────────────────────────────────
sudo useradd -m -s /bin/bash username    # create user + home
sudo passwd username                      # set password
sudo addgroup groupname                   # create group
sudo usermod -aG groupname username       # add user to group

# ── READ / CHECK ────────────────────────────────────────
id username                               # show UID, GID, groups
whoami                                    # current user
groups username                           # show user's groups
cat /etc/passwd | grep username           # user info
sudo cat /etc/shadow | grep username      # password hash
sudo -l                                   # check sudo privileges

# ── MODIFY ──────────────────────────────────────────────
sudo usermod -aG group user               # add to group (SAFE)
sudo usermod -s /bin/zsh username         # change shell
sudo usermod -L username                  # lock account
sudo usermod -U username                  # unlock account
sudo passwd -e username                   # force pw change on login

# ── DELETE ──────────────────────────────────────────────
sudo userdel -r username                  # delete user + home
sudo delgroup groupname                   # delete group

# ── PRIVILEGE ESCALATION CHECK (pentesting) ─────────────
sudo -l                                   # what can I sudo?
cat /etc/passwd                           # list all users
cat /etc/group                            # list all groups
find / -perm -4000 2>/dev/null            # find SUID files
```
