## 1. `pwd` (Print Working Directory)

`pwd` dipakai untuk mengetahui posisi direktori kita saat ini di dalam filesystem. Ini adalah perintah pertama yang sebaiknya dijalankan saat baru masuk ke sebuah sistem, supaya kita tahu sedang berada di mana.

```bash
$ pwd
/home/cry0l1t3
```

---

## 2. `ls` (List Directory Contents)

`ls` dipakai untuk menampilkan daftar file dan direktori di suatu lokasi. Tanpa opsi tambahan, hanya nama file dan folder yang ditampilkan. Kita juga bisa menentukan path tertentu tanpa perlu berpindah ke sana lebih dulu.

```bash
# List current directory
$ ls
Desktop  Documents  Downloads  Music  Pictures  Public  Templates  Videos

# List specific path without navigating there
$ ls /var/
backups  cache  crash  lib  local  log  lock  mail  opt  run  spool  tmp
```

---

## 3. `ls -l` (Detailed Listing)

Flag `-l` menampilkan informasi lengkap tentang setiap file dan direktori, termasuk permission, pemilik, ukuran, dan waktu modifikasi. Baris pertama `total 32` menunjukkan total blok disk yang dipakai (32 blok x 1024 byte = 32 KB).

```bash
$ ls -l

total 32
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:37 Desktop
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:34 Documents
drwxr-xr-x 3 cry0l1t3 htbacademy 4096 Nov 15 03:26 Downloads
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:34 Music
```

### Rincian Kolom Output

```
drwxr-xr-x   2   cry0l1t3   htbacademy   4096   Nov 13 17:37   Desktop
     │        │       │           │         │          │           │
     │        │       │           │         │          │           └─ Name
     │        │       │           │         │          └─ Date & Time
     │        │       │           │         └─ Size (bytes) / blocks
     │        │       │           └─ Group owner
     │        │       └─ Owner (user)
     │        └─ Number of hard links
     └─ Type + Permissions
```

| Kolom | Keterangan |
|-------|------------|
| `drwxr-xr-x` | Tipe dan permission file |
| `2` | Jumlah hard link |
| `cry0l1t3` | Pemilik file |
| `htbacademy` | Grup pemilik |
| `4096` | Ukuran file (byte) |
| `Nov 13 17:37` | Tanggal & waktu modifikasi |
| `Desktop` | Nama file / direktori |

### Memahami Permission: `drwxr-xr-x`

```
d  rwx  r-x  r-x
│   │    │    │
│   │    │    └─ Others  : read + execute only
│   │    └─ Group    : read + execute only
│   └─ Owner    : read + write + execute
└─ Type: d=directory, -=file, l=symlink
```

| Simbol | Arti |
|--------|------|
| `d` | Direktori |
| `-` | File biasa |
| `l` | Symbolic link |
| `r` | Read (baca) |
| `w` | Write (tulis) |
| `x` | Execute (eksekusi) |
| `-` | Tidak ada permission |

## 4. `ls -la` (Show Hidden Files)

Flag `-a` menampilkan semua file termasuk file tersembunyi. Di Linux, file tersembunyi diawali dengan tanda titik (`.`), seperti `.bashrc` atau `.bash_history`. File-file ini biasanya berisi konfigurasi penting dan sering terlewat oleh `ls` biasa.

```bash
$ ls -la

total 403188
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:37 .bash_history
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:37 .bashrc
...
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:37 Desktop
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:34 Documents
```

Catatan pentesting: file tersembunyi seperti `.bash_history` bisa berisi perintah yang pernah dijalankan, credential, atau path sensitif yang ditinggalkan user lain. Selalu cek dengan `ls -la` saat melakukan enumerasi sistem.

### File Tersembunyi yang Umum

| File | Fungsi |
|------|--------|
| `.bashrc` | Konfigurasi shell Bash |
| `.bash_history` | Riwayat perintah yang pernah dijalankan |
| `.bash_profile` | Konfigurasi login shell |
| `.ssh/` | Kunci & konfigurasi SSH |
| `.env` | Variabel environment |

## 5. `cd` (Change Directory)

`cd` dipakai untuk berpindah antar direktori. Kita bisa menggunakan absolute path (dimulai dari `/`) atau relative path (relatif terhadap direktori saat ini). Tidak perlu berpindah bertahap, kita bisa langsung melompat ke path tujuan secara penuh.

```bash
# Navigate using absolute path (jump directly)
$ cd /dev/shm
cry0l1t3@htb[/dev/shm]$

# Navigate using relative path
$ cd Documents

# Jump to home directory
$ cd ~
$ cd          # also goes to home

# Navigate using dot notation
$ cd ./Storage/local/user
```

### Absolute vs Relative Path

```
Filesystem root: /
        │
        ├── home/
        │     └── cry0l1t3/        ← you are here (~)
        │           ├── Desktop/
        │           └── Documents/
        │
        └── dev/
              └── shm/             ← target

Absolute: cd /dev/shm              (always starts from /)
Relative: cd ../../dev/shm         (from current location)
```

## 6. `cd -` (Return to Previous Directory)

`cd -` adalah pintasan cepat untuk kembali ke direktori yang sebelumnya dikunjungi. Sangat berguna saat berpindah bolak-balik antara dua direktori yang berbeda.

```bash
$ pwd
/home/cry0l1t3

$ cd /dev/shm
cry0l1t3@htb[/dev/shm]$

$ cd -
cry0l1t3@htb[~]$         # back to /home/cry0l1t3

$ cd -
cry0l1t3@htb[/dev/shm]$  # and back again
```

---

## 7. `cd ..` (Go Up to Parent Directory)

`..` (dua titik) selalu merujuk ke direktori parent, yaitu satu level di atas direktori saat ini. Sedangkan `.` (satu titik) merujuk ke direktori saat ini. Kedua simbol ini selalu tampil di output `ls -la` sebagai dua entri pertama.

```bash
$ pwd
/dev/shm

$ ls -la /dev/shm
total 0
drwxrwxrwt  2 root root   40 Mai 15 18:31 .    ← current dir (/dev/shm)
drwxr-xr-x 17 root root 4000 Mai 14 20:45 ..   ← parent dir (/dev)

# Go up one level
$ cd ..
cry0l1t3@htb[/dev]$

# Go up two levels at once
$ cd ../..

# Combine with path
$ cd ../../home/cry0l1t3
```

---

## 8. `clear` (Clear the Terminal)

`clear` dipakai untuk membersihkan layar terminal dari semua output sebelumnya. Bisa juga dikombinasikan dengan perintah lain memakai `&&`. Alternatif yang lebih cepat: pakai shortcut keyboard `[CTRL + L]`.

```bash
# Clear the terminal
$ clear

# Combine: navigate and clear in one line
$ cd /dev/shm && clear

# Keyboard shortcut alternative
[CTRL + L]
```

## 9. Pintasan Keyboard Shell

Shell menyediakan berbagai pintasan keyboard yang mempercepat navigasi dan penggunaan terminal secara signifikan.

| Shortcut | Fungsi |
|----------|--------|
| `[TAB]` | Auto-complete nama file/path |
| `[TAB TAB]` | Tampilkan semua kemungkinan completion |
| `↑ / ↓` | Scroll riwayat perintah |
| `[CTRL + R]` | Cari di riwayat perintah |
| `[CTRL + L]` | Bersihkan terminal |
| `[CTRL + C]` | Batalkan perintah yang sedang berjalan |
| `[CTRL + A]` | Pindah ke awal baris |
| `[CTRL + E]` | Pindah ke akhir baris |

### Demo Auto-complete dengan TAB

```bash
# Type partial path and press TAB twice to see options
$ cd /dev/s[TAB TAB]
shm/  snd/

# Add "h" to narrow it down — shell completes automatically
$ cd /dev/sh[TAB]
$ cd /dev/shm/    ← completed!
```

## Cheatsheet Referensi Cepat

```bash
# ── WHERE AM I ──────────────────────────────────────
pwd                         # show current directory

# ── LIST CONTENTS ───────────────────────────────────
ls                          # basic list
ls -l                       # detailed list
ls -la                      # detailed + hidden files
ls -lh                      # human-readable sizes
ls /var/                    # list specific path

# ── NAVIGATE ────────────────────────────────────────
cd /dev/shm                 # absolute path
cd Documents                # relative path
cd ~                        # home directory
cd -                        # previous directory
cd ..                       # parent directory
cd ../..                    # two levels up

# ── CLEAN TERMINAL ──────────────────────────────────
clear                       # clear screen
cd /dev/shm && clear        # navigate + clear
[CTRL + L]                  # shortcut to clear

# ── SHORTCUTS ───────────────────────────────────────
[TAB]                       # auto-complete
[TAB TAB]                   # show all completions
[↑] / [↓]                  # command history
[CTRL + R]                  # search history
[CTRL + C]                  # cancel command
[CTRL + A]                  # beginning of line
[CTRL + E]                  # end of line
```
