## Kenapa Kemampuan Mencari Bantuan Itu Penting

Kita tidak perlu menghafal semua perintah dan opsinya. Yang lebih penting adalah tahu cara mencari bantuan saat menemukan tool yang belum dikenal atau lupa opsi tertentu. Kemampuan ini adalah tanda seorang engineer yang baik, bukan soal hafalan, tapi soal kemampuan beradaptasi.

Setiap tool punya ratusan opsi. Menghafal semuanya tidak mungkin dan tidak perlu. Yang perlu dikuasai adalah cara menemukan informasi yang tepat dengan cepat.

## 1. `man`, Manual Pages

`man` (manual) menampilkan dokumentasi lengkap untuk sebuah perintah atau tool. Manual page berisi penjelasan mendalam tentang semua opsi, argumen, contoh penggunaan, dan perilaku tool tersebut. Ini sumber referensi paling lengkap yang tersedia langsung di sistem.

```bash
# Syntax
man <tool>

# Example: manual for ls
$ man ls
```

**Output:**
```
LS(1)                    User Commands                    LS(1)

NAME
       ls - list directory contents

SYNOPSIS
       ls [OPTION]... [FILE]...

DESCRIPTION
       List information about the FILEs (the current directory
       by default). Sort entries alphabetically if none of
       -cftuvSUX nor --sort is specified.

       -a, --all
              do not ignore entries starting with .

       -A, --almost-all
              do not list implied . and ..
...
Manual page ls(1) line 1 (press h for help or q to quit)
```

### Navigasi di dalam man page

| Tombol | Fungsi |
|--------|--------|
| `↑` / `↓` | Scroll baris per baris |
| `Space` | Scroll satu halaman ke bawah |
| `b` | Kembali satu halaman |
| `/keyword` | Cari keyword |
| `n` | Lanjut ke hasil pencarian berikutnya |
| `N` | Kembali ke hasil pencarian sebelumnya |
| `g` | Pergi ke awal |
| `G` | Pergi ke akhir |
| `h` | Tampilkan bantuan navigasi |
| `q` | Keluar dari man page |

### Nomor Section Man Page

```bash
# Format: man <section> <command>
$ man 1 ls      # user commands
$ man 5 passwd  # file formats (e.g. /etc/passwd structure)
$ man 8 sudo    # system admin commands
```

| Section | Isi |
|---------|-----|
| `1` | Perintah user umum |
| `2` | System calls |
| `3` | Library functions |
| `4` | Device files |
| `5` | Format file konfigurasi |
| `6` | Games |
| `7` | Lain-lain |
| `8` | Perintah administrasi sistem |

## 2. `--help`, Flag Bantuan Cepat

`--help` adalah cara cepat dan ringkas untuk melihat opsi yang tersedia tanpa harus membuka manual page lengkap. Output-nya lebih pendek dan langsung menampilkan daftar flag beserta penjelasan singkatnya. Cocok saat kita hanya butuh mengingat satu atau dua opsi.

```bash
# Syntax
<tool> --help

# Example
$ ls --help
```

**Output:**
```
Usage: ls [OPTION]... [FILE]...
List information about the FILEs (the current directory by default).
Sort entries alphabetically if none of -cftuvSUX nor --sort is specified.

  -a, --all                  do not ignore entries starting with .
  -A, --almost-all           do not list implied . and ..
      --author               with -l, print the author of each file
  -b, --escape               print C-style escapes for nongraphic characters
  -B, --ignore-backups       do not list implied entries ending with ~
  -c                         with -lt: sort by, and show, ctime
  -C                         list entries by columns
<SNIP>
```

## 3. `-h`, Flag Bantuan Pendek

Beberapa tools menggunakan `-h` (bukan `--help`) sebagai versi pendek dari flag bantuan. Hasilnya biasanya lebih ringkas dari `--help`. Tidak semua tools mendukung `-h`: beberapa hanya pakai `--help`, beberapa mendukung keduanya.

```bash
# Syntax
<tool> -h

# Example: curl short help
$ curl -h
```

**Output:**
```
Usage: curl [options...] <url>
     --abstract-unix-socket <path> Connect via abstract Unix domain socket
     --anyauth       Pick any authentication method
 -a, --append        Append to target file when uploading
     --basic         Use HTTP Basic Authentication
     --cacert <file> CA certificate to verify peer against
 -E, --cert <certificate[:password]> Client certificate file and password
<SNIP>
```

### Pilih yang Mana?

```
Tool unknown?         → man <tool>          (full documentation)
Need a quick flag?    → <tool> --help       (most tools)
Tool uses short help? → <tool> -h           (curl, nmap, etc.)
Not sure?             → try --help first, then -h
```

## 4. `apropos`, Cari Berdasarkan Keyword

`apropos` dipakai untuk mencari keyword di dalam deskripsi singkat semua manual page. Berguna saat kita tahu apa yang ingin dilakukan tapi tidak tahu nama perintahnya. Misalnya, ingin tahu tools apa saja yang berhubungan dengan `sudo`.

```bash
# Syntax
apropos <keyword>

# Example: find everything related to sudo
$ apropos sudo
```

**Output:**
```
sudo (8)             - execute a command as another user
sudo.conf (5)        - configuration for sudo front end
sudo_plugin (8)      - Sudo Plugin API
sudo_root (8)        - How to run administrative commands
sudoedit (8)         - execute a command as another user
sudoers (5)          - default sudo security policy plugin
sudoreplay (8)       - replay sudo session logs
visudo (8)           - edit the sudoers file
```

```bash
# More examples
$ apropos password       # find password-related commands
$ apropos network        # find networking commands
$ apropos compress       # find compression tools
$ apropos "file system"  # search multi-word keyword
```

Jika `apropos` tidak mengembalikan hasil apa pun, jalankan `sudo mandb` dulu untuk memperbarui database manual.

## 5. ExplainShell, Penjelasan Command Online

ExplainShell (https://explainshell.com) adalah tool online yang memecah dan menjelaskan setiap bagian dari perintah panjang. Sangat berguna saat menemukan perintah kompleks yang belum pernah dilihat sebelumnya dan ingin memahami apa yang dilakukan setiap bagiannya.

```bash
# Example: paste this complex command into explainshell.com
find /etc/ -name *.conf -user root -size +20k -newermt 2020-03-03 -exec ls -al {} \; 2>/dev/null

# ExplainShell will break it down:
# find        → search for files
# /etc/       → starting directory
# -name *.conf → match files ending in .conf
# -user root  → owned by root
# -size +20k  → larger than 20 kilobytes
# -newermt    → modified after specified date
# -exec ls -al {} \; → run ls -al on each result
# 2>/dev/null → suppress errors
```

## 6. Catatan Keamanan: GTFOBins Pager Breakout & Rekon Offline

Dalam penetration testing dan security assessment, sistem bantuan bawaan Linux punya beberapa implikasi keamanan penting.

1. GTFOBins / pager breakout: `man` secara default menggunakan pager seperti `less` atau `more` untuk menampilkan teks. Jika user memiliki izin `sudo` untuk menjalankan `man` (misalnya `sudo man ls` atau `sudo man 1 intro`), penyerang bisa mengetik `!/bin/sh` atau `!bash` di dalam tampilan `man` untuk langsung memperoleh interactive root shell.
2. Rekon sistem offline: pada target terisolasi tanpa konektivitas internet (air-gapped atau lab CTF), `man` dan `apropos` jadi senjata utama untuk menemukan tool bawaan (seperti `nc`, `socat`, `python`, `gcc`, `openssl`, `base64`) yang bisa dipakai untuk privilege escalation atau eksfiltrasi data.
3. Format konfigurasi (man section 5): membaca dokumentasi konfigurasi lokal lewat `man 5` (seperti `man 5 sudoers`, `man 5 sshd_config`, `man 5 shadow`) memudahkan auditor menganalisis sintaks dan mengidentifikasi miskonfigurasi keamanan pada file konfigurasi sistem.

```bash
# ── GTFOBINS PAGER ESCAPE EXAMPLES ───────────────────────────

# 1. Sudo man privilege escalation
$ sudo man ls
# Inside man / less pager, type:
!/bin/sh
# Result: # (root shell!)

# 2. Offline tool discovery for reverse shell payloads
$ apropos "network" | grep -E "transfer|client|listen"
$ apropos "compiler" # check if gcc/clang is installed

# 3. Read security configuration documentation
$ man 5 sudoers     # syntax for /etc/sudoers (e.g. NOPASSWD, wildcards)
$ man 5 shadow      # password hash field formats
```

## Cheatsheet Referensi Cepat

```bash
# ── FULL DOCUMENTATION ───────────────────────────────
man ls                      # manual for ls
man 5 /etc/passwd           # manual for passwd file format
man -k keyword              # same as apropos

# ── QUICK HELP ───────────────────────────────────────
ls --help                   # long help flag
curl -h                     # short help flag (some tools)
nmap -h                     # short help (nmap style)

# ── SEARCH MANUALS ───────────────────────────────────
apropos sudo                # find commands related to sudo
apropos password            # find password-related commands
sudo mandb                  # update man page database

# ── NAVIGATING man PAGES ─────────────────────────────
/keyword    # search inside man page
n           # next match
N           # previous match
q           # quit
Space       # next page
b           # previous page
g           # go to top
G           # go to bottom

# ── ONLINE RESOURCES ─────────────────────────────────
# https://explainshell.com  → visual command breakdown
# https://tldr.sh           → simplified man pages (community)
# https://gtfobins.github.io → unix binaries bypass list
# https://cheat.sh          → cheatsheets from terminal:
curl cheat.sh/ls            # get ls cheatsheet from terminal
```
