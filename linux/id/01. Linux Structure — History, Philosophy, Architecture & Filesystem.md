## 1. Apa itu Linux?

Linux adalah sistem operasi, sama seperti Windows, macOS, iOS, atau Android. Sistem operasi (OS) adalah perangkat lunak yang mengelola semua sumber daya hardware komputer dan menjembatani komunikasi antara aplikasi dan hardware.

Yang membuat Linux berbeda adalah ia hadir dalam banyak distribusi (distro), yaitu versi Linux yang disesuaikan untuk kebutuhan yang berbeda-beda. Linux penting di dunia cybersecurity karena beberapa hal berikut.

- Gratis dan open source, source code-nya bisa dimodifikasi siapa saja.
- Lebih jarang terkena malware dibanding OS lain.
- Stabil dan berperforma tinggi.
- Dipakai di server, mainframe, router, smart TV, konsol game, sampai Android.

### Distribusi Linux Populer

| Distro | Fokus | Cocok untuk |
|--------|-------|-------------|
| Ubuntu | Ramah pengguna | Pemula, desktop |
| Debian | Stabilitas | Server, pengembangan |
| Parrot OS | Keamanan & privasi | Pentesting, CTF |
| Kali Linux | Keamanan ofensif | Penetration testing |
| Fedora | Teknologi terbaru | Developer |
| Arch Linux | Kustomisasi | Pengguna tingkat lanjut |
| CentOS / RHEL | Enterprise | Server produksi |
| Manjaro | Kemudahan pakai | Pengguna desktop |

Catatan: di HackTheBox Academy, materi ini memakai Parrot OS (Pwnbox), distro berbasis Debian yang berfokus pada keamanan, privasi, dan pengembangan.

## 2. Sejarah Linux

Linux tidak muncul tiba-tiba. Ada rangkaian peristiwa panjang yang mendahuluinya, dan memahami sejarah ini penting karena banyak konsep Linux berakar dari filosofi Unix yang jauh lebih tua.

### Garis Waktu

```
1970  ── Unix OS released by Ken Thompson & Dennis Ritchie (AT&T)
  │
1977  ── BSD (Berkeley Software Distribution) released
  │        └── AT&T lawsuit limits BSD development
  │
1983  ── Richard Stallman starts the GNU Project
  │        └── Goal: create a free Unix-like OS
  │        └── GNU General Public License (GPL) created
  │
1991  ── Linus Torvalds (Finnish student) starts Linux kernel
  │        └── Goal: new, free OS kernel
  │        └── Written in C, originally prohibited commercial use
  │
Now   ── Linux kernel: 23+ million lines of code
           Licensed under GNU GPL v2
           600+ distributions available
           Powers most of the internet's servers
           Android (Linux-based) = most installed OS worldwide
```

| Tahun | Peristiwa |
|-------|-----------|
| 1970 | Unix dirilis oleh Ken Thompson & Dennis Ritchie di AT&T |
| 1977 | BSD dirilis, pengembangannya dibatasi oleh gugatan hukum AT&T |
| 1983 | Proyek GNU dimulai oleh Richard Stallman |
| 1989 | Lisensi GNU General Public License (GPL) dibuat |
| 1991 | Kernel Linux dibuat oleh Linus Torvalds, saat itu berusia 21 tahun |
| Sekarang | 23+ juta baris kode, 600+ distro, OS paling banyak dipasang di dunia |

## 3. Filosofi Linux

Filosofi Linux berpusat pada kesederhanaan, modularitas, dan keterbukaan. Linux mendukung pembuatan program kecil yang melakukan satu tugas dengan sangat baik, lalu menggabungkannya untuk menyelesaikan operasi yang kompleks.

### 5 Prinsip Inti

| # | Prinsip | Penjelasan |
|---|---------|------------|
| 1 | Semua adalah file | Semua resource sistem (hardware, proses, koneksi jaringan) direpresentasikan sebagai file, bisa dibaca dan ditulis dengan tools yang sama |
| 2 | Program kecil bertujuan tunggal | Linux menyediakan banyak tools kecil yang masing-masing melakukan satu hal dengan sangat baik |
| 3 | Kemampuan merangkai program | Program-program kecil bisa dihubungkan lewat pipe untuk menyelesaikan tugas besar dan kompleks |
| 4 | Menghindari antarmuka pengguna yang membatasi | Linux dirancang untuk bekerja terutama lewat shell/terminal, memberi pengguna kendali penuh atas OS |
| 5 | Konfigurasi dalam file teks | Data konfigurasi disimpan dalam file teks, contohnya `/etc/passwd` menyimpan semua user yang terdaftar |

Prinsip-prinsip ini yang membuat Linux begitu berguna untuk cybersecurity: semuanya transparan, bisa discripting, dan bisa dikombinasikan.

## 4. Komponen Linux

Linux terdiri dari beberapa komponen utama yang bekerja bersama untuk mengoperasikan sistem.

| Komponen | Deskripsi |
|----------|-----------|
| Bootloader | Kode yang memandu proses booting untuk memulai OS. Parrot Linux memakai GRUB Bootloader |
| OS Kernel | Komponen utama OS yang mengelola resource I/O device di level hardware |
| Daemons | Layanan background yang memastikan fungsi seperti scheduling, printing, dan multimedia berjalan dengan benar |
| OS Shell | Interface antara OS dan user, tempat user memberikan perintah ke OS. Shell populer: Bash, Zsh, Fish, Ksh |
| Graphics Server | Subsistem grafis "X" / X-server yang memungkinkan program grafis berjalan secara lokal atau remote |
| Window Manager | GUI desktop environment seperti GNOME, KDE, MATE, Unity, Cinnamon, termasuk file browser & web browser |
| Utilities | Aplikasi yang menjalankan fungsi tertentu untuk user atau program lain |

## 5. Arsitektur Linux

Sistem operasi Linux dapat dibagi menjadi 4 lapisan (layer) yang saling berkomunikasi dari bawah ke atas.

```
┌─────────────────────────────────────────────────────┐
│                  SYSTEM UTILITY                      │
│   Makes all OS functionality available to the user   │
│   (commands, programs, libraries, man pages)         │
├─────────────────────────────────────────────────────┤
│                     SHELL                            │
│   Command-line interface (CLI) — user enters         │
│   commands to interact with the kernel               │
│   Bash / Zsh / Fish / Ksh                            │
├─────────────────────────────────────────────────────┤
│                     KERNEL                           │
│   Core of Linux — virtualizes and controls hardware  │
│   CPU, RAM, I/O, process management                  │
│   Gives each process its own virtual resources       │
├─────────────────────────────────────────────────────┤
│                    HARDWARE                          │
│   Physical components: CPU, RAM, HDD/SSD,            │
│   Network card, GPU, peripherals                     │
└─────────────────────────────────────────────────────┘
          ↕ each layer communicates with adjacent layers
```

| Layer | Deskripsi |
|-------|-----------|
| Hardware | Perangkat fisik: RAM, hard drive, CPU, dll |
| Kernel | Inti Linux, memvirtualisasi dan mengontrol resource hardware, memberi setiap proses resource virtual sendiri |
| Shell | CLI (Command-Line Interface), tempat user memasukkan perintah untuk menjalankan fungsi kernel |
| System Utility | Menyediakan semua fungsionalitas OS kepada user |

## 6. Hierarki Filesystem (FHS)

Linux menggunakan struktur direktori berbentuk pohon (tree) yang didokumentasikan dalam Filesystem Hierarchy Standard (FHS). Semua direktori dimulai dari root `/`, seperti batang pohon yang bercabang ke bawah.

### Pohon Direktori

```
/ (root)
├── bin/      ← essential command binaries
├── boot/     ← bootloader, kernel
├── dev/      ← device files (hardware access)
├── etc/      ← system config files
├── home/     ← user home directories
│   └── cry0l1t3/
├── lib/      ← shared libraries for boot
├── media/    ← removable media (USB, CD)
├── mnt/      ← temporary mount points
├── opt/      ← optional / third-party software
├── proc/     ← virtual filesystem (process info)
├── root/     ← root user's home directory
├── run/      ← runtime data (PIDs, sockets)
├── sbin/     ← system admin binaries
├── sys/      ← virtual filesystem (kernel/device info)
├── tmp/      ← temporary files (cleared on boot)
├── usr/      ← user programs, libraries, man pages
└── var/      ← variable data (logs, mail, web files)
```

### Tabel Referensi Direktori

| Path | Deskripsi |
|------|-----------|
| `/` | Direktori root, berisi semua file yang dibutuhkan untuk booting |
| `/bin` | Binary perintah esensial (ls, cp, mv, cat, dll) |
| `/boot` | Bootloader, kernel executable, file booting |
| `/dev` | File device untuk akses hardware (disk, USB, dll) |
| `/etc` | File konfigurasi sistem lokal & aplikasi |
| `/home` | Direktori home untuk setiap user |
| `/lib` | Shared library untuk sistem boot |
| `/media` | Media removable eksternal (USB, CD/DVD) |
| `/mnt` | Mount point sementara untuk filesystem |
| `/opt` | Software opsional / third-party tools |
| `/root` | Direktori home untuk user root |
| `/sbin` | Binary untuk administrasi sistem |
| `/tmp` | File sementara, dihapus saat reboot |
| `/usr` | Program user, library, man pages |
| `/var` | Data variabel: log, email, web files, cron |

### Direktori yang Relevan untuk Pentesting

| Path | Relevansi Pentesting |
|------|----------------------|
| `/etc/passwd` | Daftar semua user di sistem |
| `/etc/shadow` | Hash password user (butuh akses root) |
| `/etc/crontab` | Scheduled jobs, bisa jadi jalur privilege escalation |
| `/tmp` | Writable oleh semua user, sering dipakai untuk staging exploit |
| `/var/log` | Log sistem, jejak aktivitas user & serangan |
| `/home` | Kemungkinan berisi SSH keys, credential, file konfigurasi |
| `/root` | Home directory root, target privilege escalation |
| `/dev` | Device files, mis. `/dev/null`, `/dev/shm` (penyimpanan sementara berbasis RAM) |

## Cheatsheet Referensi Cepat

```bash
# Check Linux version and distro
uname -a                    # kernel version
cat /etc/os-release         # distro information
lsb_release -a              # distro details

# Explore filesystem hierarchy
ls /                        # list root directory
ls /etc/                    # system config files
ls /home/                   # user home directories
ls /var/log/                # system log files
cat /etc/passwd             # list all users
cat /etc/os-release         # current distro info

# Check shell in use
echo $SHELL                 # current shell path
cat /etc/shells             # all available shells
```
