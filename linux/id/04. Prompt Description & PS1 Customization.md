## 1. Dasar Bash Prompt

Bash prompt adalah baris teks yang muncul di terminal untuk memberi tahu bahwa sistem siap menerima perintah. Secara default, prompt menampilkan informasi berikut.

- Username, yaitu siapa yang sedang login.
- Hostname, yaitu nama komputer/mesin.
- Current directory, yaitu folder yang sedang aktif.

Setelah prompt muncul, kursor (garis atau kotak berkedip) menunggu kita mengetik perintah.

---

## 2. Struktur Prompt

Format default bash prompt mengikuti pola yang konsisten dan mudah dipahami.

### Format Default

```
<username>@<hostname><current working directory>$
```

### Anatomi

```
cry0l1t3  @  htb  [~]  $
    │     │   │    │    │
    │     │   │    │    └── $ = regular user  |  # = root user
    │     │   │    └─────── current directory (~ = home)
    │     │   └──────────── hostname (machine name)
    │     └──────────────── separator
    └────────────────────── username
```

### Contoh Nyata

```bash
# Standard user in home directory
cry0l1t3@htb[~]$

# Standard user in a different directory
cry0l1t3@htb[/etc/ssh]$

# Root user
root@htb[/htb]#

# Minimal prompt (when PS1 not set — common in reverse shells)
$       ← unprivileged user
#       ← root / privileged
```

Catatan: tanda tilde `~` selalu merujuk ke home directory user yang sedang login. Contoh: `~` sama dengan `/home/cry0l1t3` untuk user biasa, atau `/root` untuk root.

## 3. Prompt User vs Root

Cara termudah untuk mengetahui apakah kita login sebagai user biasa atau root adalah dengan melihat karakter terakhir pada prompt.

- `$` berarti user biasa (unprivileged).
- `#` berarti root / superuser (privileged).

Perbedaan ini penting saat melakukan penetration testing. Karakter `#` berarti kita sudah mendapatkan root access.

```bash
# Regular user prompt
cry0l1t3@htb[~]$  ← $ = normal user, limited privileges

# Root prompt
root@htb[/htb]#   ← # = root, FULL system access

# Minimal shell (e.g. after exploit / reverse shell)
$   ← still a user shell
#   ← got root! privilege escalation successful
```

Catatan pentesting: saat menjalankan reverse shell pada target, kita mungkin hanya melihat `$` atau `#` tanpa username/hostname. Ini terjadi karena variabel PS1 belum di-set dengan benar di sesi shell tersebut.

## 4. Variabel PS1

PS1 (Prompt String 1) adalah variabel environment di Linux yang mengontrol tampilan command prompt. PS1 bekerja seperti template yang mendefinisikan teks yang muncul setiap kali sistem siap menerima perintah.

Dengan mengkustomisasi PS1, kita bisa menampilkan informasi tambahan yang berguna, misalnya:

- IP address mesin atau target.
- Tanggal dan waktu.
- Status sukses/gagal perintah terakhir.
- Full path direktori saat ini.

Ini berguna saat penetration testing karena membantu melacak aktivitas dan mendokumentasikan pekerjaan secara lebih efektif.

```bash
# Check current PS1 value
$ echo $PS1
\[\u@\h \W\]\$

# Temporarily change PS1 in current session
$ PS1="[\u@\h \w] $ "

# Permanently change in ~/.bashrc
$ nano ~/.bashrc
# Add/modify PS1 line, then:
$ source ~/.bashrc
```

---

## 5. Karakter Spesial PS1

PS1 menggunakan karakter spesial yang diawali dengan backslash `\` untuk menampilkan informasi dinamis secara otomatis.

| Karakter | Deskripsi | Contoh Output |
|----------|-----------|----------------|
| `\u` | Username saat ini | `cry0l1t3` |
| `\h` | Hostname (sampai titik pertama) | `htb` |
| `\H` | Full hostname | `htb.local` |
| `\w` | Full path direktori saat ini | `/home/user/docs` |
| `\W` | Nama folder saat ini saja | `docs` |
| `\d` | Tanggal (Mon Feb 6) | `Mon Feb  6` |
| `\D{%Y-%m-%d}` | Tanggal format YYYY-MM-DD | `2025-06-01` |
| `\t` | Waktu 24 jam (HH:MM:SS) | `14:32:10` |
| `\T` | Waktu 12 jam (HH:MM:SS) | `02:32:10` |
| `\@` | Waktu 12 jam (AM/PM) | `02:32 PM` |
| `\s` | Nama shell | `bash` |
| `\j` | Jumlah background jobs | `2` |
| `\n` | Baris baru (newline) | ↵ |
| `\$` | `$` untuk user, `#` untuk root | `$` atau `#` |

## 6. Contoh Kustomisasi Prompt

PS1 dikonfigurasi di file `~/.bashrc`. Perubahan permanen harus ditambahkan di file ini lalu di-source agar langsung berlaku.

### Contoh Preset

```bash
# ── MINIMAL (clean and simple) ──────────────────────
PS1="[\u@\h \W]\$ "
# Output: [cry0l1t3@htb ~]$

# ── WITH FULL PATH ───────────────────────────────────
PS1="[\u@\h \w]\$ "
# Output: [cry0l1t3@htb /home/cry0l1t3/documents]$

# ── WITH DATE & TIME ─────────────────────────────────
PS1="[\D{%Y-%m-%d} \t] \u@\h:\w\$ "
# Output: [2025-06-01 14:32:10] cry0l1t3@htb:~$

# ── PENTESTING PROMPT (with IP tracking) ─────────────
PS1="[\u@\h - $(hostname -I | awk '{print $1}')] \w\$ "
# Output: [cry0l1t3@htb - 10.10.14.5] /home/cry0l1t3$

# ── WITH COLOR (green user, blue path) ───────────────
PS1="\[\033[01;32m\]\u@\h\[\033[00m\]:\[\033[01;34m\]\w\[\033[00m\]\$ "
# Output: cry0l1t3@htb:/home/cry0l1t3$  (colored)
```

### Referensi Kode Warna

```bash
# Format: \[\033[<code>m\]...\[\033[00m\]
#                    └── color code

# Text Colors
\[\033[30m\]   # Black
\[\033[31m\]   # Red
\[\033[32m\]   # Green
\[\033[33m\]   # Yellow
\[\033[34m\]   # Blue
\[\033[35m\]   # Purple
\[\033[36m\]   # Cyan
\[\033[37m\]   # White

# Bold versions
\[\033[01;32m\]  # Bold Green
\[\033[01;34m\]  # Bold Blue
\[\033[01;31m\]  # Bold Red

# Reset
\[\033[00m\]   # Reset to default
```

### Cara Menerapkannya Secara Permanen

```bash
# 1. Open .bashrc
$ nano ~/.bashrc

# 2. Find or add the PS1 line at the bottom:
PS1="[\D{%Y-%m-%d} \t] \u@\h:\w\$ "

# 3. Save and apply without restarting terminal
$ source ~/.bashrc
# or
$ . ~/.bashrc
```

### Alur Kerja Pentesting: Merekam Perintah

```bash
# Record all commands with timestamps using script
$ script -a -t 2>~/pentest_timing.txt ~/pentest_log.txt

# View bash history with timestamps
$ export HISTTIMEFORMAT="%F %T "
$ history

# Bash history file location
$ cat ~/.bash_history
```

Catatan: mengatur PS1 kustom dengan tanggal/waktu, digabung dengan logging lewat `script`, adalah praktik yang baik selama pentest. Ini otomatis mendokumentasikan setiap perintah dengan timestamp untuk keperluan pelaporan.

## Cheatsheet Referensi Cepat

```bash
# ── CHECK CURRENT PROMPT ─────────────────────────────
echo $PS1                    # show current PS1 value
echo $0                      # show current shell

# ── IDENTIFY USER LEVEL ──────────────────────────────
whoami                       # current username
id                           # UID, GID, groups
# $ at end = regular user
# # at end = root

# ── TEMPORARY CHANGE ─────────────────────────────────
PS1="[\u@\h \w]\$ "         # change for current session only

# ── PERMANENT CHANGE ─────────────────────────────────
echo 'PS1="[\u@\h \w]\$ "' >> ~/.bashrc
source ~/.bashrc

# ── COMMON PS1 PRESETS ───────────────────────────────
# Minimal:     PS1="[\u@\h \W]\$ "
# Full path:   PS1="[\u@\h \w]\$ "
# With time:   PS1="[\t] \u@\h:\w\$ "
# Pentesting:  PS1="[\D{%Y-%m-%d} \t] \u@\h \w\$ "

# ── RECORD COMMANDS (pentest documentation) ──────────
script -a ~/session.log      # start recording
exit                         # stop recording
export HISTTIMEFORMAT="%F %T "  # add timestamps to history
```
