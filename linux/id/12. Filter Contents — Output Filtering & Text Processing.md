## 1. `more`

`more` menampilkan isi file per halaman. Punya beberapa keterbatasan: tidak bisa di-scroll ke atas, dan tampilan yang sudah lewat tetap tertinggal di terminal setelah keluar dengan `q`. Cocok untuk melihat file secara cepat tanpa perlu navigasi.

```bash
more /etc/passwd
```

> Gunakan `SPACE` untuk ke halaman berikutnya, `q` untuk keluar.

---

## 2. `less`

`less` adalah versi yang lebih canggih dari `more`. Bisa di-scroll ke atas dan ke bawah, menampilkan seluruh isi file, dan setelah keluar dengan `q` terminal akan bersih tanpa sisa tampilan. Lebih direkomendasikan untuk membaca file panjang.

```bash
less /etc/passwd
```

> Gunakan tombol panah atau `j`/`k` untuk scroll, `/keyword` untuk mencari di dalam file, `q` untuk keluar.

---

## 3. `head`

`head` menampilkan 10 baris pertama dari sebuah file secara default. Berguna untuk melihat header atau awal dari file log atau data.

```bash
head /etc/passwd

# Custom: show first 20 lines
head -n 20 /etc/passwd
```

---

## 4. `tail`

`tail` adalah kebalikan dari `head`, menampilkan 10 baris terakhir dari sebuah file. Sangat berguna untuk memantau file log secara real-time dengan flag `-f`.

```bash
tail /etc/passwd

# Real-time log monitoring
tail -f /var/log/syslog

# Custom: show last 20 lines
tail -n 20 /etc/passwd
```

---

## 5. `sort`

`sort` mengurutkan isi file atau output berdasarkan urutan alfabet (A-Z) secara default. Bisa dikombinasikan dengan pipe (`|`) untuk mengurutkan output dari perintah lain.

```bash
sort /etc/passwd

# Reverse order (Z-A)
sort -r /etc/passwd

# Sort numerically
sort -n file.txt
```

---

## 6. `grep`

`grep` adalah singkatan dari Global Regular Expression Print. Fungsinya mencari dan memfilter baris dari file atau output yang sesuai dengan pola tertentu. Sangat kuat jika dikombinasikan dengan regex.

```bash
# Show lines containing "root"
grep "root" /etc/passwd

# Exclude lines with "false" or "nologin"
grep -v "false\|nologin" /etc/passwd

# Case insensitive search
grep -i "ROOT" /etc/passwd
```

| Flag | Fungsi |
|------|--------|
| `-v` | Balik hasil pencarian (kecualikan pola) |
| `-i` | Case insensitive |
| `-n` | Tampilkan nomor baris |
| `-r` | Pencarian rekursif di direktori |
| `-E` | Extended regex |

---

## 7. `cut`

`cut` digunakan untuk membuang atau mengekstrak bagian tertentu dari setiap baris dalam file. Biasanya dipakai untuk memilih kolom berdasarkan delimiter tertentu, seperti `:` pada `/etc/passwd`.

```bash
# Extract field 1 (username) using ":" as delimiter
cut -d":" -f1 /etc/passwd

# Extract multiple fields
cut -d":" -f1,7 /etc/passwd
```

---

## 8. `tr`

`tr` (translate) digunakan untuk mengganti atau menghapus karakter dari input. Misalnya, mengganti karakter `:` menjadi spasi agar output lebih mudah dibaca.

```bash
# Replace ":" with space
cat /etc/passwd | tr ":" " "

# Convert lowercase to uppercase
cat file.txt | tr 'a-z' 'A-Z'

# Delete specific characters
cat file.txt | tr -d ':'
```

---

## 9. `column`

`column` digunakan untuk memformat output menjadi tampilan tabel yang lebih rapi dan mudah dibaca. Biasanya dikombinasikan dengan `tr` untuk menghasilkan tabel yang terstruktur.

```bash
# Format passwd file as a table
cat /etc/passwd | tr ":" " " | column -t
```

---

## 10. `awk`

`awk` adalah bahasa pemrosesan teks yang sangat kuat. Fungsi utamanya adalah mencetak kolom tertentu dari setiap baris output. Misalnya, `$1` merujuk ke kolom pertama, `$NF` merujuk ke kolom terakhir.

```bash
cat /etc/passwd | grep -v "false\|nologin" | tr ":" " " | awk '{print $1, $NF}'
```

**Output:**
```
root /bin/bash
sync /bin/sync
postgres /bin/bash
mrb3n /bin/bash
cry0l1t3 /bin/bash
htb-student /bin/bash
```

| Variabel | Arti |
|----------|------|
| `$1` | Kolom pertama |
| `$2` | Kolom kedua |
| `$NF` | Kolom terakhir (N = total field) |
| `$0` | Seluruh baris |
| `NR` | Nomor baris saat ini |

---

## 11. `sed`

`sed` (Stream Editor) adalah alat untuk mengganti teks menggunakan pola regex pada input. Format umumnya `s/pola_lama/pola_baru/g`, dengan `s` berarti substitute (ganti) dan `/g` berarti global (ganti semua kemunculan, bukan hanya yang pertama).

```bash
cat /etc/passwd | grep -v "false\|nologin" | tr ":" " " | awk '{print $1, $NF}' | sed 's/bin/HTB/g'
```

**Output:**
```
root /HTB/bash
sync /HTB/sync
postgres /HTB/bash
mrb3n /HTB/bash
cry0l1t3 /HTB/bash
htb-student /HTB/bash
```

---

## 12. `wc`

`wc` (Word Count) digunakan untuk menghitung jumlah baris, kata, atau karakter dalam file atau output. Flag yang paling umum dipakai dalam filtering adalah `-l` untuk menghitung jumlah baris hasil match.

```bash
cat /etc/passwd | grep -v "false\|nologin" | tr ":" " " | awk '{print $1, $NF}' | wc -l
```

**Output:**
```
6
```

| Flag | Fungsi |
|------|--------|
| `-l` | Hitung baris |
| `-w` | Hitung kata |
| `-c` | Hitung byte/karakter |

## 13. Menggabungkan Semua Tool

One-liner pipeline yang menggabungkan semua tool di atas:

```bash
cat /etc/passwd \
  | grep -v "false\|nologin" \   # Remove service accounts
  | tr ":" " " \                 # Replace ":" with space
  | awk '{print $1, $NF}' \      # Print username and shell
  | sed 's/bin/HTB/g' \          # Replace "bin" with "HTB"
  | sort \                       # Sort alphabetically
  | wc -l                        # Count total results
```

### Diagram Pipeline

```
[cat /etc/passwd]
       │
       ▼
[grep -v "false\|nologin"]  ── filter out service accounts
       │
       ▼
[tr ":" " "]  ── make columns readable
       │
       ▼
[awk '{print $1, $NF}']  ── extract username & shell
       │
       ▼
[sed 's/bin/HTB/g']  ── substitute text
       │
       ▼
[sort]  ── alphabetical order
       │
       ▼
[wc -l]  ── count output
```

## 14. Catatan Keamanan: Forensik Log & GTFOBins

Filter teks adalah komponen fundamental dalam operasi Security Operations Center (SOC), threat hunting, dan incident response.

1. Analisis log forensik: mencari serangan brute force SSH dengan `grep "Failed password" /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | sort -nr`; mendeteksi scanning web mencurigakan dengan `grep -E "nikto|sqlmap|nmap|dirbuster" /var/log/apache2/access.log`; mengekstrak IP penyerang paling aktif dengan `awk '{print $1}' /var/log/nginx/access.log | sort | uniq -c | sort -nr | head -10`.
2. Credential hunting: menelusuri seluruh direktori proyek web atau server untuk menemukan password atau secret key dengan `grep -rnwiE "password|secret|apikey|access_token|db_pass" /var/www/ 2>/dev/null`.
3. PrivEsc lewat binary text processing (referensi GTFOBins): `awk` bisa membuka shell dengan `awk 'BEGIN {system("/bin/sh")}'`; `sed` bisa membaca file terlindungi dengan `sed -e '1w /dev/stdout' -e 1d /etc/shadow`; `cut` bisa membaca file terlindungi baris demi baris dengan `cut -d "" -f1 /etc/shadow`; `less`/`more` bisa dipakai untuk keluar ke shell dengan `!/bin/sh`.

```bash
# ── ADVANCED LOG PARSING ONE-LINERS ──────────────────────────

# Extract all unique IPv4 addresses from auth.log
$ grep -oE '([0-9]{1,3}\.){3}[0-9]{1,3}' /var/log/auth.log | sort -u

# Find top 5 HTTP 404 targets (directory fuzzing detection)
$ awk '($9 ~ /404/)' /var/log/apache2/access.log | awk '{print $7}' | sort | uniq -c | sort -nr | head -5

# GTFOBins Sudo Awk Root Shell
$ sudo awk 'BEGIN {system("/bin/sh")}'
```

## Cheatsheet Referensi Cepat

```bash
# View files
more file.txt          # paged, stays in terminal
less file.txt          # paged, scrollable, clean exit
head -n 10 file.txt    # first 10 lines
tail -n 10 file.txt    # last 10 lines
tail -f file.txt       # real-time follow

# Filter & search
grep "pattern" file.txt          # search for pattern
grep -v "pattern" file.txt       # exclude pattern
grep -i "pattern" file.txt       # case-insensitive

# Transform
sort file.txt                    # sort A-Z
sort -r file.txt                 # sort Z-A
cut -d":" -f1 file.txt           # extract column 1
tr ":" " " < file.txt            # replace char
column -t file.txt               # table format

# Advanced
awk '{print $1, $NF}' file.txt   # print first & last column
sed 's/old/new/g' file.txt       # substitute text globally
wc -l file.txt                   # count lines
```
