## 1. Storage Stack Linux — Dari Disk ke Directory Tree

Data disimpan pada block device (disk, LV, loop), diformat dengan file system, lalu di-mount ke direktori dalam single tree (`/`).

```text
hardware → partition / LV --mkfs--> filesystem --mount--> /mountpoint
```

Administrator bekerja dengan `lsblk` untuk topologi, `blkid` untuk UUID/tipe, dan `/etc/fstab` untuk persistensi boot. Entri fstab yang salah bisa membuat sistem gagal boot; selalu uji dengan `mount -a`.

```
/dev/nvme0n1
 ├─ nvme0n1p1  →  /boot/efi   (vfat)
 ├─ nvme0n1p2  →  /boot       (ext4)
 └─ nvme0n1p3  →  LVM PV
                      ├─ vg0-root → /       (ext4)
                      ├─ vg0-home → /home  (ext4)
                      └─ vg0-swap → [swap]
```

| Layer | Tools | File kunci |
|:---|:---|:---|
| Discovery | `lsblk`, `fdisk -l`, `parted -l` | `/dev/*` |
| Format | `mkfs.ext4`, `mkfs.xfs`, `mkswap` | FS superblock |
| Mount | `mount`, `umount`, `findmnt` | `/etc/fstab`, `/proc/mounts` |
| LVM | `pvcreate`, `vgcreate`, `lvcreate` | Metadata `/etc/lvm/` |

## 2. Partitioning — MBR, GPT, `fdisk` & `parted`

Disk modern memakai GPT (GUID Partition Table); MBR legacy masih ditemukan di VM lama. `fdisk` (interaktif) dan `parted` (scriptable) adalah alat standar.

Selalu pastikan nama device (`/dev/sdb` vs `/dev/sda`) sebelum operasi destruktif. Gunakan `partprobe` atau reboot setelah perubahan tabel partisi.

```bash
# Topology
lsblk -f
sudo fdisk -l
sudo parted -l

# GPT partition with parted (example — DESTRUCTIVE on wrong disk)
sudo parted /dev/sdb --script mklabel gpt
sudo parted /dev/sdb --script mkpart primary ext4 1MiB 100%
sudo partprobe /dev/sdb

# Interactive fdisk
sudo fdisk /dev/sdb    # n=new, p=print, w=write, q=quit
```

| Skema | Maks partisi | Firmware boot | Catatan |
|:---:|:---:|:---|:---|
| MBR | 4 primary (+ extended) | BIOS | Legacy |
| GPT | Sangat banyak | UEFI | Direkomendasikan saat ini |

## 3. Tipe File System — ext4, XFS & swap

Pilih FS sesuai beban kerja: ext4 untuk kebutuhan umum, XFS untuk file besar atau default RHEL, vfat untuk ESP, swap untuk memori virtual.

| FS | Kegunaan umum | Perintah create |
|:---|:---|:---|
| ext4 | Root/home tujuan umum | `mkfs.ext4` |
| XFS | File besar / default RHEL | `mkfs.xfs` |
| vfat | EFI System Partition | `mkfs.vfat -F 32` |
| swap | Memori virtual / hibernasi | `mkswap` |

Catat label atau UUID untuk fstab; nama device (`/dev/sda1`) bisa berubah urutan setelah perubahan hardware.

```bash
sudo mkfs.ext4 -L datavol /dev/sdb1
sudo mkfs.xfs /dev/vg0/lv_data
sudo mkswap /dev/vg0/lv_swap
sudo swapon /dev/vg0/lv_swap

blkid
lsblk -f
```

## 4. Mount, Umount & `/etc/fstab`

`mount` menempelkan FS ke direktori kosong. `/etc/fstab` mendefinisikan mount otomatis saat boot.

Format fstab:

```text
device             mountpoint   type   options            dump   fsck
UUID=1234-abcd     /data        ext4   defaults,nofail    0      2
```

Gunakan `nofail` untuk media removable non-kritikal di server. Gunakan `UUID=` daripada `/dev/sdX`. Selalu uji dengan `sudo mount -a` setelah mengubah fstab.

```bash
# Manual mount
sudo mkdir -p /mnt/data
sudo mount /dev/sdb1 /mnt/data
findmnt /mnt/data
mount | grep /mnt/data

# Umount (busy → stop processes using path)
sudo umount /mnt/data
sudo fuser -vm /mnt/data

# /etc/fstab example
# UUID=abc-123-def   /mnt/data   ext4   defaults,nofail   0   2
sudo mount -a          # apply fstab without reboot
```

| Opsi mount | Efek |
|:---|:---|
| `defaults` | rw, suid, dev, exec, auto, nouser, async |
| `noexec` | Blokir eksekusi dari mount (direktori upload) |
| `nosuid` | Abaikan bit setuid pada FS |
| `nodev` | Abaikan file device pada FS |
| `ro` | Read-only |
| `nofail` | Boot tetap lanjut kalau mount gagal |

## 5. LVM — Logical Volume Manager

LVM adalah abstraksi di atas partisi:

```text
PV (Physical Volume)  →  VG (Volume Group)  →  LV (Logical Volume)
```

Keuntungannya: resize online, snapshot, striping (tingkat lanjut).

Alur kerja: tipe partisi `8e` (MBR) atau GPT `8300` Linux LVM, lalu `pvcreate` → `vgcreate` → `lvcreate` → `mkfs` → mount.

```bash
# Create stack (lab disk /dev/sdb1 prepared)
sudo pvcreate /dev/sdb1
sudo vgcreate vg_data /dev/sdb1
sudo lvcreate -L 50G -n lv_archive vg_data
sudo mkfs.ext4 /dev/vg_data/lv_archive
sudo mkdir -p /archive
echo '/dev/vg_data/lv_archive  /archive  ext4  defaults  0  2' | sudo tee -a /etc/fstab
sudo mount -a

# Extend LV + filesystem (ext4)
sudo lvextend -L +20G /dev/vg_data/lv_archive
sudo resize2fs /dev/vg_data/lv_archive

# Inspect
pvs; vgs; lvs
sudo lvdisplay
```

| Perintah | Fungsi |
|:---|:---|
| `pvcreate` | Inisialisasi partisi sebagai PV |
| `vgcreate` | Kelompokkan PV menjadi VG |
| `lvcreate` | Alokasikan LV dari VG |
| `lvextend` / `lvreduce` | Resize LV |
| `resize2fs` / `xfs_growfs` | Perbesar FS mengikuti LV |

## 6. Kapasitas, Penggunaan & Integritas

`df -hT` menunjukkan ruang bebas per mount. `du -sh` menunjukkan ukuran direktori. `fsck` memeriksa/memperbaiki FS; unmount dulu, kecuali root filesystem yang perlu penanganan hati-hati.

Pantau habisnya inode (`df -i`) pada server mail/cache. Jadwalkan pemeriksaan file system lewat field pass di fstab atau systemd timer.

```bash
df -hT
df -i
du -sh /var/log/* 2>/dev/null | sort -h | tail

# Offline check (FS must be unmounted)
sudo umount /dev/sdb1
sudo fsck -f /dev/sdb1

# Find large files quickly
sudo find /var -xdev -type f -size +100M -ls 2>/dev/null | head
```

## 7. Security Notes — Defense / Privilege Paths

Opsi mount (`noexec`, `nosuid`, `nodev`) adalah kontrol keamanan, bukan kosmetik. Direktori unggahan dan share jaringan harus dikunci ketat.

Mount world-writable dengan `exec` adalah jalur klasik untuk drop webshell. Jaga `/etc/fstab` tetap milik root dengan permission `644`, dan perlakukan konten NFS/SMB remote sebagai tidak tepercaya.

| Risiko | Mekanisme | Pertahanan |
|:---|:---|:---|
| Mount world-writable + `exec` | Drop webshell di `/mnt/uploads` | `noexec,nosuid,nodev` |
| Mount NFS/SMB sebagai root | Konten remote dipercaya seperti lokal | `nosuid,nodev`; ACL jaringan |
| `/etc/fstab` bisa ditulis user | Kompromi root saat boot | Milik root `644`; configuration management |
| Disk penuh | Log/cache memenuhi disk, DoS | Quota; logrotate; alert pada `df` |
| Penyalahgunaan snapshot LVM (admin) | Salinan forensik data sensitif | RBAC pada perintah LVM |

```bash
# Defensive mount audit
findmnt -lo TARGET,OPTIONS,SOURCE
grep -v '^#' /etc/fstab
mount | grep -E 'nosuid|noexec'
```

## 8. Cheatsheet Referensi Cepat

```bash
# Discovery
lsblk -f
blkid
sudo fdisk -l

# Format & swap
sudo mkfs.ext4 /dev/sdb1
sudo mkswap /dev/sdb2 && sudo swapon /dev/sdb2

# Mount
sudo mount /dev/sdb1 /mnt/data
sudo umount /mnt/data
sudo mount -a

# LVM
sudo pvcreate /dev/sdb1
sudo vgcreate vg0 /dev/sdb1
sudo lvcreate -L 10G -n lv0 vg0
pvs && vgs && lvs

# Space
df -hT
du -sh /path
```
