## 1. Identifikasi OS & Kernel

Mengumpulkan informasi sistem operasi dan kernel adalah langkah pertama dalam administrasi sistem maupun penetration testing. Beberapa perintah berikut mengungkap versi distribusi Linux, rilis kernel, dan arsitektur CPU.

- `uname -a`: menampilkan semua informasi kernel (arsitektur, rilis kernel, nama host, tanggal build).
- `/etc/os-release` / `/etc/issue`: berisi rilis dan nama distribusi resmi (Ubuntu, Debian, Kali, CentOS).
- `hostnamectl`: menampilkan ringkasan hostname, kernel, dan arsitektur pada sistem modern berbasis `systemd`.

```bash
# ── KERNEL & OS VERSION CHECK ────────────────────────────────
$ uname -a
Linux htb-target 5.15.0-78-generic #85-Ubuntu SMP Fri Jul 7 15:25:09 UTC 2023 x86_64 x86_64 x86_64 GNU/Linux

$ uname -r      # Kernel release only (e.g., 5.15.0-78-generic)
$ uname -m      # Machine architecture (e.g., x86_64 / aarch64)

# ── DISTRO INFORMATION ───────────────────────────────────────
$ cat /etc/os-release
NAME="Ubuntu"
VERSION="22.04.3 LTS (Jammy Jellyfish)"
ID=ubuntu
ID_LIKE=debian
VERSION_ID="22.04"

$ hostnamectl
```

## 2. Hardware, CPU & Memory

Kernel Linux memaparkan status hardware dan konsumsi resource melalui filesystem virtual `/proc`.

- `lscpu`: rincian arsitektur prosesor, jumlah core, socket, cache L1/L2/L3, dan status virtualisasi.
- `free -h`: total kapasitas RAM fisik dan swap yang terpakai/tersedia dalam format yang mudah dibaca (`-h` = human-readable).
- `/proc/cpuinfo` & `/proc/meminfo`: sumber data mentah dari kernel untuk spesifikasi prosesor dan memori.

```bash
# ── CPU SPECIFICATIONS ───────────────────────────────────────
$ lscpu
Architecture:            x86_64
  CPU op-mode(s):        32-bit, 64-bit
  Address sizes:         39 bits physical, 48 bits virtual
  Byte Order:            Little Endian
  CPU(s):                4
  Model name:            Intel(R) Core(TM) i7-10700K CPU @ 3.80GHz

# ── MEMORY CONSUMPTION ───────────────────────────────────────
$ free -h
               total        used        free      shared  buff/cache   available
Mem:           7.7Gi       2.1Gi       3.4Gi       120Mi       2.2Gi       5.2Gi
Swap:          2.0Gi          0B       2.0Gi
```

## 3. Disk & Filesystem

- `lsblk`: daftar semua block device (hard disk, NVMe, USB, loop device) dalam struktur pohon beserta titik mount (mountpoint).
- `df -h`: penggunaan ruang disk untuk setiap partisi yang sedang di-mount.
- `du -sh <path>`: total ukuran file atau direktori tertentu.
- `fdisk -l` / `parted -l`: tabel partisi disk (butuh akses root).

```bash
# ── BLOCK DEVICES TREE ───────────────────────────────────────
$ lsblk
NAME   MAJ:MIN RM   SIZE RO TYPE MOUNTPOINTS
sda      8:0    0    50G  0 disk 
├─sda1   8:1    0     1M  0 part 
├─sda2   8:2    0     2G  0 part /boot
└─sda3   8:3    0    48G  0 part /

# ── DISK FREE SPACE ──────────────────────────────────────────
$ df -h /
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda3        48G   12G   34G  27% /

# ── DIRECTORY SIZE CALCULATION ───────────────────────────────
$ du -sh /var/log/
1.4G	/var/log/
```

## 4. Network Interface & Hostname

- `ip addr` / `ip a`: semua antarmuka jaringan (NIC) beserta alamat IPv4/IPv6 dan MAC address (pengganti utility lama `ifconfig`).
- `ip route` / `ip r`: tabel routing kernel dan default gateway.
- `hostname -I`: semua alamat IP host secara ringkas.
- `/etc/resolv.conf`: server DNS resolver yang dipakai sistem.
- `/etc/hosts`: tabel mapping statis antara IP dan hostname lokal.

```bash
# ── INSPECT NETWORK INTERFACES ───────────────────────────────
$ ip -br a
lo               UNKNOWN        127.0.0.1/8 ::1/128 
eth0             UP             10.10.14.25/24 fe80::250:56ff:fe9d:8b2a/64 
tun0             UP             10.10.10.50/32 

# ── ROUTING & DNS ────────────────────────────────────────────
$ ip route
default via 10.10.14.1 dev eth0 proto dhcp src 10.10.14.25 metric 100 

$ cat /etc/resolv.conf
nameserver 1.1.1.1
nameserver 8.8.8.8
```

## 5. File Terbuka & Socket (`lsof`)

Di Linux, semua adalah file (everything is a file). Perintah `lsof` (List Open Files) menampilkan semua file, pipe, device, dan socket jaringan yang sedang diakses oleh proses sistem.

- `lsof -i`: semua koneksi jaringan dan port terbuka.
- `lsof -i :80`: mencari proses yang sedang memakai port 80.
- `lsof -u <user>`: file yang sedang dibuka oleh user tertentu.
- `ss -tulnp`: socket TCP/UDP yang sedang listening beserta PID proses pemiliknya.

```bash
# ── LIST OPEN NETWORK CONNECTIONS ────────────────────────────
$ sudo lsof -i -P -n
COMMAND    PID     USER   FD   TYPE DEVICE SIZE/OFF NODE NAME
sshd       892     root    3u  IPv4  24110      0t0  TCP *:22 (LISTEN)
sshd       892     root    4u  IPv6  24112      0t0  TCP *:22 (LISTEN)
apache2   1245 www-data    4u  IPv4  28901      0t0  TCP *:80 (LISTEN)

# ── LISTENING PORTS USING SS ─────────────────────────────────
$ ss -tulnp
Netid State  Recv-Q Send-Q Local Address:Port  Peer Address:PortProcess
tcp   LISTEN 0      128          0.0.0.0:22         0.0.0.0:*    users:(("sshd",pid=892,fd=3))
tcp   LISTEN 0      511          0.0.0.0:80         0.0.0.0:*    users:(("apache2",pid=1245,fd=4))
```

## 6. Environment Variables

Environment variable adalah pasangan nilai dinamis yang dipakai sistem dan aplikasi untuk menentukan konfigurasi eksekusi.

- `$PATH`: daftar direktori tempat shell mencari file executable secara otomatis.
- `$USER` & `$HOME`: username aktif dan path home direktori.
- `env` / `printenv`: semua variabel lingkungan yang aktif pada sesi saat ini.
- `export VAR="value"`: membuat variabel baru dan mengekspornya ke semua child process yang dijalankan dari shell tersebut.

```bash
# ── INSPECT ENVIRONMENT ──────────────────────────────────────
$ echo $PATH
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin

$ echo $USER $HOME
htb-student /home/htb-student

# Set temporary environment variable
$ export TARGET_IP="10.10.10.100"
$ ping -c 1 $TARGET_IP
```

## 7. Catatan Keamanan: Kernel Exploit, Rekon Lokal & Environment Poisoning

Dalam penetration testing Linux (HTB Academy Module 18 & The Hacker Playbook 3), informasi sistem adalah fondasi eksploitasi lokal.

1. Pencocokan exploit kernel. Versi kernel lama yang diperoleh dari `uname -r` sering memiliki kerentanan Local Privilege Escalation (LPE) yang sudah terdokumentasi, misalnya Dirty COW (CVE-2016-5195), Dirty Pipe (CVE-2022-0847), OverlayFS (CVE-2021-3493), atau PwnKit (CVE-2021-4034). Gunakan database exploit lokal seperti `searchsploit linux kernel 5.10`.
2. PATH hijacking / environment poisoning. Jika program SUID atau skrip cron menjalankan perintah tanpa path absolut (misalnya memanggil `curl` alih-alih `/usr/bin/curl`), penyerang bisa menyisipkan binary palsu di awal `$PATH` (`export PATH=/tmp:$PATH`) untuk mendapatkan eksekusi kode sebagai root.
3. Pemeriksaan internal port. Menggunakan `ss -tulnp` atau `netstat -tlpn` bisa mengungkap service lokal yang hanya mendengarkan pada `127.0.0.1` (seperti database MySQL internal, Redis, atau web admin backend) yang bisa di-pivot atau dieksploitasi.

```bash
# ── PENTESTING SYSTEM RECONNAISSANCE SCRIPT ──────────────────
# 1. OS & Architecture check
uname -a; cat /etc/*release 2>/dev/null

# 2. Search for kernel exploits with searchsploit
searchsploit "Linux Kernel $(uname -r | cut -d'-' -f1)"

# 3. Check internal listening services
ss -tulnp | grep -E "127.0.0.1|::1"

# 4. Check for writable directories in PATH
echo $PATH | tr ":" "\n" | while read dir; do [ -w "$dir" ] && echo "[!] Writable PATH: $dir"; done
```

## 8. Cheatsheet Referensi Cepat

```bash
# ── SYSTEM & KERNEL ──────────────────────────────────────────
uname -a                               # full kernel & architecture
uname -r                               # kernel release version
cat /etc/os-release                    # Linux distribution details
hostname -I                            # all host IP addresses

# ── HARDWARE & RESOURCES ─────────────────────────────────────
lscpu                                  # CPU architecture details
free -h                                # RAM & Swap memory usage
lsblk                                  # list block devices & mounts
df -h                                  # free disk space per partition
du -sh /path/dir                       # directory disk usage

# ── NETWORK & SOCKETS ────────────────────────────────────────
ip -br a                               # brief network interfaces list
ip route                               # routing table & default gateway
ss -tulnp                              # listening TCP/UDP ports with PID
sudo lsof -i -P -n                     # active network connections & files

# ── ENVIRONMENT ──────────────────────────────────────────────
env                                    # print all environment variables
echo $PATH                             # print execution search path
export VAR="value"                     # set environment variable
```
