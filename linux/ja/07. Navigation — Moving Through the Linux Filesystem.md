## 重要な用語

この教材でよく出てくる言葉である。

| 用語 | 意味 |
|:---|:---|
| 作業ディレクトリ | 今自分が「立っている」フォルダ |
| 絶対パス | ルートからの完全な住所。`/home/alex/notes` など |
| 相対パス | 今いる場所からの住所。`../notes` など |
| `.` と `..` | 「このフォルダ」と「1つ上のフォルダ」 |
| `~` | ホームディレクトリへの近道 |
| `pwd` / `cd` / `ls` | 今の場所を表示 / フォルダ移動 / 中身の一覧 |
| タブ補完 | Tabキーでファイル名やコマンド名を自動補完すること |

## 1. `pwd`（Print Working Directory）

`pwd` は、ファイルシステム内で自分が今どこにいるかを確認するためのコマンドである。システムにアクセスした直後にまず実行しておくと、自分の現在地を正確に把握できる。

```bash
$ pwd
/home/cry0l1t3
```

---

## 2. `ls`（List Directory Contents）

`ls` は、指定した場所にあるファイルとディレクトリの一覧を表示するコマンドである。オプションを付けなければ、ファイルとフォルダの名前だけが表示される。移動せずに特定のパスを直接指定して一覧表示することもできる。

```bash
# List current directory
$ ls
Desktop  Documents  Downloads  Music  Pictures  Public  Templates  Videos

# List specific path without navigating there
$ ls /var/
backups  cache  crash  lib  local  log  lock  mail  opt  run  spool  tmp
```

---

## 3. `ls -l`（詳細な一覧表示）

`-l` フラグを付けると、パーミッション、所有者、サイズ、更新日時など、各ファイル・ディレクトリの詳細情報が表示される。最初の行にある `total 32` は使用ディスクブロック数を示す（32ブロック × 1024バイト = 32 KB）。

```bash
$ ls -l

total 32
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:37 Desktop
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:34 Documents
drwxr-xr-x 3 cry0l1t3 htbacademy 4096 Nov 15 03:26 Downloads
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:34 Music
```

### 出力列の内訳

```
drwxr-xr-x   2   cry0l1t3   htbacademy   4096   Nov 13 17:37   Desktop
     │        │       │           │         │          │           │
     │        │       │           │         │          │           └─ Name
     │        │       │           │         │          └─ Date & Time
     │        │       │           │         └─ Size (bytes) / blocks
     │        │       │           └─ Group owner
     │        │       └─ Owner (user)
     │        └─ Number of hard links
     └─ Type + Permissions
```

| 列 | 説明 |
|----|------|
| `drwxr-xr-x` | ファイルの種類とパーミッション |
| `2` | ハードリンク数 |
| `cry0l1t3` | ファイルの所有者 |
| `htbacademy` | グループ所有者 |
| `4096` | ファイルサイズ（バイト） |
| `Nov 13 17:37` | 最終更新日時 |
| `Desktop` | ファイル・ディレクトリ名 |

### パーミッションの読み方: `drwxr-xr-x`

```
d  rwx  r-x  r-x
│   │    │    │
│   │    │    └─ Others  : read + execute only
│   │    └─ Group    : read + execute only
│   └─ Owner    : read + write + execute
└─ Type: d=directory, -=file, l=symlink
```

| 記号 | 意味 |
|------|------|
| `d` | ディレクトリ |
| `-` | 通常ファイル |
| `l` | シンボリックリンク |
| `r` | 読み取り権限 |
| `w` | 書き込み権限 |
| `x` | 実行権限 |
| `-` | 権限なし |

先頭の1文字がタイプ（d はディレクトリ、- は通常ファイル、l はシンボリックリンク）を表し、それ以降が3文字ずつ3組に分かれる。1組目が所有者（owner）、2組目がグループ（group）、3組目がその他（others）の権限を表し、各組は read・write・execute の順で並ぶ。

## 4. `ls -la`（隠しファイルを表示）

`-a` フラグを付けると、隠しファイルを含むすべてのファイルが表示される。Linux では、`.bashrc` や `.bash_history` のようにドット（`.`）で始まるファイルが隠しファイルとして扱われる。これらのファイルには重要な設定が含まれていることが多く、通常の `ls` では見落としがちである。

```bash
$ ls -la

total 403188
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:37 .bash_history
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:37 .bashrc
...
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:37 Desktop
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:34 Documents
```

ペンテストの観点: `.bash_history` のような隠しファイルには、過去に実行されたコマンド、認証情報、他のユーザーが残したセンシティブなパスが含まれていることがある。システムを列挙する際は必ず `ls -la` で確認する。

### よくある隠しファイル

| ファイル | 機能 |
|---------|------|
| `.bashrc` | Bash シェルの設定 |
| `.bash_history` | 実行したコマンドの履歴 |
| `.bash_profile` | ログインシェルの設定 |
| `.ssh/` | SSH キーと設定 |
| `.env` | 環境変数 |

## 5. `cd`（Change Directory）

`cd` は、ディレクトリ間を移動するためのコマンドである。絶対パス（`/` から始まる）または相対パス（現在のディレクトリからの相対位置）のどちらでも使える。段階的に移動する必要はなく、目的地のフルパスを指定して一気に移動できる。

```bash
# Navigate using absolute path (jump directly)
$ cd /dev/shm
cry0l1t3@htb[/dev/shm]$

# Navigate using relative path
$ cd Documents

# Jump to home directory
$ cd ~
$ cd          # also goes to home

# Navigate using dot notation
$ cd ./Storage/local/user
```

### 絶対パスと相対パス

```
Filesystem root: /
        │
        ├── home/
        │     └── cry0l1t3/        ← you are here (~)
        │           ├── Desktop/
        │           └── Documents/
        │
        └── dev/
              └── shm/             ← target

Absolute: cd /dev/shm              (always starts from /)
Relative: cd ../../dev/shm         (from current location)
```

絶対パスは常に `/` から書き始めるため、今どこにいても同じコマンドで同じ場所に到達できる。相対パスは現在の位置を基準にするため、同じコマンドでも実行する場所によって行き先が変わる点に注意する。

## 6. `cd -`（直前のディレクトリに戻る）

`cd -` は、直前に訪れていたディレクトリに戻るためのショートカットである。2つの異なるディレクトリを行き来するときに便利である。

```bash
$ pwd
/home/cry0l1t3

$ cd /dev/shm
cry0l1t3@htb[/dev/shm]$

$ cd -
cry0l1t3@htb[~]$         # back to /home/cry0l1t3

$ cd -
cry0l1t3@htb[/dev/shm]$  # and back again
```

---

## 7. `cd ..`（親ディレクトリへ移動）

`..`（ドット2つ）は常に親ディレクトリ、つまり現在のディレクトリの1つ上の階層を指す。一方 `.`（ドット1つ）は現在のディレクトリ自身を指す。この2つのエントリは、`ls -la` の出力で常に最初の2行として表示される。

```bash
$ pwd
/dev/shm

$ ls -la /dev/shm
total 0
drwxrwxrwt  2 root root   40 Mai 15 18:31 .    ← current dir (/dev/shm)
drwxr-xr-x 17 root root 4000 Mai 14 20:45 ..   ← parent dir (/dev)

# Go up one level
$ cd ..
cry0l1t3@htb[/dev]$

# Go up two levels at once
$ cd ../..

# Combine with path
$ cd ../../home/cry0l1t3
```

---

## 8. `clear`（ターミナルをクリア）

`clear` は、ターミナル画面に表示されていたそれまでの出力をすべて消すコマンドである。`&&` を使って他のコマンドと組み合わせることもできる。もっと速い方法として、キーボードショートカット `[CTRL + L]` も使える。

```bash
# Clear the terminal
$ clear

# Combine: navigate and clear in one line
$ cd /dev/shm && clear

# Keyboard shortcut alternative
[CTRL + L]
```

## 9. シェルのナビゲーションショートカット

シェルには、ターミナルでの操作とナビゲーションを大幅に速くするさまざまなキーボードショートカットが用意されている。

| ショートカット | 機能 |
|---------------|------|
| `[TAB]` | ファイル名・パスを自動補完 |
| `[TAB TAB]` | すべての補完候補を表示 |
| `↑ / ↓` | コマンド履歴をスクロール |
| `[CTRL + R]` | コマンド履歴を検索 |
| `[CTRL + L]` | ターミナルをクリア |
| `[CTRL + C]` | 実行中のコマンドをキャンセル |
| `[CTRL + A]` | 行の先頭に移動 |
| `[CTRL + E]` | 行の末尾に移動 |

### TAB 自動補完のデモ

```bash
# Type partial path and press TAB twice to see options
$ cd /dev/s[TAB TAB]
shm/  snd/

# Add "h" to narrow it down — shell completes automatically
$ cd /dev/sh[TAB]
$ cd /dev/shm/    ← completed!
```

## `ls` フラグ早見表

| コマンド | 機能 |
|---------|------|
| `ls` | 名前のみ表示 |
| `ls -l` | 詳細表示（パーミッション、サイズ、日付） |
| `ls -a` | 隠しファイルを表示 |
| `ls -la` | 詳細表示＋隠しファイル |
| `ls -lh` | 詳細表示＋人間が読みやすいサイズ表記 |
| `ls -lt` | 時間順にソート |
| `ls -lr` | 逆順表示 |
| `ls /path` | 特定パスを一覧表示 |

## クイックリファレンス・チートシート

```bash
# ── WHERE AM I ──────────────────────────────────────
pwd                         # show current directory

# ── LIST CONTENTS ───────────────────────────────────
ls                          # basic list
ls -l                       # detailed list
ls -la                      # detailed + hidden files
ls -lh                      # human-readable sizes
ls /var/                    # list specific path

# ── NAVIGATE ────────────────────────────────────────
cd /dev/shm                 # absolute path
cd Documents                # relative path
cd ~                        # home directory
cd -                        # previous directory
cd ..                       # parent directory
cd ../..                    # two levels up

# ── CLEAN TERMINAL ──────────────────────────────────
clear                       # clear screen
cd /dev/shm && clear        # navigate + clear
[CTRL + L]                  # shortcut to clear

# ── SHORTCUTS ───────────────────────────────────────
[TAB]                       # auto-complete
[TAB TAB]                   # show all completions
[↑] / [↓]                  # command history
[CTRL + R]                  # search history
[CTRL + C]                  # cancel command
[CTRL + A]                  # beginning of line
[CTRL + E]                  # end of line
```
