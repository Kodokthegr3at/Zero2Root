## 重要な用語

この教材でよく出てくる言葉である。

| 用語 | 意味 |
|:---|:---|
| テキストエディタ | プレーンテキストのファイル(設定、スクリプト)を編集するプログラム |
| nano | シンプルで初心者向けのエディタ。ショートカットが画面に表示される |
| vim | サーバーのどこにでもある強力なエディタ。ただしモード式 |
| モード(vim) | vimはノーマルモード(コマンド)かインサートモード(入力)のどちらか |
| バッファ | 編集中のファイルのメモリ上のコピー |
| 保存 / 終了 | nano: `Ctrl+O` のあと `Ctrl+X`。vim: `:w` のあと `:q` |
| シンタックスハイライト | 読みやすくするために、コードを意味ごとに色付けすること |

## 1. `nano`: シンプルなテキストエディタ

`nano` は初心者にも扱いやすいテキストエディタです。Vim とは異なり、Nano にはモードがなく、ファイルを開いたらすぐに文字を入力できます。ファイルを新規作成または開くには、最初の引数としてファイル名を指定するだけです。

```bash
# Create and open a new file
$ nano notes.txt

# Open an existing file
$ nano /etc/hosts
```

Nano の画面:
```
  GNU nano 2.9.3                    notes.txt

Here we can type everything we want and make our notes.▓


^G Get Help    ^O Write Out   ^W Where Is    ^K Cut Text    ^J Justify
^X Exit        ^R Read File   ^\ Replace     ^U Uncut Text  ^T To Spell
```

> キャレット記号 `^` は `[CTRL]` キーを表します。つまり `^X` は `[CTRL + X]` を意味します。

---

## 2. Nano のキーボードショートカット

Nano は画面下部に使用可能なショートカットを常時表示します。`^` は `[CTRL]` キー、`M-` は `[Alt]` キーを意味します。

| ショートカット | 機能 |
|----------|---------|
| `CTRL + O` | ファイルを保存 |
| `CTRL + X` | Nano を終了 |
| `CTRL + W` | テキストを検索 |
| `CTRL + K` | 現在の行をカット |
| `CTRL + U` | カットしたテキストを貼り付け |
| `CTRL + G` | ヘルプを表示 |
| `CTRL + C` | カーソル位置を表示 |
| `CTRL + \` | テキストを置換 |
| `M-U` | 直前の操作を元に戻す(undo) |
| `M-E` | やり直し(redo) |

### Nano 内での検索

`CTRL + W` を押すと画面下部に検索バーが開きます。

```
# Press CTRL+W to open search bar:

GNU nano 2.9.3                    notes.txt

Here ▓we can type everything we want and make our notes.

Search:  notes
^G Get Help   M-C Case Sens   M-B Backwards   ^C Cancel
```

基本的な作業の流れは、開く、書く、保存する、閉じるの4段階です。

```bash
# Workflow: edit → save → exit
1. nano notes.txt           # open/create file
2. Type your content        # write directly
3. CTRL + O  → ENTER        # save file
4. CTRL + X                 # exit editor
5. cat notes.txt            # verify content
```

## 3. `/etc/passwd`: ペンテスター必見のファイル

`/etc/passwd` ファイルには、Linux システムの全ユーザーに関する重要な情報(ユーザー名、UID、GID、ホームディレクトリなど)が保存されています。歴史的にはパスワードハッシュもこのファイルに保存されていましたが、現在はより厳格なパーミッションを持つ `/etc/shadow` に移されています。

ペネトレーションテスターにとってこのファイルが重要な理由はいくつかあります。

- パーミッション設定を誤ると機密情報が外部に露出する
- 権限昇格(privilege escalation)の起点になり得る
- 脆弱なユーザーアカウントの特定に役立つ

```bash
# View the passwd file
$ cat /etc/passwd

root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
student:x:1001:1001::/home/student:/bin/bash
```

```
username : password : UID : GID : comment : home_dir : shell
   root  :    x    :  0  :  0  :  root   :  /root   : /bin/bash
```

| フィールド | 説明 |
|-------|-------------|
| `root` | ユーザー名 |
| `x` | パスワードのプレースホルダ(実際のハッシュは `/etc/shadow` にある) |
| `0` | ユーザーID(UID)。0 は root |
| `0` | グループID(GID) |
| `root` | コメント / GECOS フィールド |
| `/root` | ホームディレクトリ |
| `/bin/bash` | デフォルトシェル |

> ペンテストの注意点: `/etc/passwd` が world-writable になっていると、攻撃者が新しい root ユーザーを直接追加できてしまいます。常に `ls -la /etc/passwd` で確認してください。

## 4. `vim`: 強力なモーダルエディタ

`vim`(Vi IMproved)は非常に強力なオープンソースのテキストエディタです。Nano とは異なり、Vim はモーダルエディタです。つまり、テキストの入力とコマンドの実行でそれぞれ異なるモードを使い分けます。Vim は「小さく、速く、`grep`・`awk`・`sed` など他のツールと組み合わせられる」という Unix の原則に従っています。

Vim は Nano より学習曲線が急ですが、モードとカーソル移動に慣れると、その効率の高さが実感できます。

```bash
# Open Vim
$ vim

# Open or create a file
$ vim notes.txt

# Exit Vim (from Normal mode)
:q          # quit (if no changes)
:q!         # force quit (discard changes)
:wq         # save and quit
:x          # save and quit (shorthand)
```

## 5. Vim のモード

Vim には通常のエディタとの違いを生む6つの基本モードがあります。これらのモードを理解することが Vim を使いこなす鍵です。

| モード | 移行キー | 説明 |
|------|-----------|--------|
| Normal | `ESC` | Vim 起動時のデフォルトモード。すべての入力はテキストではなくエディタコマンドとして扱われる。 |
| Insert | `i`, `a`, `o` | テキストをバッファに入力・挿入するためのモード。 |
| Visual | `v`, `V`, `CTRL+V` | テキストを視覚的に選択するモード。選択した範囲を削除・コピー・置換できる。 |
| Command | `:` | エディタ下部で一行コマンドを入力するモード(ソート、置換、削除など)。 |
| Replace | `R` | 入力した文字が既存の文字を上書きする。既存の文字がなくなると、以降は追加入力になる。 |
| Ex | `Q` | Vim の前身である Ex エディタの動作をエミュレートするモード。Normal モードに戻らず、複数のコマンドを連続して実行できる。 |

### モード遷移図

```
               ┌─────────────────────┐
               │    NORMAL MODE      │  ← default on start / press ESC
               └──────────┬──────────┘
                          │
          ┌───────────────┼───────────────┐
          │               │               │
          ▼               ▼               ▼
   ┌─────────────┐ ┌─────────────┐ ┌──────────────┐
   │ INSERT MODE │ │ VISUAL MODE │ │ COMMAND MODE │
   │  (i, a, o) │ │  (v, V)     │ │     (:)      │
   └─────────────┘ └─────────────┘ └──────────────┘
   Type text here   Select text     :w  :q  :wq
   Press ESC        Press ESC       :s/old/new/g
   to go back       to go back
```

### よく使う Vim コマンド

```bash
# --- Mode switching ---
i           # Enter Insert mode (before cursor)
a           # Enter Insert mode (after cursor)
o           # New line below + Insert mode
ESC         # Return to Normal mode

# --- Navigation (Normal mode) ---
h j k l     # Move left / down / up / right
gg          # Go to first line
G           # Go to last line
:20         # Go to line 20

# --- Editing (Normal mode) ---
dd          # Delete (cut) current line
yy          # Yank (copy) current line
p           # Paste below
u           # Undo
CTRL + r    # Redo
x           # Delete character under cursor

# --- Search (Normal mode) ---
/pattern    # Search forward
n           # Next match
N           # Previous match

# --- Command mode ---
:w          # Save (write)
:q          # Quit
:wq         # Save and quit
:q!         # Force quit (no save)
:s/old/new/g        # Replace on current line
:%s/old/new/g       # Replace in entire file
:set number         # Show line numbers
```

## 6. `vimtutor`: Vim をインタラクティブに学ぶ

`vimtutor` は Vim に組み込まれたインタラクティブなチュートリアルで、初心者がエディタの操作を習得できるように作られています。完了までに約25〜30分かかります。実務で Vim を使い始める前に一度通しておく価値があります。

アクセス方法は2通りあります。

1. ターミナルで `vimtutor` と入力する(練習用のコピーファイルが開く)
2. Vim の内部から、Command モードに入って `:Tutor` と入力する

```bash
# Start the interactive tutorial
$ vimtutor
```

```
===============================================================================
=    W e l c o m e   t o   t h e   V I M   T u t o r    -    Version 1.7      =
===============================================================================

     Vim is a very powerful editor that has many commands, too many to
     explain in a tutor such as this.  This tutor is designed to describe
     enough of the commands that you will be able to easily use Vim as
     an all-purpose editor.

     The approximate time required to complete the tutor is 25-30 minutes...
```

> `vimtutor` は練習用ファイルの「コピー」を開くので、壊れる心配をせずに自由に試せます。各レッスンのコマンドは、読むだけでなく実際に手を動かして実行することで身につきます。

## Nano と Vim の比較

| 項目 | `nano` | `vim` |
|---------|--------|-------|
| 学習曲線 | 緩やか | 急 |
| モーダル編集 | なし | あり(6モード) |
| ショートカット表示 | あり(画面下部) | なし(暗記が必要) |
| 速度(習熟後) | 普通 | 非常に速い |
| スクリプト・マクロ | なし | あり |
| プラグイン対応 | なし | 豊富 |
| 向いている用途 | 手早い編集、初心者 | パワーユーザー、開発者 |
| 終了コマンド | `CTRL + X` | `:q!` または `:wq` |

## クイックリファレンス

```bash
# ── NANO ──────────────────────────────────────────
nano filename.txt       # open / create file
CTRL + O  → ENTER       # save file
CTRL + X                # exit
CTRL + W                # search
CTRL + K                # cut line
CTRL + U                # paste
M-U                     # undo

# ── VIM ───────────────────────────────────────────
vim filename.txt        # open / create file

# Mode switching
i                       # insert mode
ESC                     # back to normal mode
v                       # visual mode
:                       # command mode

# Save / Exit
:w                      # save
:q                      # quit
:wq                     # save and quit
:q!                     # force quit

# Essential commands (Normal mode)
dd                      # delete line
yy                      # copy line
p                       # paste
u                       # undo
/pattern                # search

# Start interactive tutorial
vimtutor
```
