## 重要な用語

この教材でよく出てくる言葉である。

| 用語 | 意味 |
|:---|:---|
| ページャ | 長い出力を1画面ずつ見る(`less`、`more`) |
| `head` / `tail` | ファイルの最初 / 最後の行を表示する |
| `grep` | パターンに一致する行だけを残す |
| `cut` | 特定の列やフィールドを取り出す |
| `sort` / `uniq` | 行を並べ替える / 重複した行をまとめる |
| `wc` | 行数、単語数、文字数を数える |
| `awk` / `sed` | フィールド処理や置換のための小さなテキスト処理言語 |

## 1. `more`

`more` はファイルの内容をページ単位で表示します。いくつか制限があります。上にスクロールできないことと、`q` で終了しても表示済みの内容はターミナルに残ることです。ナビゲーション不要でファイルをさっと確認したいときに向いています。

```bash
more /etc/passwd
```

> `SPACE` で次のページへ、`q` で終了します。

---

## 2. `less`

`less` は `more` の上位版です。上下どちらにもスクロールでき、ファイル全体を表示でき、`q` で終了するとターミナルがクリアされて表示が残りません。長いファイルを読むときはこちらを使うほうがよいです。

```bash
less /etc/passwd
```

> 矢印キーまたは `j`/`k` でスクロール、`/keyword` でファイル内検索、`q` で終了します。

---

## 3. `head`

`head` はデフォルトでファイルの最初の10行を表示します。ログファイルやデータファイルの先頭を確認するのに便利です。

```bash
head /etc/passwd

# Custom: show first 20 lines
head -n 20 /etc/passwd
```

---

## 4. `tail`

`tail` は `head` の逆で、ファイルの最後の10行を表示します。`-f` フラグと組み合わせると、ログファイルをリアルタイムで監視できます。

```bash
tail /etc/passwd

# Real-time log monitoring
tail -f /var/log/syslog

# Custom: show last 20 lines
tail -n 20 /etc/passwd
```

---

## 5. `sort`

`sort` はファイルの内容やストリームをデフォルトでアルファベット順(A-Z)に並べ替えます。パイプ(`|`)と組み合わせて他のコマンドの出力を並べ替えることもできます。

```bash
sort /etc/passwd

# Reverse order (Z-A)
sort -r /etc/passwd

# Sort numerically
sort -n file.txt
```

---

## 6. `grep`

`grep` は Global Regular Expression Print の略です。ファイルやストリームから、指定したパターンに一致する行を検索・フィルタリングします。正規表現と組み合わせるとさらに強力になります。

```bash
# Show lines containing "root"
grep "root" /etc/passwd

# Exclude lines with "false" or "nologin"
grep -v "false\|nologin" /etc/passwd

# Case insensitive search
grep -i "ROOT" /etc/passwd
```

| フラグ | 機能 |
|------|--------|
| `-v` | マッチを反転(パターンを除外) |
| `-i` | 大文字小文字を区別しない |
| `-n` | 行番号を表示 |
| `-r` | ディレクトリを再帰的に検索 |
| `-E` | 拡張正規表現 |

---

## 7. `cut`

`cut` はファイルの各行から特定の部分を削除または抽出します。`/etc/passwd` の `:` のような区切り文字を基準に列を選択するのによく使われます。

```bash
# Extract field 1 (username) using ":" as delimiter
cut -d":" -f1 /etc/passwd

# Extract multiple fields
cut -d":" -f1,7 /etc/passwd
```

---

## 8. `tr`

`tr`(translate)はストリームの文字を置換または削除します。たとえば `:` をスペースに置き換えると出力が読みやすくなります。

```bash
# Replace ":" with space
cat /etc/passwd | tr ":" " "

# Convert lowercase to uppercase
cat file.txt | tr 'a-z' 'A-Z'

# Delete specific characters
cat file.txt | tr -d ':'
```

---

## 9. `column`

`column` はストリームを整ったテーブル形式に整形し、読みやすくします。`tr` と組み合わせて構造化されたテーブルを作るのが一般的です。

```bash
# Format passwd file as a table
cat /etc/passwd | tr ":" " " | column -t
```

---

## 10. `awk`

`awk` は強力なテキスト処理言語です。ここでの主な用途は、出力の各行から特定の列を表示することです。`$1` は最初の列、`$NF` は最後の列を指します。

```bash
cat /etc/passwd | grep -v "false\|nologin" | tr ":" " " | awk '{print $1, $NF}'
```

**Output:**
```
root /bin/bash
sync /bin/sync
postgres /bin/bash
mrb3n /bin/bash
cry0l1t3 /bin/bash
htb-student /bin/bash
```

| 変数 | 意味 |
|----------|---------|
| `$1` | 最初の列 |
| `$2` | 2番目の列 |
| `$NF` | 最後の列(N = 列の総数) |
| `$0` | 行全体 |
| `NR` | 現在の行番号 |

---

## 11. `sed`

`sed`(Stream Editor)はストリームに対して正規表現パターンでテキストを置換するツールです。一般的な形式は `s/古いパターン/新しいパターン/g` で、`s` は substitute(置換)、`/g` は global で、最初の一致だけでなくすべての出現箇所を置換するという意味です。

```bash
cat /etc/passwd | grep -v "false\|nologin" | tr ":" " " | awk '{print $1, $NF}' | sed 's/bin/HTB/g'
```

**Output:**
```
root /HTB/bash
sync /HTB/sync
postgres /HTB/bash
mrb3n /HTB/bash
cry0l1t3 /HTB/bash
htb-student /HTB/bash
```

---

## 12. `wc`

`wc`(Word Count)はファイルやストリームの行数・単語数・文字数を数えます。フィルタリングで最もよく使われるフラグは、マッチした行数を数える `-l` です。

```bash
cat /etc/passwd | grep -v "false\|nologin" | tr ":" " " | awk '{print $1, $NF}' | wc -l
```

**Output:**
```
6
```

| フラグ | 機能 |
|------|--------|
| `-l` | 行数を数える |
| `-w` | 単語数を数える |
| `-c` | バイト数・文字数を数える |

## 13. すべてのツールを組み合わせる

上記のツールをすべてつなげたワンライナー:

```bash
cat /etc/passwd \
  | grep -v "false\|nologin" \   # Remove service accounts
  | tr ":" " " \                 # Replace ":" with space
  | awk '{print $1, $NF}' \      # Print username and shell
  | sed 's/bin/HTB/g' \          # Replace "bin" with "HTB"
  | sort \                       # Sort alphabetically
  | wc -l                        # Count total results
```

### パイプラインの図

```
[cat /etc/passwd]
       │
       ▼
[grep -v "false\|nologin"]  ── filter out service accounts
       │
       ▼
[tr ":" " "]  ── make columns readable
       │
       ▼
[awk '{print $1, $NF}']  ── extract username & shell
       │
       ▼
[sed 's/bin/HTB/g']  ── substitute text
       │
       ▼
[sort]  ── alphabetical order
       │
       ▼
[wc -l]  ── count output
```

## 14. セキュリティノート: ログフォレンジクスと GTFOBins

テキストフィルタリングのコマンドは、SOC(セキュリティ運用センター)の業務、スレットハンティング、インシデント対応の基礎になります。

1. フォレンジックなログ分析: SSH のブルートフォース試行を絞り込むには `grep "Failed password" /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | sort -nr`、自動化された Web スキャナーを検出するには `grep -E "nikto|sqlmap|nmap|dirbuster" /var/log/apache2/access.log`、アクセス上位の攻撃元 IP を抽出するには `awk '{print $1}' /var/log/nginx/access.log | sort | uniq -c | sort -nr | head -10` を使う。
2. 認証情報・シークレットの探索: Web ルートやプロジェクトツリーから漏えいしたパスワードやキーを探すには `grep -rnwiE "password|secret|apikey|access_token|db_pass" /var/www/ 2>/dev/null` を使う。
3. テキスト処理系バイナリを使った権限昇格(GTFOBins 参照): `awk` はシェルを起動できる(`awk 'BEGIN {system("/bin/sh")}'`)。`sed` は保護されたファイルを読める(`sed -e '1w /dev/stdout' -e 1d /etc/shadow`)。`cut` も保護されたファイルを1行ずつ読める(`cut -d "" -f1 /etc/shadow`)。`less` や `more` はページャーからシェルに抜けられる(`!/bin/sh`)。

```bash
# ── ADVANCED LOG PARSING ONE-LINERS ──────────────────────────

# Extract all unique IPv4 addresses from auth.log
$ grep -oE '([0-9]{1,3}\.){3}[0-9]{1,3}' /var/log/auth.log | sort -u

# Find top 5 HTTP 404 targets (directory fuzzing detection)
$ awk '($9 ~ /404/)' /var/log/apache2/access.log | awk '{print $7}' | sort | uniq -c | sort -nr | head -5

# GTFOBins Sudo Awk Root Shell
$ sudo awk 'BEGIN {system("/bin/sh")}'
```

| `more` | ファイル | ページ表示 | 不可 | 残る |
| `less` | ファイル | ページ表示 | 可能 | クリアされる |
| `head` | ファイル | 最初のN行 | — | クリアされる |
| `tail` | ファイル | 最後のN行 | — | クリアされる |
| `sort` | ファイル/パイプ | 並べ替えた行 | — | クリアされる |
| `grep` | ファイル/パイプ | 一致した行 | — | クリアされる |
| `cut` | ファイル/パイプ | 抽出した列 | — | クリアされる |
| `tr` | パイプ | 置換した文字 | — | クリアされる |
| `column` | パイプ | テーブル形式 | — | クリアされる |
| `awk` | パイプ | 選択したフィールド | — | クリアされる |
| `sed` | パイプ | 置換したテキスト | — | クリアされる |
| `wc` | ファイル/パイプ | カウント | — | クリアされる |

## クイックリファレンス

```bash
# View files
more file.txt          # paged, stays in terminal
less file.txt          # paged, scrollable, clean exit
head -n 10 file.txt    # first 10 lines
tail -n 10 file.txt    # last 10 lines
tail -f file.txt       # real-time follow

# Filter & search
grep "pattern" file.txt          # search for pattern
grep -v "pattern" file.txt       # exclude pattern
grep -i "pattern" file.txt       # case-insensitive

# Transform
sort file.txt                    # sort A-Z
sort -r file.txt                 # sort Z-A
cut -d":" -f1 file.txt           # extract column 1
tr ":" " " < file.txt            # replace char
column -t file.txt               # table format

# Advanced
awk '{print $1, $NF}' file.txt   # print first & last column
sed 's/old/new/g' file.txt       # substitute text globally
wc -l file.txt                   # count lines
```
