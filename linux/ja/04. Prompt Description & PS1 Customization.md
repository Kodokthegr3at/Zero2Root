## 重要な用語

この教材でよく出てくる言葉である。

| 用語 | 意味 |
|:---|:---|
| プロンプト | 各コマンドの前に表示される文字。`user@host:~$` など |
| PS1 | プロンプトの見た目を定義する変数 |
| エスケープシーケンス | `\u` や `\w` のような、PS1が実際の情報(ユーザー、パス)に展開するコード |

| `.bashrc` | プロンプトの設定を永続化するシェルの設定ファイル |

## 1. Bash プロンプトの基礎

Bash プロンプトは、システムがコマンドを受け付ける準備ができたことを知らせるためにターミナルに表示されるテキスト行である。デフォルトでは次の情報が表示される。

- ユーザー名: 現在ログインしているのは誰か。
- ホスト名: コンピュータ/マシンの名前。
- 現在のディレクトリ: アクティブなフォルダ。

プロンプトが表示されたあと、カーソル（点滅する線やボックス）がコマンドの入力を待つ。

---

## 2. プロンプトの構造

デフォルトの Bash プロンプトの形式は、一貫していて分かりやすいパターンに従う。

### デフォルトの形式

```
<username>@<hostname><current working directory>$
```

### 構造の内訳

```
cry0l1t3  @  htb  [~]  $
    │     │   │    │    │
    │     │   │    │    └── $ = regular user  |  # = root user
    │     │   │    └─────── current directory (~ = home)
    │     │   └──────────── hostname (machine name)
    │     └──────────────── separator
    └────────────────────── username
```

### 実際の例

```bash
# Standard user in home directory
cry0l1t3@htb[~]$

# Standard user in a different directory
cry0l1t3@htb[/etc/ssh]$

# Root user
root@htb[/htb]#

# Minimal prompt (when PS1 not set — common in reverse shells)
$       ← unprivileged user
#       ← root / privileged
```

補足: チルダ `~` は常にログイン中のユーザーのホームディレクトリを指す。例えば、一般ユーザーの場合 `~` は `/home/cry0l1t3`、root の場合は `/root` になる。

---

## 3. ユーザーと root のプロンプト

一般ユーザーとして、もしくは root としてログインしているかを見分ける最も簡単な方法は、プロンプトの最後の文字を確認することである。

- `$` は一般ユーザー（非特権）を意味する。
- `#` は root / スーパーユーザー（特権あり）を意味する。

この違いはペネトレーションテストにおいて重要である。`#` という文字は、root アクセスを取得したことを意味する。

```bash
# Regular user prompt
cry0l1t3@htb[~]$  ← $ = normal user, limited privileges

# Root prompt
root@htb[/htb]#   ← # = root, FULL system access

# Minimal shell (e.g. after exploit / reverse shell)
$   ← still a user shell
#   ← got root! privilege escalation successful
```

ペンテストの注意点: ターゲット上でリバースシェルを実行すると、ユーザー名やホスト名のない `$` または `#` だけが表示されることがある。これは、そのシェルセッションで PS1 変数が正しく設定されていないために起こる。

---

## 4. PS1 変数

PS1（Prompt String 1）は、コマンドプロンプトの表示方法を制御する Linux の環境変数である。PS1 は、システムがコマンドを受け付ける準備ができるたびに表示されるテキストを定義するテンプレートのように機能する。

PS1 をカスタマイズすることで、次のような有用な追加情報を表示できる。

- マシンやターゲットの IP アドレス。
- 日付と時刻。
- 直前のコマンドの成功/失敗ステータス。
- 現在のディレクトリのフルパス。

これはペネトレーションテスト中に特に役立つ。活動の追跡や作業の文書化をより効果的に行えるからである。

```bash
# Check current PS1 value
$ echo $PS1
\[\u@\h \W\]\$

# Temporarily change PS1 in current session
$ PS1="[\u@\h \w] $ "

# Permanently change in ~/.bashrc
$ nano ~/.bashrc
# Add/modify PS1 line, then:
$ source ~/.bashrc
```

---

## 5. PS1 の特殊文字

PS1 はバックスラッシュ `\` で始まる特殊文字を使い、動的な情報を自動的に表示する。

| 文字 | 説明 | 出力例 |
|------|------|--------|
| `\u` | 現在のユーザー名 | `cry0l1t3` |
| `\h` | ホスト名（最初のドットまで） | `htb` |
| `\H` | フルホスト名 | `htb.local` |
| `\w` | 現在のディレクトリのフルパス | `/home/user/docs` |
| `\W` | 現在のディレクトリ名のみ | `docs` |
| `\d` | 日付（Mon Feb 6） | `Mon Feb  6` |
| `\D{%Y-%m-%d}` | YYYY-MM-DD 形式の日付 | `2025-06-01` |
| `\t` | 24時間形式の時刻（HH:MM:SS） | `14:32:10` |
| `\T` | 12時間形式の時刻（HH:MM:SS） | `02:32:10` |
| `\@` | 12時間形式の時刻（AM/PM） | `02:32 PM` |
| `\s` | シェルの名前 | `bash` |
| `\j` | バックグラウンドジョブの数 | `2` |
| `\n` | 改行 | ↵ |
| `\$` | ユーザーは `$`、root は `#` | `$` または `#` |

## 6. プロンプトのカスタマイズ例

PS1 は `~/.bashrc` ファイルで設定する。恒久的な変更はこのファイルに追加し、すぐに反映させるために source する必要がある。

### プリセット例

```bash
# ── MINIMAL (clean and simple) ──────────────────────
PS1="[\u@\h \W]\$ "
# Output: [cry0l1t3@htb ~]$

# ── WITH FULL PATH ───────────────────────────────────
PS1="[\u@\h \w]\$ "
# Output: [cry0l1t3@htb /home/cry0l1t3/documents]$

# ── WITH DATE & TIME ─────────────────────────────────
PS1="[\D{%Y-%m-%d} \t] \u@\h:\w\$ "
# Output: [2025-06-01 14:32:10] cry0l1t3@htb:~$

# ── PENTESTING PROMPT (with IP tracking) ─────────────
PS1="[\u@\h - $(hostname -I | awk '{print $1}')] \w\$ "
# Output: [cry0l1t3@htb - 10.10.14.5] /home/cry0l1t3$

# ── WITH COLOR (green user, blue path) ───────────────
PS1="\[\033[01;32m\]\u@\h\[\033[00m\]:\[\033[01;34m\]\w\[\033[00m\]\$ "
# Output: cry0l1t3@htb:/home/cry0l1t3$  (colored)
```

### カラーコードの一覧

```bash
# Format: \[\033[<code>m\]...\[\033[00m\]
#                    └── color code

# Text Colors
\[\033[30m\]   # Black
\[\033[31m\]   # Red
\[\033[32m\]   # Green
\[\033[33m\]   # Yellow
\[\033[34m\]   # Blue
\[\033[35m\]   # Purple
\[\033[36m\]   # Cyan
\[\033[37m\]   # White

# Bold versions
\[\033[01;32m\]  # Bold Green
\[\033[01;34m\]  # Bold Blue
\[\033[01;31m\]  # Bold Red

# Reset
\[\033[00m\]   # Reset to default
```

### 恒久的に適用する方法

```bash
# 1. Open .bashrc
$ nano ~/.bashrc

# 2. Find or add the PS1 line at the bottom:
PS1="[\D{%Y-%m-%d} \t] \u@\h:\w\$ "

# 3. Save and apply without restarting terminal
$ source ~/.bashrc
# or
$ . ~/.bashrc
```

### ペンテストの実務: コマンドの記録

```bash
# Record all commands with timestamps using script
$ script -a -t 2>~/pentest_timing.txt ~/pentest_log.txt

# View bash history with timestamps
$ export HISTTIMEFORMAT="%F %T "
$ history

# Bash history file location
$ cat ~/.bash_history
```

補足: 日付/時刻付きのカスタム PS1 を設定し、`script` によるロギングと組み合わせるのは、ペンテスト中の良い実践である。これにより、すべてのコマンドがタイムスタンプ付きで自動的に記録され、レポート作成に役立つ。

## クイックリファレンス・チートシート

```bash
# ── CHECK CURRENT PROMPT ─────────────────────────────
echo $PS1                    # show current PS1 value
echo $0                      # show current shell

# ── IDENTIFY USER LEVEL ──────────────────────────────
whoami                       # current username
id                           # UID, GID, groups
# $ at end = regular user
# # at end = root

# ── TEMPORARY CHANGE ─────────────────────────────────
PS1="[\u@\h \w]\$ "         # change for current session only

# ── PERMANENT CHANGE ─────────────────────────────────
echo 'PS1="[\u@\h \w]\$ "' >> ~/.bashrc
source ~/.bashrc

# ── COMMON PS1 PRESETS ───────────────────────────────
# Minimal:     PS1="[\u@\h \W]\$ "
# Full path:   PS1="[\u@\h \w]\$ "
# With time:   PS1="[\t] \u@\h:\w\$ "
# Pentesting:  PS1="[\D{%Y-%m-%d} \t] \u@\h \w\$ "

# ── RECORD COMMANDS (pentest documentation) ──────────
script -a ~/session.log      # start recording
exit                         # stop recording
export HISTTIMEFORMAT="%F %T "  # add timestamps to history
```
