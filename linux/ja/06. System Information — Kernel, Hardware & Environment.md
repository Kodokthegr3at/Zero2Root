## 1. OSとカーネルの識別

OSとカーネルの情報収集は、システム管理でもペネトレーションテストの初期偵察でも最初に行う作業である。以下のコマンドでディストリビューション、カーネルバージョン、CPUアーキテクチャを確認できる。

- `uname -a`: カーネルの全情報（カーネルバージョン、ビルド日時、アーキテクチャ、ホスト名）を表示する。
- `/etc/os-release` / `/etc/issue`: 公式ディストリビューション名とバージョン情報が書かれたファイル（Ubuntu、Debian、Kali、CentOS など）。
- `hostnamectl`: `systemd` を使う現代的なシステムでホスト名、カーネル、アーキテクチャの概要を表示する。

```bash
# ── KERNEL & OS VERSION CHECK ────────────────────────────────
$ uname -a
Linux htb-target 5.15.0-78-generic #85-Ubuntu SMP Fri Jul 7 15:25:09 UTC 2023 x86_64 x86_64 x86_64 GNU/Linux

$ uname -r      # Kernel release only (e.g., 5.15.0-78-generic)
$ uname -m      # Machine architecture (e.g., x86_64 / aarch64)

# ── DISTRO INFORMATION ───────────────────────────────────────
$ cat /etc/os-release
NAME="Ubuntu"
VERSION="22.04.3 LTS (Jammy Jellyfish)"
ID=ubuntu
ID_LIKE=debian
VERSION_ID="22.04"

$ hostnamectl
```

## 2. ハードウェア、CPU、メモリ

Linux カーネルは仮想ファイルシステム `/proc` を通じてハードウェアの状態とリソース使用状況を公開している。

- `lscpu`: CPUアーキテクチャ、コア数、ソケット数、L1/L2/L3キャッシュ、仮想化サポートなどの詳細情報を表示する。
- `free -h`: 物理RAMとスワップの使用量・空き容量を人間が読みやすい形式（`-h`）で表示する。
- `/proc/cpuinfo` と `/proc/meminfo`: カーネルが保持する、プロセッサとメモリの仕様に関する生データ。

```bash
# ── CPU SPECIFICATIONS ───────────────────────────────────────
$ lscpu
Architecture:            x86_64
  CPU op-mode(s):        32-bit, 64-bit
  Address sizes:         39 bits physical, 48 bits virtual
  Byte Order:            Little Endian
  CPU(s):                4
  Model name:            Intel(R) Core(TM) i7-10700K CPU @ 3.80GHz

# ── MEMORY CONSUMPTION ───────────────────────────────────────
$ free -h
               total        used        free      shared  buff/cache   available
Mem:           7.7Gi       2.1Gi       3.4Gi       120Mi       2.2Gi       5.2Gi
Swap:          2.0Gi          0B       2.0Gi
```

## 3. ディスクとファイルシステム

- `lsblk`: すべてのブロックデバイス（HDD、NVMe、USB、ループデバイスなど）をマウントポイント付きのツリー構造で一覧表示する。
- `df -h`: マウント中の各ファイルシステムのディスク使用量を表示する。
- `du -sh <path>`: 指定したファイルまたはディレクトリの合計サイズを集計する。
- `fdisk -l` / `parted -l`: ディスクのパーティションテーブルを表示する（root権限が必要）。

```bash
# ── BLOCK DEVICES TREE ───────────────────────────────────────
$ lsblk
NAME   MAJ:MIN RM   SIZE RO TYPE MOUNTPOINTS
sda      8:0    0    50G  0 disk 
├─sda1   8:1    0     1M  0 part 
├─sda2   8:2    0     2G  0 part /boot
└─sda3   8:3    0    48G  0 part /

# ── DISK FREE SPACE ──────────────────────────────────────────
$ df -h /
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda3        48G   12G   34G  27% /

# ── DIRECTORY SIZE CALCULATION ───────────────────────────────
$ du -sh /var/log/
1.4G	/var/log/
```

## 4. ネットワークインターフェースとホスト名

- `ip addr` / `ip a`: ネットワークインターフェース（NIC）とそのIPv4/IPv6アドレス、MACアドレスを表示する（旧来の `ifconfig` の後継）。
- `ip route` / `ip r`: カーネルのルーティングテーブルとデフォルトゲートウェイを表示する。
- `hostname -I`: ホストに割り当てられたすべてのIPアドレスを簡潔に表示する。
- `/etc/resolv.conf`: システムが使用するDNSネームサーバーを設定するファイル。
- `/etc/hosts`: IPアドレスとホスト名の静的な対応表。DNS問い合わせより先に参照される。

```bash
# ── INSPECT NETWORK INTERFACES ───────────────────────────────
$ ip -br a
lo               UNKNOWN        127.0.0.1/8 ::1/128 
eth0             UP             10.10.14.25/24 fe80::250:56ff:fe9d:8b2a/64 
tun0             UP             10.10.10.50/32 

# ── ROUTING & DNS ────────────────────────────────────────────
$ ip route
default via 10.10.14.1 dev eth0 proto dhcp src 10.10.14.25 metric 100 

$ cat /etc/resolv.conf
nameserver 1.1.1.1
nameserver 8.8.8.8
```

## 5. オープンファイルとソケット（`lsof`）

Linux では「すべてはファイルである」という考え方に基づき、`lsof`（List Open Files）コマンドを使うと、プロセスが開いているファイル、パイプ、デバイス、ネットワークソケットをすべて一覧できる。

- `lsof -i`: アクティブなネットワーク接続とオープンポートを表示する。
- `lsof -i :80`: ポート80を使用しているプロセスを特定する。
- `lsof -u <user>`: 特定ユーザーが開いているファイルを一覧表示する。
- `ss -tulnp`: リッスン中のTCP/UDPソケットと、それを保持しているプロセスのPIDを表示する。

```bash
# ── LIST OPEN NETWORK CONNECTIONS ────────────────────────────
$ sudo lsof -i -P -n
COMMAND    PID     USER   FD   TYPE DEVICE SIZE/OFF NODE NAME
sshd       892     root    3u  IPv4  24110      0t0  TCP *:22 (LISTEN)
sshd       892     root    4u  IPv6  24112      0t0  TCP *:22 (LISTEN)
apache2   1245 www-data    4u  IPv4  28901      0t0  TCP *:80 (LISTEN)

# ── LISTENING PORTS USING SS ─────────────────────────────────
$ ss -tulnp
Netid State  Recv-Q Send-Q Local Address:Port  Peer Address:PortProcess
tcp   LISTEN 0      128          0.0.0.0:22         0.0.0.0:*    users:(("sshd",pid=892,fd=3))
tcp   LISTEN 0      511          0.0.0.0:80         0.0.0.0:*    users:(("apache2",pid=1245,fd=4))
```

## 6. 環境変数

環境変数とは、システムやアプリケーションの実行時の設定を決めるために使われる、動的なキーと値のペアである。

- `$PATH`: コマンドを実行するときに実行ファイルを検索するディレクトリのリスト（コロン区切り）。
- `$USER` と `$HOME`: 現在のユーザー名とホームディレクトリのパス。
- `env` / `printenv`: 現在のセッションで有効なすべての環境変数を表示する。
- `export VAR="value"`: 新しい変数を作成し、そのシェルから起動されるすべての子プロセスに引き継ぐ。

```bash
# ── INSPECT ENVIRONMENT ──────────────────────────────────────
$ echo $PATH
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin

$ echo $USER $HOME
htb-student /home/htb-student

# Set temporary environment variable
$ export TARGET_IP="10.10.10.100"
$ ping -c 1 $TARGET_IP
```

## 7. セキュリティ上の注意点: カーネルエクスプロイト、ローカル偵察、環境変数の汚染

Linux のペネトレーションテスト（HTB Academy Module 18、The Hacker Playbook 3）において、システム情報はローカルでの権限昇格の土台になる。

1. カーネルエクスプロイトの照合。`uname -r` で得た古いカーネルバージョンには、既知のローカル権限昇格（LPE）脆弱性が存在することが多い。例えば Dirty COW（CVE-2016-5195）、Dirty Pipe（CVE-2022-0847）、OverlayFS（CVE-2021-3493）、PwnKit（CVE-2021-4034）などである。`searchsploit linux kernel 5.10` のようにローカルのエクスプロイトデータベースを検索する。
2. `$PATH` ハイジャックと環境変数の汚染。SUIDプログラムやcronスクリプトが絶対パスを指定せずにコマンドを呼び出している場合（`/usr/bin/curl` ではなく `curl` を呼ぶなど）、攻撃者は `$PATH` の先頭に細工したディレクトリを追加し（`export PATH=/tmp:$PATH`）、root権限でコードを実行できる可能性がある。
3. 内部ポートの調査。`ss -tulnp` や `netstat -tlpn` を使うと、`127.0.0.1` だけでリッスンしているローカルサービス（内部向けMySQL、Redis、管理用Webバックエンドなど)を発見でき、それを足がかりにピボットや追加のエクスプロイトが可能になる場合がある。

```bash
# ── PENTESTING SYSTEM RECONNAISSANCE SCRIPT ──────────────────
# 1. OS & Architecture check
uname -a; cat /etc/*release 2>/dev/null

# 2. Search for kernel exploits with searchsploit
searchsploit "Linux Kernel $(uname -r | cut -d'-' -f1)"

# 3. Check internal listening services
ss -tulnp | grep -E "127.0.0.1|::1"

# 4. Check for writable directories in PATH
echo $PATH | tr ":" "\n" | while read dir; do [ -w "$dir" ] && echo "[!] Writable PATH: $dir"; done
```

## 8. クイックリファレンス・チートシート

```bash
# ── SYSTEM & KERNEL ──────────────────────────────────────────
uname -a                               # full kernel & architecture
uname -r                               # kernel release version
cat /etc/os-release                    # Linux distribution details
hostname -I                            # all host IP addresses

# ── HARDWARE & RESOURCES ─────────────────────────────────────
lscpu                                  # CPU architecture details
free -h                                # RAM & Swap memory usage
lsblk                                  # list block devices & mounts
df -h                                  # free disk space per partition
du -sh /path/dir                       # directory disk usage

# ── NETWORK & SOCKETS ────────────────────────────────────────
ip -br a                               # brief network interfaces list
ip route                               # routing table & default gateway
ss -tulnp                              # listening TCP/UDP ports with PID
sudo lsof -i -P -n                     # active network connections & files

# ── ENVIRONMENT ──────────────────────────────────────────────
env                                    # print all environment variables
echo $PATH                             # print execution search path
export VAR="value"                     # set environment variable
```
