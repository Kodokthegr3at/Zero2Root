## 1. 🖥️ What Is Oracle Solaris?

### 🇮🇩 Bahasa Indonesia
**Solaris** (dulu SunOS/Sun Solaris) adalah Unix komersial dari **Sun Microsystems** (kini **Oracle**). Berbagi DNA BSD/System V dengan Linux, tetapi **kernel, userland, init, packaging, dan FS default** berbeda.

$$
\text{Solaris stack} = \text{Sun/Oracle kernel} + \text{SMF} + \text{ZFS default} + \text{Zones} + \text{IPS pkg}
$$

### 🇬🇧 English
Solaris remains relevant in **enterprise SPARC/x86**, telco, and legacy estates. Pentesters and admins encounter it alongside Linux — knowing the deltas speeds recon and hardening.

### 日本語
Solaris は Unix 系 OS で、Linux とはカーネル・init・パッケージ・既定 FS が異なります。SPARC/x86 のレガシー環境で今も遭遇します。

```
Timeline (simplified)
  1990s  SunOS / Solaris 2.x
  2000s  Solaris 8/9/10 — ZFS, Containers preview
  2010s  Oracle acquisition; Solaris 11 + IPS
  today  Oracle Solaris 11.x (maintenance-focused)
         Linux distros dominate cloud; Solaris in legacy/verticals
```

| Property | Solaris | Typical Linux |
|:---|:---|:---|
| Vendor | Oracle | Community/commercial mix |
| Init / services | SMF | systemd (most distros) |
| Default FS | ZFS (modern) | ext4/XFS/btrfs |
| Containers | Zones | cgroups/namespaces (Docker/Podman) |
| Package mgr | IPS (`pkg`) | apt/dnf/pacman |
| License | Proprietary (Oracle) | Mostly open source |

## 2. ⚖️ Solaris vs Linux — Key Differences for Admins

### 🇮🇩 Bahasa Indonesia
Admin yang terbiasa Linux akan menemui CLI dan path yang beda, meski konsep (user, proses, jaringan) mirip.

| Area | Solaris | Linux |
|:---|:---|:---|
| Kernel name | Sun/Oracle kernel | Linux kernel |
| Service control | `svcadm`, `svcs` | `systemctl` |
| Boot loader | GRUB (x86) | GRUB/systemd-boot |
| Network config | `dladm`, `ipadm`, `route` | `ip`, NetworkManager |
| User/group files | `/etc/passwd`, `/etc/shadow` | Same FHS concept |
| Process list | `ps`, `pgrep`, `/proc` | Same ideas, different ps flags |
| Firewall | IPFilter historically; `pf` patterns | iptables/nft/ufw |

### 🇬🇧 English
Many GNU tools exist on Solaris via **GNU userland** packages, but **paths and flags differ**. Scripts portable on Linux may fail on Solaris without adjustment.

### 日本語
概念は近いですがコマンドとパスが違います。Linux 用スクリプトはそのままでは動かないことが多いです。

```bash
# Linux habit          →  Solaris equivalent (illustrative — Solaris 11)
# systemctl status ssh →  svcs -xv ssh
# df -hT               →  zfs list  (when ZFS root)
# ip addr              →  ipadm show-addr
# apt install curl     →  pkg install curl
# crontab -l           →  crontab -l (similar, different paths)
```

## 3. 🎛️ SMF — Service Management Facility

### 🇮🇩 Bahasa Indonesia
**SMF** menggantikan legacy init scripts dengan **FMRI** (Fault Management Resource Identifier) dan graf ketergantungan.

$$
\text{FMRI} = \texttt{svc:/category/service:instance}
$$

Contoh: `svc:/network/ssh:default`

### 🇬🇧 English
SMF tracks service state (`online`, `offline`, `maintenance`), restarts on failure, and orders startup by dependencies — conceptually similar to **systemd** but a different CLI and XML manifests.

### 日本語
SMF は Solaris の init 相当です。状態追跡・依存関係・障害時再起動は systemd に似ていますが CLI は `svcs` / `svcadm` です。

```bash
# List services
svcs -a
svcs -x                    # failed/maintenance
svcs -l ssh                # detailed

# Enable / start / stop
sudo svcadm enable ssh
sudo svcadm disable ssh
sudo svcadm restart ssh
sudo svcadm clear ssh      # clear maintenance state

# Inspect properties
svcprop -p all ssh
```

| SMF state | Meaning |
|:---|:---|
| `online` | Running / satisfied |
| `offline` | Disabled/stopped |
| `maintenance` | Admin intervention needed |
| `degraded` | Partial function |

Compare Linux systemd → **note 17** (`systemctl`, `journalctl`).

## 4. 📦 IPS Packaging — `pkg`

### 🇮🇩 Bahasa Indonesia
**Image Packaging System (IPS)** mengelola software dengan publisher Oracle dan dependency solver.

### 🇬🇧 English
Use **`pkg`**, not `apt`/`yum`. Boot environments (BE) pair with ZFS for rollback upgrades.

### 日本語
Solaris 11 は `pkg` です。ZFS の boot environment (`beadm`) と組み合わせてアップグレードを巻き戻せます。

```bash
pkg publisher
pkg search curl
pkg info -r curl
sudo pkg install curl
pkg list
pkg update

# Verify package contents
pkg contents -H curl

# Create boot environment before major update (ZFS systems)
beadm list
sudo beadm create pre-update-$(date +%Y%m%d)
```

| Command | Action |
|:---|:---|
| `pkg install PKG` | Install package |
| `pkg update` | Update installed set |
| `pkg verify` | Check file integrity |
| `beadm activate BE` | Boot into snapshot BE |

## 5. 💾 ZFS — Zettabyte File System

### 🇮🇩 Bahasa Indonesia
**ZFS** menggabungkan volume manager + filesystem: **copy-on-write**, checksums, snapshots, compression, dedup (hati-hati dengan RAM).

$$
\text{Dataset path: } \texttt{tank/home/alice} \subset \texttt{tank/home} \subset \texttt{tank (pool)}
$$

### 🇬🇧 English
Linux now has **OpenZFS** on some distros, but Solaris integration is native and mature. Admins think in **pools** and **datasets**, not just `/dev/sda1`.

### 日本語
ZFS はプールとデータセットで考えます。チェックサム・スナップショット・圧縮が標準機能です。Linux の OpenZFS より Solaris 側の統合が古いです。

```bash
# Pool & dataset (Solaris)
zpool list
zpool status
zfs list
zfs create tank/export
zfs set compression=lz4 tank/export
zfs snapshot tank/export@backup-$(date +%F)
zfs rollback tank/export@backup-2026-08-18

# Quotas & reservations
zfs set quota=50G tank/home/alice
zfs set reservation=10G tank/home/alice
```

| ZFS feature | Benefit |
|:---|:---|
| Checksumming | Detect silent corruption |
| Snapshots | Instant point-in-time |
| Send/receive | Replication |
| Compression | Space savings (CPU tradeoff) |

## 6. 🏝️ Solaris Zones — OS-Level Virtualization

### 🇮🇩 Bahasa Indonesia
**Zones** adalah isolasi level kernel (seperti container modern): **global zone** + **non-global zones** dengan namespace terpisah.

### 🇬🇧 English
Predates Linux containers but similar goals. **Kernel zones** vs **native zones** differ in isolation strength. Not Docker — but conceptually related to **note 23**.

### 日本語
Zones は OS 仮想化です。global zone がホスト、non-global が隔離された userland を共有カーネル上で動かします。

```bash
# Zone management (illustrative)
zonecfg -z myzone
zoneadm -z myzone install
zoneadm -z myzone boot
zlogin myzone

# From global zone
zoneadm list -cv
```

```
Global Zone (host)
 ├─ Zone: web01   (own /etc, users, SMF subset)
 ├─ Zone: db01
 └─ Zone: dev01
Shared kernel, isolated userlands
```

## 7. 🔐 Security Notes — Solaris Hardening Highlights

### 🇮🇩 Bahasa Indonesia
Identifikasi OS dulu — mengira Solaris sebagai Linux membuat enum service dan jalur hardening salah.

### 🇬🇧 English
Map Solaris controls to Linux analogues: RBAC/roles vs sudo, audit daemon vs auditd, Trusted Extensions vs SELinux. Verify packages with `pkg verify`.

### 日本語
OS を早期に識別します。RBAC・監査・最小化パッケージが Linux の sudo/auditd/最小イメージに相当します。

| Topic | Solaris practice | Linux analogue |
|:---|:---|:---|
| RBAC / roles | `roleadd`, `profiles` | sudo + groups |
| Auditing | Solaris audit daemon | auditd |
| MAC | Trusted Extensions (niche) | SELinux/AppArmor |
| Password policy | `/etc/security/policy.conf` | `login.defs`, PAM |
| Remote access | `ssh` SMF service | `sshd` systemd unit |
| Minimization | `pkg` variant sets | minimal cloud images |

```bash
# Defensive recon (authorized Solaris host)
uname -a
cat /etc/release
svcs -x
netstat -an -f inet | grep LISTEN    # or ss equivalent if installed
pkg verify
zfs list
```

**Assessment tip:** identify the OS early — mistaking Solaris for Linux leads to the wrong privilege-escalation and service-enum paths.
